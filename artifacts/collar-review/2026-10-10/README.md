# 首輪の見直し — 現状と直し方、柄違いとおそろいセットの提案

[確認用HTMLを開く](index.html)。写真は同じフォルダの `img/` (修正前) と `after/img/` (修正後) を相対参照する (埋め込みはしない)。インターネット接続不要。フォルダごと開くか、フォルダごとコピーして使う。

1. 「1. いまの首輪」で、結論と犬ごとの写真・数値を見る。姿勢のボタン (静止・歩き・座り・伏せ) で写真が切り替わり、小さな写真を押すと大きな写真が入れ替わる。
2. 各項目の末尾で「了承 / 修正したい / 保留」とメモを記入する (8 項目)。犬ごとのメモ欄もある。
3. 「2. 追加パッケージ案」の「要ユーザー判断」6 点で「提案どおり / 変更 / 保留」とメモを記入する。初期状態はすべて未回答。
4. 「回答を保存 (JSON)」で回答ファイルをダウンロードし、チャットへ添付して引き継ぐ。「読みやすい一覧を保存 (Markdown)」は読み返し用。
5. 再開時は同じブラウザーの保存内容を使うか、「回答を読み込む」で保存済み JSON を選ぶ。

### 3. 修正後 (2026-10-10 最終、案 1) — 前後比較の使い方

1. 上の移動バーの「3. 修正後の前後比較」で開く。(a) 何を変えたか・適用した調整テーブル、(b) 試したラウンド、(c) 適用・検証、(d) 前後の数値と完了条件との照合を読む。
2. (e) 犬ごとの前後比較: 左が修正前、右が修正後 (最終 R9、案 1: ポメラニアン・サモエドは帯を毛の中に隠して金具とリードで見せる) で、同じ姿勢・同じ視点の写真が並ぶ。姿勢のボタンで切り替え、小さな写真 (修正後) を押すと比べる視点が変わる。静止は左側面・正面・真上・あご下を先に並べ、「ほかの視点も表示」で残り 4 視点を出す。
3. 犬ごとに「了承 / 修正したい / 保留」とメモを記入する (6 犬種)。(g) 残る課題と (h) VR で見てほしい点 (歩き・座り・伏せ・リード接続中・撫で中・飾り併用、サモエド・ポメラニアンの金具とリードの出方) を見て、VR で確認する。
4. 回答 JSON には `after` (犬ごとの `decision` / `notes`) が増えた。`after` が無い以前の JSON (`vanimal-collar-review-2026-10-10T08-34-16-974Z.json` など) もそのまま読み込める (修正後の回答は未回答になる)。ブラウザー保存のキーは変えていないので、1・2 の入力はそのまま残る。

ブラウザー保存は補助。file URL やブラウザー設定によって使えない場合は画面に案内を出す。別ブラウザー・別端末へ引き継ぐ場合は JSON を使う。回答は Unity・Issue へ自動反映されない。

写真と数値は 2026-10-10 に一時 Editor スクリプト (`tools/KH_CollarSurveyTempEditor.cs.txt` が写し) でプレビュー用の犬の複製を撮影・計測したもの (102 枚、720×560)。**Editor のアニメーションサンプルで、Play / VR / 実機の結果ではない。** 数値の元データは `tools/metrics.json`・`tools/report.txt`。修正後 (最終 R9) は同日に同じ姿勢・視点で撮り直した 102 枚 (`after/img/`) と `after/tools/` (`metrics.json`・`report.txt`・`fit-report.txt`) で、条件は修正前と同じ (VR の結果ではない)。追加パッケージ案の価格は提案で、価格の正本は古民家 `docs/business-strategy.md`。

再生成: `node scripts/art/build-collar-review.cjs` (テンプレートは `scripts/art/collar-review.template.html`。修正前は `tools/metrics.json`、修正後は `after/tools/metrics.json`・`after/tools/fit-report.txt` から数値表を作り、調整テーブルは `Assets/KominkaHillside/Scripts/Editor/KH_LeashProductionEditor.cs` から読む (帯の半径は `leash-assets.cjs` の `radii` と一致することも確かめる)。参照する 204 枚 (修正前 102 + 修正後 102) が `img/`・`after/img/` に揃い、枚数が一致することを確かめてから `index.html` を書く。足りなければ書かずに止まる)。
