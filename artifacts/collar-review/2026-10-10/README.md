# 首輪の見直し — 現状と直し方、柄違いとおそろいセットの提案

[確認用HTMLを開く](index.html)。写真は同じフォルダの `img/` を相対参照する (埋め込みはしない)。インターネット接続不要。フォルダごと開くか、フォルダごとコピーして使う。

1. 「1. いまの首輪」で、結論と犬ごとの写真・数値を見る。姿勢のボタン (静止・歩き・座り・伏せ) で写真が切り替わり、小さな写真を押すと大きな写真が入れ替わる。
2. 各項目の末尾で「了承 / 修正したい / 保留」とメモを記入する (8 項目)。犬ごとのメモ欄もある。
3. 「2. 追加パッケージ案」の「要ユーザー判断」6 点で「提案どおり / 変更 / 保留」とメモを記入する。初期状態はすべて未回答。
4. 「回答を保存 (JSON)」で回答ファイルをダウンロードし、チャットへ添付して引き継ぐ。「読みやすい一覧を保存 (Markdown)」は読み返し用。
5. 再開時は同じブラウザーの保存内容を使うか、「回答を読み込む」で保存済み JSON を選ぶ。

ブラウザー保存は補助。file URL やブラウザー設定によって使えない場合は画面に案内を出す。別ブラウザー・別端末へ引き継ぐ場合は JSON を使う。回答は Unity・Issue へ自動反映されない。

写真と数値は 2026-10-10 に一時 Editor スクリプト (`tools/KH_CollarSurveyTempEditor.cs.txt` が写し) でプレビュー用の犬の複製を撮影・計測したもの (102 枚、720×560)。**Editor のアニメーションサンプルで、Play / VR / 実機の結果ではない。** 数値の元データは `tools/metrics.json`・`tools/report.txt`。追加パッケージ案の価格は提案で、価格の正本は古民家 `docs/business-strategy.md`。

再生成: `node scripts/art/build-collar-review.cjs` (テンプレートは `scripts/art/collar-review.template.html`。`tools/metrics.json` から数値表を作り、参照する 102 枚の画像が `img/` に揃っていることを確かめてから `index.html` を書く。足りなければ書かずに止まる)。

関連: [首輪の位置ずれ BUG-DOG-011](../../../docs/development/issues/BUG-DOG-011-collar-fit.md)、[首輪・リードの柄違い IMP-DOG-048](../../../docs/development/issues/IMP-DOG-048-collar-and-leash-patterns.md)。

- 独立レビュー (同日、統括経由) の指摘を反映して再生成した:
