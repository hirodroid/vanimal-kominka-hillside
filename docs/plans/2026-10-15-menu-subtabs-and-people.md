### 3.2 推奨: 行を動かさず、サブタブで表示する行を絞る

- **行は `Content` の子のまま**。文言の配線 (`UILocalizationBindings.json`) が `Page_Acc/Scroll/Viewport/Content/AccRowN/...` の経路で 22 本のラベルを引いており、親を変えると Menu/22 の `ValidateScene` と Bind を呼ぶビルダーが止まる (さんぽ §8.1 と同じ判断)。
- **サブタブ = フィルタ**。カタログ階層 (A) で選んだ群の行だけ `SetActive(true)`、ほかの群と群見出し (FxHead / CollarHead) は隠す。飾り 10 件は 6 + 4 の 2 ページ、首輪 5・撫でFX 6 は 1 ページ。出すセルが常に 6 以下なら Content (≤ 376) が Viewport (390) に収まり、ScrollRect を残したままスクロールが起きない (`Clamped`)。ScrollRect を無効化する案 (さんぽ方式) は Menu/13 が周回版で実行禁止のため専用ビルダーと Menu/21 の分岐が要り、今回は採らない。
- **サブタブの置き場**: A 面の上段 (y 164 の行)。今は見出し `Header` (−100, 164、900×36、`KD_HandMenuScrollEditor.cs:379`) が使い、[もどる] (470, 164、140×40) は A 面では出ない。A 面では見出し (「犬のかざり」。タブの帯に「かざり」があるので省ける) を隠し、サブタブ 3 つ × 約 260 幅 + ページ送り (◀ 1/2 ▶、約 250 幅) を置く (1100 に収まる見込み。試算。開発側で決める)。B / C / D の面は見出しと [もどる] を今のまま出す。
- **B1 / B2 / C / D の面は今のまま**。サブタブは A 面でだけ出す。D (7 行) は今もスクロールで見ているので変えない。
- **ボタン文言・購入と装着の流れは変えない**。モックの「一覧で [買う]」は試着プレビューを飛ばすので採らない。撫でFX の「買うと即切替」「使用中はボタンを隠す」も現行のまま。
- **翻訳キー**: サブタブ名は既存キーで足りる (「犬のかざり」`KD_TreatPouch.WordAccTitle`、「首輪とリード」`collar.group`、「撫でエフェクト」`KD_TreatPouch.WordFxGroup`)。ページ送りの矢印は記号だけにし、ページ番号は数字の連結にすれば新規キー 0。「前へ / 次へ」の語を付けるなら写真の既存キー `photo.frame.previous` / `.next` (「前」「次」) を流用する (新規 13 言語を作らない)。
- **状態の保持**: サブタブとページは滞在中ローカルに保つ (タブを切り替えても戻さない。今の `_accProduct` と同じ扱い)。`ResetAccessoryScroll` の呼び手 (`Acc.cs` 118/176/187/314、`Collar.cs` 61/96、`Live.cs:200`) はページを 0 に戻す処理へ。ライブ詳細 → 犬選択 (`Live.cs:200`) の経路は、戻ったときに飾りのサブタブへ合わせる。
- **失わないもの**: 試着プレビュー (AccRow0..5 のミニチュア)、首輪と重なる犬の暗転と理由、60 秒待ち・反映待ち・拒否の表示、はずす / とりかえ、お花セットの B1/B2、首輪の「自分のリード」の行、確認カード共有 1 枚の排他、下端の支度ポイント未受取の案内。

- **ページ送り**: 自分以外が 9 人以下なら 9 セル全部を人に使う (ページ送りなし)。**10 人以上なら全ページ同じ割り付け**にする: セル 0 = [◀ 前の 7 人]、セル 1〜7 = 人 (**1 ページ 7 人**、ページ p のセル c は並びの添字 p × 7 + (c − 1))、セル 8 = [次の 7 人 ▶ (p+1 / 全ページ数)]。1 ページ目の [◀] と最終ページの [▶] は暗くして押しても何もしない。描画と押下は同じ対応表を使い、重複・欠落なく全員に届く。[人] へ切り替えたとき (`_TravelModePeople`) はページを先頭へ戻す。別の案 (上段か下段に ◀ ▶ を置く) は、上段 (トグル 2 つ + 切替 2 つ + [もどる] = 1062) も下段 (2 ボタン 500 + フッターの文) も余白がなく、採らない。
- **16 人の上限を外す**: `_joinIds` / `_joinBoxes` を 80 (VRChat のインスタンスの最大) にし、セルの部品は 9。`_JoinPick0..8` は上の対応表で並びの添字へ写す (9 人以下は添字 = セル番号)。並びの規則 (開いた時点の距離順で凍結、入室は末尾、退出は消す) は変えない。退出で最終ページが空になったら 1 つ前のページへ、選んでいる相手が別のページにいても選択は保つ。
- **フッターの文 (合流先 / 犬 N 匹 / 散歩先)** は、グリッドの帯にかかるので (今 y −150〜−46)、2 ボタンの左 (x −540〜−105、y −250〜−160、435×90) へ 3 行で移す (pt は実行時に変えない。18pt + 自動縮小 14pt。実装 2026-10-15)。[地点] のときは今の位置のまま。
- **セルの中身**: 1 行目 表示名 20pt (… で切る、補助フォントは今と同じ `KH_CourseTravelNameFontEditor` の対象)、2 行目 16pt (自動縮小 12pt。実装 2026-10-15)。今の 2 段目は「{地点}の近く  ここから N m」の**後ろ**に「(申し込みを受けていません)」「(準備中)」を足す (`KD_TreatPouch.Travel.cs:568-574`) が、幅 570 → 約 323 では状態が … に消えるので、**状態を優先**する: 受付 OFF・準備中・返事待ち・向かっているときは 2 行目を状態の文だけにし、地点と距離は通常のときだけ出す (色だけで受付 OFF と準備中を区別しない)。文言キーは今のもの (`join.near` / `join.notAccepting` / `join.waiting` / `call.onway`、準備中)。色 (返事待ち / 選択 / 受付 OFF・準備中 / 通常) も今のまま。**13 言語の収まりはセルの全状態と、移したフッター (相手名・着地点の理由を含む) を Course/81 の `Fit` で測る** (TMP の実測は未)。
- **変えないもの**: ボタン 2 つの文言・位置・寸法、申込中の「取り消す (N)」方式、受付トグル 2 つ、相手側の通知板、受付箱の契約 (同時 1 件、code2 / code3、30 秒)、`_TravelModePeople` の入口、同期変数 0 本。
- **翻訳キー**: 新規は「次の人 / 前の人」の 1〜2 キー (または記号 ◀ ▶ + 「n / m」だけにして 0 キー)。人数の見出し「このインスタンスにいる人 · N人」は、上段に余白が無いので採らない (人数は n / m で読める)。
- **失うもの (ユーザーの判断が要る)**: 2026-09-27 の決定「地図に出すのは選んでいる相手だけ」の輪が**なくなる**。輪は今のモードの選択 ([地点] なら地点、[人] なら相手。`KD_TreatPouch.Travel.cs:584-588`) を出すので、[人] で地図を隠すと相手の輪を見る手段は無い ([地点] へ戻しても地点の選択しか出ない)。モック自身が地図を外しているので同じ方向だが、決定を変えることになる (§7 の質問 1)。相手の居場所は 2 行目の「{地点}の近く  ここから N m」で読む。
- **人数の見出し**は採らない (上段に余白が無い)。ページ番号 (p / q) からは人数が分からないので、人数の情報を省く判断として記録する。
