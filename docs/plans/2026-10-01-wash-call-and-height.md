# 洗い場へ犬を呼ぶ・高さを調整する — 設計と実装の約束

> 対象: [IMP-DOG-035](../development/issues/IMP-DOG-035-wash-call-dog-to-station.md)、[IMP-ENV-011](../development/issues/IMP-ENV-011-wash-height-adjust.md)。親は [IMP-DOG-024](../development/issues/IMP-DOG-024-walk-and-wash-experience.md)、方式は [設計書](2026-09-30-dog-wash-design.md)

2026-10-01。ユーザーの PCVR 確認 (2026-09-30 夜〜10-01) の指摘から。**実装していない。** 値は試作値。

## 1. ユーザーの指摘と決定

- 洗いたい犬を洗い場へ連れて来る方法が難しい → **犬を選んで呼べる。呼んだら洗い場に来て立ち、洗い終わるまでそこにいる** (決定)
- 犬を洗うには上下の位置合わせが要る。PCVR は OVR などで自分の位置を動かせるが、それ以外は難しい → **台の高さを調整できる** (犬を上げる。背の高い人向け)。**自分用の見えない床を作り、その高さも調整できる** (自分が浮く。犬を上から洗える) (決定)

統括の既定 (違えば変える): 操作は各洗い場の棚の **ボード** に置く (犬 6 匹のボタン、おわり、台 ▲▼、自分 ▲▼)。手元メニューには足さない。

## 2. 体験の流れ

1. 洗い場のボードで犬のボタンを押す
2. その犬が洗い場へ来る (遠ければ近くへ現れてから歩く。既存の「呼ぶ」「合流」の作法に合わせる)
3. すのこの上に、棚と平行 (体の両側へ人が回れる向き) に立ち、留まる
4. 台 ▲▼ で犬ごと台が上下する (全員に見える)。自分 ▲▼ で自分の足もとの見えない床が上下する (自分だけ)
5. 「おわり」を押すと犬は台を下りて普段の行動へ戻る。台は元の高さへ下りる

## 3. 規則

| 事項 | 規則 |
|---|---|
| 1 つの洗い場に留まる犬 | 1 匹。別の犬を呼ぶと、前の犬は解放される |
| 呼べる犬 | リードを付けていない犬と、**呼んだ人が連れている犬**。他人が連れている犬は呼べない (拘束しない原則)。Fetch / フリスビーの最中・水の中の犬は、終わってから来る (5 秒待って来なければ「いまは来られない」) |
| 留まっている間 | Fetch・フリスビー・新しいリード接続は断る (洗われ中と同じ門)。体は回さない (決定済み)。頭の「たまに見る」と反応はこれまでどおり |
| 解放 | 「おわり」、別の犬を呼ぶ、集合・呼び戻し・ワープの明示的な要求、呼んだ人が退出、最後のストロークから 120 秒かつ呼んだ人が 10 m より遠い |
| 台の高さ | 0〜0.9 m、0.1 m 刻み。洗い場ごとに同期。犬がいない時は 0 へ戻る |
| 自分の床 | 0〜1.2 m、0.1 m 刻み。同期しない (自分だけ)。洗い場から 8 m 離れたら 0 へ戻る。動かす時は 0.5 m/s でなめらかに |
| 汚れ | 洗い場の 6 m 以内では汚れない (既存) |

## 4. 実装の約束 (担当間)

### `KH_WashStationCall` (新規 U#、洗い場ごと、`BehaviourSyncMode.Manual`)

洗い場のルートの子 `Call` に置く。Owner は奪わない (インスタンスのマスターのまま。犬の Owner と同じ想定で、違う時は犬のルートの Owner へ要求を回す)。

| 同期する値 | 内容 |
|---|---|
| `heldDog` (int) | 留まっている犬の番号 (0〜5)。無ければ -1 |
| `callerId` (int) | 呼んだ人の playerId |
| `lift` (float) | 台の高さ (m) |
| `arrived` (bool) | 犬が台に着いたか (着くまでは歩いている) |

| 配線する値 | 内容 |
|---|---|
| `stationIndex` | 0 = 主洗い場、1〜 = 道中 |
| `anchor` (Transform) | 犬が立つ点。台の上面の中心。`liftRoot` の子 |
| `liftRoot` (Transform) | 台 (すのこと、その Collider)。`lift` に合わせてローカルの y を動かす |
| `standYaw` | 犬が向く向き (棚と平行) |
| `dogs[]` (KD_DogWanderController、6) / `washes[]` (KH_DogWash、6) | 全犬 |
| `liftMax` = 0.9 / `liftStep` = 0.1 / `idleReleaseSeconds` = 120 / `callerFarMeters` = 10 | 調整値 |

| 入口 | 内容 |
|---|---|
| `ReqCall(int dog)` | `[NetworkCallable]`。Owner が規則 (§3) で受けるか決める。送り主は `NetworkCalling.CallingPlayer` |
| `ReqRelease()` | `[NetworkCallable]`。誰でも解放できる (呼んだ人でなくてもよい。困った時に戻せるように) |
| `ReqLift(int steps)` | `[NetworkCallable]`。±1 刻み |
| `_Call(int dog)` / `_Release()` / `_Lift(int steps)` | ボードのボタンが呼ぶローカルの入口 (Owner なら直接、違えば上の要求を送る) |
| `_HeldDog()` / `_Arrived()` / `_AnchorPosition()` / `_StandYaw()` / `_Lift01()` | 犬の側とボードが読む |
| `_ReleaseDog(int dog)` | 犬の側が、集合・呼び戻し・ワープの受理で呼ぶ (その犬を留めていれば解放) |

### 犬の側 (`KD_DogWanderController.HillsideWash.cs`)

- `public KH_WashStationCall[] washCalls;` (全洗い場)。毎フレーム、自分を留めている洗い場を探す (最大 4 個)
- 留められている時: 着くまでは既存の移動 (集合の「アンカーへ向かう」と同じ作法) で `anchor` へ。遠い (30 m 超) 時は既存の合流・ワープの作法で近くへ現れてから歩く。着いたら Owner が `arrived` を立てるよう洗い場へ知らせ、ルートを `anchor` の位置・`standYaw` に保つ (**台の高さへルートの y を書く**。地面への吸着は止める)
- 門: 留められている間は `WashHeld` と同じ扱い (Fetch / フリスビー / 新しいリード接続を断る)
- 集合・呼び戻し・ワープの受理のエッジで `_ReleaseDog`
- リード接続中で呼んだ人が持ち主の時: 留まる間はリードの追従を止め、解放で通常の追従へ

### `KH_WashPersonalFloor` (新規 U#、洗い場ごと、同期なし)

- `floor` (BoxCollider を持つ GameObject。5 × 0.1 × 5 m、見えない、プレイヤーが乗れる Layer)。台と棚の Collider とは重ならない高さの扱い (床が台より上へ行く時は台の周りだけ)
- `_Adjust(int steps)`: 0〜1.2 m。0 の時は無効。動かす時は 0.5 m/s。8 m 離れたら 0 へ
- 自分にだけ効く (各クライアントのローカルの Collider)

### ボード (ビルダー)

各洗い場の棚に World Space の Canvas。犬 6 匹のボタン (名前。顔の画像が既存にあれば使う)、おわり、台 ▲▼、自分 ▲▼、いまの状態 (誰を呼んだか、台の高さ、自分の高さ)。UI の作法は `vrc-world-ui` と `docs/world-ui-spec.md`。日本語のフォントは既存のものを使い、字形があるかを Verify で確かめる。
