# フリスビーの設定 (DES-UI-002) — 選ぶ / 自動・操作権・置き場所

2026-10-03 作成 (AI 設計案、ユーザー未確認)。Issue: [DES-UI-002](../development/issues/DES-UI-002-frisbee-settings.md)。関連: [IMP-DOG-008](../development/issues/IMP-DOG-008-frisbee-variations.md) / [IMP-DOG-012](../development/issues/IMP-DOG-012-frisbee-six-dogs.md) / [IMP-DOG-017](../development/issues/IMP-DOG-017-frisbee-intercept-solver.md) / [IMP-DOG-023](../development/issues/IMP-DOG-023-frisbee-anywhere.md)、[改修経緯](2026-09-21-frisbee-variations.md)、[どこでも投げる](2026-09-28-frisbee-anywhere.md)。

## 1. 結論 (推奨案)

- **曲げ (投げ方) は、投げる人が自分で選ぶ。** おもちゃタブの上段に [まっすぐ][曲げる] を置く。効くのは自分が投げるディスクだけで、ローカルの値なので同期しない。
- **取り方 (通常 / 並走 / ひねり) は、全部の犬に効く共有の設定として残す。** 押せるのはトレーナーだけ (今のまま)。置き場所も今の「あそぶ」タブの「フリスビーの取り方」の行のまま。
- **待つ場所は独立した設定にしない。** 待つ場所を変えるプリセットは「並走」しか残っていないので、取り方の 1 つとして扱う。
- **それ以外は全部自動にする。** 跳ぶ形 (下で待って跳ぶ・追って跳ぶ・正面から跳ぶ)、立ったまま取る、落ちてから拾う、を投げるたびに計画器が選ぶ (今のまま)。
- **受け取る側でもトレーナーかどうかを確かめる** (集合と同じ方式)。あわせて、連打処理の不具合を直す (§2.3)。開発用の切替は本番シーンにはもう無い。試作シーンの切替キューブは、ハーネス用に残す。

### 2.1 プリセット

`KH_FrisbeeCatch.cs` の L233-249 と、`ApplyVariant` (L672-701) を読んだ。

| 番号 | 表示名 | 変えるもの | 状態 |
|---|---|---|---|
| 0 | 通常 | 待つ位置: 持つ人の 8 m 前 | 使用中 |
| 1 | 走り込み: 横 | 待つ位置: 前 7 m・横 4 m | **2026-09-26 に引退** (`IsRetiredVariant`) |
| 2 | 走り込み: 遠く | 待つ位置: 前 11 m・横 1.5 m | **引退** |
| 3 | 走り込み: 並走 | 待つ位置: 前 4 m・横 2.5 m、前を向く。計画器が「追って跳ぶ」を優先する (`_overtake`) | 使用中 |
| 4 | ひねり | 取るときのクリップと口の位置 (`_twist`) | 使用中 |
| 5 | 横曲がり | 飛び方を右へ曲げる (`FlightCurve` = 0.07) | 使用中 |

- **値は犬ごとに持つ。** 各犬の `KH_FrisbeeCatch` (Manual) に `[UdonSynced] variant` / `pendingVariant` がある。「全部の犬に同じ値」になっているのは、メニューが 6 匹全部へ同じ値を頼んでいるからにすぎない。
- **書くのは犬の Owner だけ。**
  - 頼むときは `ReqVariant` (`NetworkCallable`) を使う。
  - 遊んでいる最中の犬は予約に回し、Idle に戻ったら反映する。
  - 途中参加した人には、同期値が `OnDeserialization` で届く。
- **曲げは投げる人の側で読む。**
  - `KH_Frisbee._Launch` (L209) が、投げた瞬間に `catcher.FlightCurve` を読む。
  - 読んだ値は `ReqCatch` の第 6 引数で犬へ送る。
  - **プレイヤーが投げるときに入れられるのは強さだけ** (VR 右スティック / ホイール)。曲げはプリセットでしか決まらない。
- **取り方は投げるたびに自動で決まる。** 計画器 (`KH_FrisbeeCatch.Planner.cs`、IMP-DOG-017) は、次の 3 つの形の中から物理的にできるものを点数で選ぶ。
  - 下で待って跳ぶ
  - 追って跳ぶ
  - 正面から跳ぶ

  どれもできなければ、立って取る → 回り込んで追い越す → 落ちてから拾う、の順に試す。プリセットが効くのは次の 3 点だけ。
  - 待つ位置
  - ひねりのクリップ
  - 並走のときに「追って跳ぶ」を優先すること

## 3. 提案

### 3.1 選ぶ / 自動 / 操作権

| 項目 | 誰が決めるか | 範囲・同期 | 置き場所 | 理由 |
|---|---|---|---|---|
| **曲げ** (まっすぐ / 曲げる) | 投げる人が自分で選ぶ | 自分が投げるディスクだけ。ローカルの値 1 つで同期しない。犬へは今の `ReqCatch` の引数で届く (同期変数は増えない) | おもちゃタブの上段 | 投げ方は投げる人の技術・好み。他人の遊びを変えない。手元で選べるので、トレーナーかどうかと関係なく使える |
| **取り方** (通常 / 並走 / ひねり) | トレーナーが選ぶ | 全部の犬・その場の全員に効く。既存の犬ごとの同期値に、6 匹同じ値を書く | あそぶタブ (今の行) | 犬の動きは全員から見える共有の状態。2026-09-24 のユーザー決定 (トレーナー用) を保つ |
| 待つ場所 | 取り方の「並走」に含める | — | — | 引退後は「通常」と「並走」の 2 つしか残っていない。並走は待つ位置と跳び方を一緒に変えるので、分けると意味がずれる |
| 跳ぶ形・立って取る・拾う・旋回・速さ | 自動 (計画器) | 犬の Owner が投げるたびに決める | — | 物理的にできるかどうかで決まる。選ばせても、できない形は選べない |
| 照準の × と「犬が行けない所」 | 自動 | ローカル | 照準 | DES-DOG-005 で実装済み。照準は「必ず取れる」という表示ではない、という点は看板 A と遊び方の文言に合わせる |

### 3.2 画面

**おもちゃタブの上段 (新規)**

```
投げ方   [ まっすぐ ] [ 曲げる ]        ← 選んでいる方を点灯 + 下線。押すと即切替
──────────────────────────────────────────
ボール・ディスクを手元へ (犬 6 行、今のまま)
```

- 寸法: 上段は y 164 の帯 (高さ 52)。ラベルは 22pt、ボタンは各 200×52 (20pt)。投げ方は帯の左半分 (540) に収める。右半分は、ボールの柄の選択 (DES-DOG-002、[質問](2026-10-03-open-questions.md) の 2) が採用されたときのために空けておく。
- おもちゃのスクロールの上端を 186 から 140 に下げる (呼ぶ・ライブ・かざりと同じ `ContentTopWithRow`)。犬 6 行は 2 列 × 3 段なので、そのまま収まる (376 ≤ 390)。
- 文言の新しいキーは 3 つ × 13 言語:
  - `toy.throw.label`「投げ方」
  - `toy.throw.straight`「まっすぐ」
  - `toy.throw.curve`「曲げる」
- 初期値は「まっすぐ」。保存しない (再入室で「まっすぐ」に戻る)。保存したくなったら、ナイトモードと同じ PlayerData の型を足す。
- 曲がる向きは右だけ。計画器とハーネスは正の値でしか確かめていないため (§5 の質問 3)。

**あそぶタブ「フリスビーの取り方」(今の行を整える)**

- 順に回す値を 0 → 3 → 4 → 0 (通常 → 並走 → ひねり) にする。横曲がり (5) はメニューの候補から外す。番号 5 自体は試作シーンとハーネスのために残す (§4)。
- 下の行を「全部の犬: {0}」にする (`activities.hillside.frisbeeNow` の文面の変更、13 言語)。こうすると、全員に効く設定だと分かる (Codex U1 の「共有設定であることの明示」)。犬ごとに値がずれている間は「全部の犬: 切替中」にする (F3。新しいキー `frisbeeMixed` 1 つ)。
- トレーナーでない人の表示は今のまま (暗くして「トレーナーになると使えます」)。

### 3.3 操作権の規則

1. メニューの段階で、トレーナーでない人は押せない (今のまま)。
2. **犬の Owner が `ReqVariant` を受け取ったら、`NetworkCalling.CallingPlayer` が `KH_TrainerPass._OwnedBy` を満たすか確かめる** (F1)。満たさなければ黙って捨てる (集合と同じ)。
3. Owner (通信の担当) を権限としては使わない。権限はトレーナー特典だけで決める。
4. 曲げはローカルなので、操作権は要らない。

## 5. ユーザーへの質問

1. **曲げは「投げる人が自分で選ぶ」(おもちゃタブ、自分の投げだけに効く) でよいか。** 推奨: はい。今は、トレーナーが全員の分を切り替えている。
2. **「取り方」(通常 / 並走 / ひねり) はトレーナー特典のまま、全部の犬に効く設定でよいか。** 推奨: はい。この回答で、仕様 (game-design §4) の「トレーナー特典は集合だけ」という書き方を「集合とフリスビーの取り方」に直す。看板には載せないまま (10-03 の決定どおり)。
3. **左にも曲げたいか。** 推奨: 初期公開は右だけ。左は、ハーネスに左の投げを足して通してから追加する。
