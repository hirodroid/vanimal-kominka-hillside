おさんぽカート 利用の流れ

一人乗りの自動散歩カート。乗り場で出発し、犬の散歩設定で道を進み、好きな所で降りられる。2026-10-12 時点 (M3 まで実装、Play 未確認の項目あり)。

全体像出発合流乗車中の操作停止と残るカート到着グループすれ違いワープ等との関係犬状態遷移決めた値

全体像

カートは 8 台。5 つの乗り場 (入口・広場・奥の広場・上流の橋・川辺) と、途中で降りて残ったカートが「乗り場」になる。

  S[乗り場のメニュー
5 地点] -->|出発| R[走行中]
  S -->|合流| R
  P[残ったカートのメニュー] -->|再開| R
  P -->|合流| R
  R -->|停止ボタン / ジャンプ| P
  R -->|目的地に到着| P
  R -->|ワープ・リスポーン・退出| P
  P -.->|乗り場で空車が無いとき
最古のカートを回収| S
  
乗り場のメニュー →(出発/合流)→ 走行中 →(停止・到着・ワープ等)→ 残ったカート →(再開/合流)→ 走行中。乗り場で空車が無ければ最古の残ったカートを回収。

行き先はさんぽの設定を共用

さんぽで選んだ目的地 (入口 / 広場 / 奥の広場 / 川辺) か周回 (順 / 逆) のまま走る。カート専用の行き先設定は無い。グループに合流したら、そのグループのマスターの設定に従う。

無料・全端末

犬がいなくても乗れる。PCVR・デスクトップ・Quest 単体・スマホを対象 (実機確認はこれから)。

降りるのは自由

停止ボタンでもジャンプでも降りられる。VR 酔いを感じたらすぐ降りる、が前提。

乗り場 0 (入口) の見本カートとメニューは地図ボードの奥 (広場側) にあり、出発点もその横。門の中へは入らない。

乗車中の操作

座席の左斜め前に操作帯、左横に手元メニューのドック、左前上に撮影モニターのドックがある。

高さ ▲▼座面の高さ ±30 cm (5 cm 刻み)。他の人の画面でも同じ

案内お手入れ道具の案内 (手元メニューを開く)

途中で止まる · 残ったカートが乗り場になる

停止 → 場所に応じて右へ寄せる (橋なら出口まで進む) → 降りる → カートが残りメニューが出る → 再開 / 合流 / そのまま。
  • 本人と本人の犬だけが離脱し、同じグループの他の人は走り続ける。
  • 自分がマスターなら、参加順が次の人にマスターが移る。行き先と受付状態はそのまま。
  • 残ったカートは別の置き去りカートと 1.6 m 以上離して停める。

目的地に着く

flowchart LR
  A[先頭が目的地の手前 0.5 m] --> B[グループは「到着中」
新しい合流は受け付けない]
  B --> C[各車は自分が目的地に着いた所で停車]
  C --> D[降車 · カートはその場に残る]
  D --> E[次は乗り場か残ったカートから]
  
先頭が目的地手前 → 到着中 (合流不可) → 各車が着いた所で停車 → 降車、カートは残る。

周回 (順 / 逆) は到着が無く、止めるまで続く。入口 (目的地 0) の到着点は門の前の曲線上 (門から約 8 m)。

グループとマスター

場面動き
出発自分 1 人のグループができ、自分がマスター。受付は ON
合流そのグループの末尾に入り、マスターの行き先・方向で走る。合流前の自分の設定は保持
受付 OFF以後の合流を止める。既参加者は残る。マスターが交代しても受付状態は引き継ぐ
マスターが降りる / 退出参加順が次の人へ。グループの行き先は維持し、新マスターの元の設定には切り替えない
最後の 1 人が降りるグループは解散
隊列通常は千鳥 (前後 3 m、左右 0.6 m 交互)。橋など一列の区間では一列

逆方向のグループとすれ違う

道は幅で 3 種類に分けてある。広い道 (千鳥可)、一列なら双方通れる道、一列でも通れない狭い区間 (橋 2 本・広場入口・門前)。

flowchart TD
  A[前方 25 m 以内に
逆方向のグループ] --> B[双方とも一列 · 右寄せ 0.55 m]
  B --> C{この先に狭い区間?}
  C -->|いいえ| D[そのまますれ違う]
  C -->|はい| E{相手が区間の中 or
自分より区間に近い?}
  E -->|いいえ| F[自分が先に通る]
  E -->|はい| G[区間手前の待機点で止まる
「すれ違い待ち」表示]
  G --> H[相手の最後尾が区間を出て 2 m]
  H --> I[自動で再開]
  G -.->|60 秒たっても解除されない| I
  D --> J[10 m 離れたら千鳥に戻る]
  F --> J
  I --> J
  
対向が 25 m 以内 → 双方一列・右寄せ → 狭い区間があれば先に入った側が優先、後の側は待機点で待つ → 相手が抜けたら再開 → 離れたら千鳥に戻る。
  • 待機は交通上の自動停止で、所属・行き先・マスター・受付は変わらない。
  • 狭い区間の中にある乗り場 (上流の橋) からは、対向が抜けるまで出発を保留する。
  • 同じ方向のグループどうしは対象外 (追い越しは無い)。

乗車中のワープ等 → 取消・失敗なら乗ったまま → 実行なら先に降車 (カートは残る) → 移動 → 残りのグループは継続。

犬

場面犬の動き
乗車中リードで繋いだ犬はカートの前 0.9 m・左右に並び、カートの速さに合わせて歩き続ける。一列の区間では左右を狭める。くん活・寄り道・休憩は始めない
待機 · 停車中カートの前で待つ。嗅ぐ・伏せは出ない
降りた後通常の散歩へ戻る
犬がいないそのまま乗れる
撫でる · おやつ乗車中も可 (特別な処理なし)

状態遷移 (カート 1 台)

stateDiagram-v2
  [*] --> Idle: 起動時 (駐車場に隠す)
  Idle --> Riding: 乗り場で出発 / 合流
  Parked --> Riding: 残ったカートから再開 / 合流
  Parked --> Riding: 乗り場で回収 (最古)
  Riding --> Ending: グループの先頭が目的地に到着
  Riding --> Parked: 停止 / ジャンプ / ワープ / リスポーン / 退出
  Ending --> Parked: 自分の車が目的地に着いて降車
  Parked --> Parked: 誰でも使える乗り場として残る
  
Idle →(出発/合流)→ Riding →(先頭が到着)→ Ending →(各車が着いて降車)→ Parked。Riding →(停止・ワープ等)→ Parked。Parked →(再開/合流/回収)→ Riding。

グループ側: Free → Running (出発) → Ending (先頭が到着) → Free (全員が降りる)。待機中 (hold) と車線 (千鳥 / 右寄せ / 中央) は Running の中の属性。
