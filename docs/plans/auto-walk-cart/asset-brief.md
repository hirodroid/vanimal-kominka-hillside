# おさんぽカート 外観提案 v0.1

## 目的・用途と見た目

対象は古民家の裏山、[DES-WLD-004](../../development/issues/DES-WLD-004-auto-walk-cart.md)。2026-10-11依頼により、Unityを操作せず外観のデザインと[HTMLレビュー](design-v1.html)を作成。主分類 FIXTURE、追加タグ near_view / repeated / networked。**提案、ユーザー採用前**。ブラウザ内の簡易形状であり、製品モデルではない。

方針の正本は[core-concept §3](../../core-concept.md)。落ち着いた秋の里山、犬が主役、低光沢、密度を上げず輪郭を整える。今回の役割は座れる道具と操作の伝達。近距離の肘掛け・座面、前方の犬、後続から見る背面を比較する。既存ワールドでの確認は未実施。

推奨A「里山の椅子」は木の肘掛け＋分割した布の背クッション。B「こもれびポッド」は低い側板、C「山道のベンチ」は細いフレームと木の背板。屋根・ハンドルを置かず、足元が低い四輪式を提案。四輪式自体も外観案であり採用前。

## 対象と予算

PCVR・デスクトップ・Quest単体・Android/iOS。カートの対応方針は決定済み、動作未確認。最短視距離は手元0.2〜0.4m程度を仮定。同時台数はUNKNOWN、まず単独と3台で形状比較、これを最終上限としない。

BASELINE: 1台LOD0 4,000三角形以内、LOD1 1,500以内、本体1材質＋差替掲示1材質、共通アトラス1,024px。四輪・近距離で見る椅子の丸みを含め、設備の一般予算より輪郭に配分する。超過時は車輪分割数・見えない底面・フェンダーを見直す。UI、犬、アバター、リード、同期処理の予算は別途。HTML表示用の面数をFBX実測として扱わない。

## 形状・寸法と作り方

BASELINE、単位m: 全幅0.82 / 全長1.20 / 全高約1.05 / 座面高0.50 / 床面約0.22 / 座面幅0.52・奥行0.46 / 車輪径0.28。肘掛け上面約0.75。乗り口は左右の肘掛け前方。丸い角・座面厚・フェンダーをメッシュ、細かい縫い目・木目・タイヤ溝をテクスチャへ。HTMLの面取りは外観検討用。

本制作はlow-first候補。原点は車体中央の地面、Unity側は+Y上/+Z前。四輪は各車軸中心を原点に分離。Colliderは単純形状を候補にし、犬の通路や乗降を塞がないよう実装設計と照合。地形追従・走行方式をモデル形状で決めない。

## 接続点・可動・適合

座席アンカー、左右降車位置の候補アンカー、左右の犬同行接続点候補、肘掛け前端の操作面、背面の差替案内面を用意する案。手放しの犬同行の接続仕様と既存リードの関係は後続設計。スケルトン不要を初期案とし、四輪の回転軸を分離する。左右の参考接続点は一台2匹の上限を意味しない。

着座人物は寸法参照の簡易形状、犬も1匹の参考形状。既存6匹のモデル変更・複製は行わない。アバターサイズ・小型犬/大型犬・左右の乗降位置の適合はUNKNOWN。一般的な人物で合うだけでは全アバター適合としない。

## 材質・UV・テクスチャ

提案の主配色は苔色車体 `#53634e` / 麦色布 `#bd9a69` / 褐色木 `#92714b`。比較配色は砂と若葉、土と生成り。既存ワールド全体のパレットを変更するものではない。ベース色と低光沢、必要部分のNormalを共有アトラスへ。掲示面は後から内容を交換可能にする。UV・ベイク・端末別シェーダー選定は本制作時に具体化、現段階は未作成。透明材質や実時間発光を必須としない。

## ファイルと引き渡し

- `design-v1.html`: 外部依存なし。造形3案・配色3案、回転/定点視点、犬/人物/注釈、隊列模式図、レビュー用メモの保存。ローカルで直接開ける。
- 本票: 制作意図と仮仕様。採用済みの動作要件は親Issueが正本。
- 現時点はHTML内JavaScriptがプレビュー形状の生成原本。Blender原本・FBX・Unity Prefabは未作成。採用後に本制作の原本と書き出し手順を決める。

UnityのAssets以下へファイルを置かず、Editor/API/Play/インポートを操作しない。HTMLのCanvasは閲覧用。材質・照明の実機確認は別工程。

## 参照元と権利

ユーザーの要件、プロジェクトのコアコンセプトから形状を設計。特定の商品写真・購入モデル・外部画像・外部ライブラリは不使用。木の肘掛け、椅子、四輪という一般構造を、HTML内の自作手続き形状として作成。犬・人物も簡易自作形状。生成担当Codex、2026-10-11、目的はローカルでの外観レビュー。採用前に対象版の輪郭と素材表現を確認する。第三者作品との網羅的な照合は行っていない。

## 仮決め・未確定

造形・配色・寸法・材質・案内面の大きさ・予算はすべて提案。正式名称、道路のクリアランス、最大台数、犬数、乗車姿勢、リード接続は未確定。停止操作面は場所を示す仮形状で、全端末入力の実装仕様ではない。広告本文や価格は含めない。

通常は千鳥走行、一列は一時的で会話・視認性低下を許容する決定を保持。隊列図は配置イメージであり、実寸道路や安全な車間の検証ではない。目的地・周回・合流のUI全体はこの外観レビューの対象外。

## 確認結果

2026-10-11、ローカルのヘッドレスChromeでHTMLを確認。1440×1100と390×844の表示幅で横はみ出しなし、JavaScript例外なし。造形3案・配色3案・5視点・犬/人物/注釈表示・隊列切替・メモ生成とテキストダウンロードを確認した。デスクトップ、スマホ幅、参考人物と犬、案の比較、寸法図の画像を目視した。これはPCブラウザでの表示確認であり、スマホ実機・VRChatでの検証ではない。

独立担当（U利用者/Vビジュアル/M文書）がHTML・制作票・要件と画像を確認し、修正必須の指摘なし。文書担当のセルフ確認とは区別する。全幅0.82mと床面約0.22mへプレビューを合わせ、注釈と参考人物の足裏位置も調整後にブラウザ確認を再実行した。確認のローカル記録は `artifacts/cart-design-review/` にある（自動検査スクリプト・checks.json・画像。制作原本には含めない）。

モデル実測、Blender、Unity、ワールド内配置、VRChat全端末は未確認。単体プレビューから実機品質を合格としない。
