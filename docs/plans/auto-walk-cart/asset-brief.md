# おさんぽカート 外観提案 v0.1

## 目的・用途と見た目

対象は古民家の裏山、[DES-WLD-004](../../development/issues/DES-WLD-004-auto-walk-cart.md)。2026-10-11依頼により、Unityを操作せず外観のデザインと[HTMLレビュー](design-v1.html)を作成。主分類 FIXTURE、追加タグ near_view / repeated / networked。**提案、ユーザー採用前**。ブラウザ内の簡易形状であり、製品モデルではない。

方針の正本は[core-concept §3](../../core-concept.md)。落ち着いた秋の里山、犬が主役、低光沢、密度を上げず輪郭を整える。今回の役割は座れる道具と操作の伝達。近距離の肘掛け・座面、前方の犬、後続から見る背面を比較する。既存ワールドでの確認は未実施。

推奨A「里山の椅子」は木の肘掛け＋分割した布の背クッション。B「こもれびポッド」は低い側板、C「山道のベンチ」は細いフレームと木の背板。屋根・ハンドルを置かず、足元が低い四輪式を提案。四輪式自体も外観案であり採用前。

## 対象と予算

PCVR・デスクトップ・Quest単体・Android/iOS。カートの対応方針は決定済み、動作未確認。最短視距離は手元0.2〜0.4m程度を仮定。同時台数はUNKNOWN、まず単独と3台で形状比較、これを最終上限としない。

BASELINE: 1台LOD0 4,000三角形以内、LOD1 1,500以内、本体1材質＋差替掲示1材質、共通アトラス1,024px。四輪・近距離で見る椅子の丸みを含め、設備の一般予算より輪郭に配分する。超過時は車輪分割数・見えない底面・フェンダーを見直す。UI、犬、アバター、リード、同期処理の予算は別途。HTML表示用の面数をFBX実測として扱わない。

## 形状・寸法と作り方

BASELINE、単位m: 全幅0.82 / 全長1.20 / 全高約1.05 / 座面高0.50 / 床面約0.22 / 座面幅0.52・奥行0.46 / 車輪径0.28。肘掛け上面約0.75。乗り口は左右の肘掛け前方。丸い角・座面厚・フェンダーをメッシュ、細かい縫い目・木目・タイヤ溝をテクスチャへ。HTMLの面取りは外観検討用。

本制作はlow-first候補。原点は車体中央の地面、Unity側は+Y上/+Z前。四輪は各車軸中心を原点に分離。Colliderは単純形状を候補にし、犬の通路や乗降を塞がないよう実装設計と照合。地形追従・走行方式をモデル形状で決めない。

## 接続点・可動・適合

座席アンカー、左右降車位置の候補アンカー、左右の犬同行接続点候補、肘掛け前端の操作面、背面の差替案内面を用意する案。手放しの犬同行の接続仕様と既存リードの関係は後続設計。スケルトン不要を初期案とし、四輪の回転軸を分離する。左右の参考接続点は一台2匹の上限を意味しない。

着座人物は寸法参照の簡易形状、犬も1匹の参考形状。既存6匹のモデル変更・複製は行わない。アバターサイズ・小型犬/大型犬・左右の乗降位置の適合はUNKNOWN。一般的な人物で合うだけでは全アバター適合としない。

## 材質・UV・テクスチャ

提案の主配色は苔色車体 `#53634e` / 麦色布 `#bd9a69` / 褐色木 `#92714b`。比較配色は砂と若葉、土と生成り。既存ワールド全体のパレットを変更するものではない。ベース色と低光沢を共有アトラスへ。掲示面は後から内容を交換可能にする。UV・ベイク・端末別シェーダー選定は本制作時に具体化、現段階は未作成。透明材質や実時間発光を必須としない。

### 第3回レビュー後の方針 (2026-10-11、採否はユーザー判断待ち)

[Issue の第3回多角ロールレビュー](../../development/issues/DES-WLD-004-auto-walk-cart.md)で9担当が一致した方針。**形は簡素のまま (LOD0 4,000以内で輪郭と縁の質だけ上げる)、表面は BaseColor 1枚への書き込みでリッチにし、小物は増やさない。** 書き込みは「容量が変わらない」範囲に収める。

- **容量の前提**: BaseColor 1,024px 1枚を全端末 (PC / Quest / Android / iOS) の基準にする。この範囲では AO・摩耗・木目・縫い目を描き込んでも GPU メモリは変わらない (ASTC 6x6 mip込み約0.6MB、PC BC7 約1.3MB。一般値からの計算、CHECK)。ダウンロード容量は描き込みで少し増える (推測)。Normal (+0.6〜1.3MB)・2,048px化 (4倍)・アルファ (2倍)・配色別アトラス・台別の掲示画像は容量が増えるので既定にしない。PC 向け Normal は近距離サンプルで効果を見てから判断する。
- **texel 密度と UV 配分 (BASELINE)**: プレビュー A案の表面積は約8.45m² (隠れ面込み)、見える面は約5m²、左右ミラーと四輪共有後の固有面積は約2.5〜3m²。1,024px を均等に割ると約3〜5px/cm で、0.3m で見る肘掛けは画面上で約40〜48px/cm (Quest 3 の20〜25px/度、推測) になり 6〜10倍に引き伸ばされる。配分: 肘掛け上面・前端 (左右ミラー、約100×560px)、座面前縁、停止操作面 (約128²)、足置きの縁に約10〜16px/cm (アトラスの10〜45%)。木目と布はトリム帯にして U 方向に繰り返す。底面・内側は UV を割かず、車輪は1個分を共有する。銘と左右非対称の摩耗だけ重ねない島に置く。座面上面と背当ての前面は座った人に隠れるので低密度でよい。充填率75〜85%で収まる見込み (CHECK)。
- **描く内容 (視距離別)**: 近 (0.2〜0.4m、本人): 肘掛けに太い木目の帯3〜4本と手擦れの明るみ、座面前縁に6〜8mm幅の深緑パイピングと3〜5mmの縫い目 (暗線+明線の組)、停止操作面はアイコンと形だけ (13言語のため文字は焼かず UI 側)、足置きに板目と靴擦れ。中 (0.6〜1m): 側板のパネル線2本、塗装の角の薄い摩耗、フェンダー縁の明るい線、座面下・背の境・肘掛け下・フェンダー内側の向きの無い AO。遠 (2〜4m、後続): 背面の木枠、小さな銘、太いタイヤ溝3本程度。日差しの向きが付いた陰影は焼かない (走行中に向きが変わり、ライトプローブだけで照らされる見込み)。細かい織り目は mip でモアレになるので玉縁とステッチで表す。車輪に焼く陰影は放射状だけ。Normal 無しでは1texel≈1mmなので3mm未満の線は描かない。
- **木の表現**: LMArt 寄りの温かいスタイライズで、油仕上げの木目・板割り・木口を描く。既存の `BridgeWood.png` (風化した杉の灰褐色、写実寄り) は、この密度では細い木目が潰れ古びた印象になり、タイル前提で材質数も超えるので流用しない。明度は BridgeWood に寄せて世界になじませる。Blender の手続き木目を焼き込めば再出力できる。
- **配色**: 「土と生成り」の車体 `#975f48` は赤茶の犬、「砂と若葉」の車体 `#c2b49b` はクリーム・白の犬と黄土の地面に同化する (core-concept §3)。「苔と麦」に絞る案を推奨。布 `#bd9a69` もタンの毛色に近いので少し灰緑へ寄せるか、前縁のパイピングで切り分ける。犬の高さ (0〜0.4m) は緑と墨色にし、背面中央に墨緑か生成りの面を置く。毛色はマスターが購入パック内で切り替えるため、赤茶・白・黒白・クリーム・タンの範囲で避ける。採用後は材質・テクスチャを正本にし、文書は HEX を転記せずファイル名で参照する。
- **ブランド色**: 車体は景観パレット、ブランド色 ([指針案](../../../../../vrc-asset-lab/assets/wash-premium/design/2026-10-08/brand-direction.md)) は操作面の縁・案内面の枠・銘だけで5%以下。銘は「VAnimal」の名称表記を焼印風に背板の下隅か側面前に一か所 (幅約50mm、専用 UV 島)。新ロゴにしない。
- **原本の持ち方**: 色の層と明度の層 (木目・織り・摩耗・AO) を分けて作り、配色変更でアトラスを出し直さずに済む書き出し手順を記録する。差替材質には背面・手元の2枠の型紙 (比率・px・余白) を固定し、価格は画像に焼かない。掲示は写真主体+10字以内1行、512×256程度で足りる見込み (推測)。
- **造形の微修正 (三角形はほぼ増えない、本制作時)**: 材質ごとに縁の厚みを変える (布は天面を8〜10mm盛ってパイピング、木は R10〜15 の丸面取り、塗装は小さい R)。座面台を座布団より引っ込めて影の溝。フェンダーは車輪に沿う弧で縁10mm・隙間20〜30mm (現プレビューは車輪に3cm食い込む)。タイヤは16分割で肩2段、内側面を省き、ハブは暗く小さく。支柱の根元に座金、肘掛け下に受け金具。背板は見える厚さ25〜30mmでゆるく湾曲。案内面は背板に埋め込む額縁 (現プレビューは19〜29mm浮く)。停止操作面は左右対称に置き目へ傾け、凸ボタンはメッシュ。車輪は前後2軸にまとめ、本体材質で GPU Instancing を使う。

HTML のプレビューは面ごとの平板な陰影 (明度幅0.62〜1.0) で AO・艶の差が無く、質感の判断には使わない。簡素/リッチの最終判断は、A案1台を Blender で粗形状+AO 焼き込み+仮テクスチャ (木目帯・パイピング・操作面) で描画した画像1枚で行う。先に肘掛け・停止面・座面前縁だけのサンプルを0.3mで PCVR → Quest の順に見る。HTML 内では木の色が model() `#92714b` と寸法図 SVG `#876a48` で食い違っており、採用時に材質側へ統一する。

## 確認結果

2026-10-11、ローカルのヘッドレスChromeでHTMLを確認。1440×1100と390×844の表示幅で横はみ出しなし、JavaScript例外なし。造形3案・配色3案・5視点・犬/人物/注釈表示・隊列切替・メモ生成とテキストダウンロードを確認した。デスクトップ、スマホ幅、参考人物と犬、案の比較、寸法図の画像を目視した。これはPCブラウザでの表示確認であり、スマホ実機・VRChatでの検証ではない。

独立担当（U利用者/Vビジュアル/M文書）がHTML・制作票・要件と画像を確認し、修正必須の指摘なし。これは v0.1 の表示・文書の確認であり、2026-10-11 の第3回多角ロールレビュー (簡素/リッチとテクスチャ) では造形・配色・texel 密度に高優先の指摘が出ている。現在の指摘は「材質・UV・テクスチャ」節の第3回レビュー後の方針を正とする。文書担当のセルフ確認とは区別する。全幅0.82mと床面約0.22mへプレビューを合わせ、注釈と参考人物の足裏位置も調整後にブラウザ確認を再実行した。確認のローカル記録は `artifacts/cart-design-review/` にある（自動検査スクリプト・checks.json・画像。制作原本には含めない）。

モデル実測、Blender、Unity、ワールド内配置、VRChat全端末は未確認。単体プレビューから実機品質を合格としない。
