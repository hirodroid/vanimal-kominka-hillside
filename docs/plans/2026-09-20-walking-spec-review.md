# 散歩仕様の受領・優先順整理 — レビュー記録

対象は後から受領した [散歩企画資料](../reference/VAnimal_KominkaHillside_Walking_Addendum.md) の反映と関連文書の整合。ユーザー指定により、この資料を旧資料・以前の会話・試作より優先する。犬の実装や最終設計のレビューではない。

`vrc-codex-review` に従い、独立した担当 U (来訪者)、D (開発)、M (保守)、X (UX)、P (PM)、V (見た目・情報設計) が文書を確認。親担当が指摘を現物で確認して修正した。

| 指摘 | 担当 | 対応 |
|---|---|---|
| 地形方式の「Terrain / Blender 未決定」が後資料と不一致 | P / M / D | Terrain で制作する方向、最終採用の性能検証は未了と統一 |
| M2b が工程表の外にある | P / M / D | M2 と M3 の間へ統合 |
| 移植完了条件が旧項目名を参照 | M | 現行の屋外休憩・既存の飾り・トレーナー機能へ修正 |
| 絡まり・引っ張り合いを「中心にしない」では弱い | U / X / V | 「シミュレーションしない」に統一 |
| 門前スポーンを最終の決定事項に見せている | X | 現在の v4 試作の配置と明示 |

そのほか、片手 3 匹・合計 6 匹、操作・同期・競合などの未決定扱い、未実装・未検証の区別、移植とリード実装の分離は問題なし。見た目の統合合格や実機動作を今回確認したわけではない。

検査: ドキュメントリンク、Issue の整合、文書差分の空白検査に合格。移植・リード実装・Play は未実施。
