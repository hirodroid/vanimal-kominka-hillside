## 1. 誰に、どんな体験を届けるか

古民家ドッグランに来てくれた人へ。**同じ 6 匹と、秋の裏山へお散歩に行く**。
山道を歩き、犬と遊び、景色のよい場所で休み、遠くに見える古民家を眺めて「あそこから犬たちと来た」と感じてもらう。
PC に加え Quest 単体・iOS でも楽しめることを目指す。古民家だけでも遊びが完結し、もっと楽しみたい人には散歩先がある関係にする。別ワールド化は負荷を配分する制作上の選択で、同一ワールドで不可能と確認した結果ではない。

主目的は新しいバズではなく、古民家で作った犬との思い出を増やすこと (原本 §2)。

## 2. 体験の核と判断基準

| 項目 | 内容 |
|---|---|
| 主役 | 古民家ドッグランと同じ 6 匹 (コーギー / ポメラニアン / ラブラドール / ダックスフンド / 柴犬 / サモエド)。景色は主役を引き立てる背景 |
| 絶対に外せない体験 | 山から古民家が見える / 犬と無理なく遊べる / 小さな空間でも「散歩した」感じがする — 原本 §9 の優先 3 点。**並列で優劣を付けない** |
| 場所のつながり | 山から古民家を見返し「あそこから来た」と感じる。地理を厳密に合わせるより、同じ犬との過ごし方が増えることを優先。現在の試作は門前から出発する配置で、コース形状などの最終仕様は未確定 |
| 既存機能の流用 | 撫でるなどは古民家を土台にし、おもちゃは残す方向。首輪・リードを加える。屋外休憩の動作、既存の飾り・トレーナー機能の範囲は未確定 |
| 散歩の中心 | 気に入った犬と少し歩き、遊び、休む。片手 3 匹・合計 6 匹までリードでつなぎ、手を基準とする範囲内で自然に動く。2026-09-20追加相談で、犬が目的地へ行きたがり、寄り道・待機・人への誘い・犬同士の遊びをする自主性を重視すると具体化。常時前方へ整列させることを目的にしない。操作の難しさを中心にせず、絡まり・引っ張り合いはシミュレーションしない。具体仕様はgame-design §4 |
| 成功の観測 | 古民家を見返せる / 犬と歩き遊べる / コースから端の切れ目が見えない / PC・Quest 単体・iOS の実機で快適さを確認する。未検証を対応済みとしない |
| 避けたい体験 | Terrain の切断面や空白が見える / 草木が密で犬を見失う / 散歩道が迷路になる / 新ギミックの説明を読まされる |

判断に迷ったら「犬と一緒に過ごす続きの場所か」で決める。豪華さは草木の密度ではなく、眺め・道・犬とのふれあい・古民家とのつながりで作る (原本 §6)。

## 3. ビジュアル方針

- 状態: **仮決め** (2026-09-19。代表シーン未検証)
- 更新日: 2026-09-19
- 判断の根拠となる体験: §2 の 3 点 + 古民家ドッグランの秋の庭 (IMP-ENV-016) との連続性
- 主要アセット候補と制約:
  - **採用済み (導入済み)**: LMArt-StylizedEnvironmentKit `BroadleafTreeField` — 古民家ドッグランで使っている広葉樹 (`BroadleafTreeB01`) と遠景 `ViewSet01` の元。秋色は古民家側で作成済みの `Assets/KominkaDogRun/{Materials,Textures}/Environment/Autumn/` を `.meta` ごとコピーして GUID 維持で流用する (OurUsualPark で実績)
  - **候補 (未導入)**: Autumn Valley - Level とその依存アセット (ユーザー所有済み)。必要な木・岩・素材だけ選ぶ。完成シーンの丸ごと使用はしない
  - **候補 (未決定)**: 遠景の古民家。モサンゴ屋「庭付き古民家」の外観だけを軽量化して置くか、遠景用の簡略モデルを作るか。「あの場所だ」と分かる屋根・建物の形は残す
  - 地形: Unity Terrain で制作する方向。最終採用の性能検証は未了 (→ `DES-ENV-001`)

### 印象・形・素材・光

| 項目 | 方針 | 確認する条件 |
|---|---|---|
| 目指す印象 / 避ける印象 | 身近で落ち着いた秋の里山。昼の明るさ。避ける: 観光地的な絶景・密林・荒野・ホラー寄りの薄暗さ | 展望場所と広場で、古民家の庭の続きに感じるか |
| 主役と背景 / 情報の強弱 | 犬が主役。地面・草・葉は彩度を抑えた黄土〜くすんだ橙で一様にせず、犬の顔・輪郭とボールが浮くようにする (古民家の秋方針を継承) | 広場で 6 匹 + ボールを 3 m / 10 m から見て見失わないか |
| 形・デフォルメ / 細部の密度 | LMArt の広葉樹に合わせたスタイライズ。木・岩・草は詰め込まず、見通しを優先。遠景ほど簡略化 | 散歩道から次の目的地 (休憩場所・広場) が見えるか |
| 素材感 | 非金属・低光沢。土の道と草地の境界を素材で読ませる (道はテクスチャで明示) | 道を外れずに広場へ着き、門へ戻れるか |
| 光 / 明るさ・色味・影 | 昼・暖色寄りの日差し。古民家と同じ「昼下がり」。影は落とすが暗部は作らない | 木陰でも犬の顔が読めるか。古民家の見返しが逆光で潰れないか |
| UIへの展開 | 古民家と同じ暗い面 + 白文字。リード接続・左右選択・解除に必要な操作を設計する。具体的 UI は未確定 | 端末ごとの操作と可読性 (`world-ui-spec.md`) |

### 役割別パレット

古民家ドッグランの秋色資産 (IMP-ENV-016) をそのまま継承する。値はコピー元の材質・テクスチャが正本で、ここへ HEX を転記しない。

| 役割 | 色・値または範囲 | 使用対象・組み合わせ | 避ける使い方 |
|---|---|---|---|
| 背景になじませる | 黄土・枯草色 (地面・草)、黄〜くすんだ橙 (葉・遠景植生)。岩・空は元の色 | Terrain / 草 / 広葉樹 / 遠景 | 一様な赤茶や強い黄色で埋める。犬の毛色 (赤茶・白・黒白・クリーム) と同化する色 |
| 主役・発見対象を目立たせる | 犬の既存材質 (変更しない)。ボール・おもちゃは古民家と同じ色 | 犬 / 遊べる小物 | 背景色をおもちゃに流用する |
| 操作・状態を伝える | 古民家の UI トークンを継承 | メニュー / 案内 | 色だけで状態を伝える |
