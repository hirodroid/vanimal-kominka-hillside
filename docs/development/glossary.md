## Issue の ID 体系

`{種別}-{システム}-{3桁}` (例: `IMP-GM-001`)。
採番は必ず `node scripts/check-issues.js --next` で行う。

**種別**

| 記号 | 意味 |
|------|------|
| `BUG` | 現在仕様どおりに動かない |
| `IMP` | 現在仕様をより良くする |
| `DES` | 設計自体を見直す |
| `VER` | 数値や体験を検証する |

**システム** (このワールドに合わせて決める。2〜3 文字の大文字)

| 記号 | 対象 |
|------|------|
| `GM` | ゲーム進行 |
| `UI` | UI 全般 |
| `NET` | 同期全般 |
| `WD` | ワールド空間 |
