## システムの語

| 語 | 意味 |
|----|------|
| 移植 (ポーティング) | 古民家ドッグランの実装を一式コピーし、以後この側で個別管理すること。自動同期はしない |
| 秋色資産 | 古民家側で作った LMArt 派生の秋用材質・テクスチャ。`.meta` ごとコピーして GUID を維持する |
| 範囲制限 | プレイヤー・犬が歩ける範囲の外へ出ないための実装 (柵の Collider など)。視覚上の境界とは別 |

## Issue の ID 体系

`{種別}-{システム}-{3桁}` (例: `IMP-GM-001`)。
採番は必ず `node scripts/check-issues.js --next` で行う。

**種別**

| 記号 | 意味 |
|------|------|
| `BUG` | 現在仕様どおりに動かない |
| `IMP` | 現在仕様をより良くする |
| `DES` | 設計自体を見直す |
| `VER` | 数値や体験を検証する |

**システム** (このワールドに合わせて決める。2〜3 文字の大文字)

| 記号 | 対象 |
|------|------|
| `ENV` | 地形・植生・遠景・照明 (舞台) |
| `DOG` | 犬ギミック (移植と改修) |
| `INF` | 基盤・ビルド・プラットフォーム・性能 |
| `UI` | UI 全般 |
| `NET` | 同期全般 |
