# KominkaHillside -- 開発全体像

> マイルストーンの進捗と完成条件の正本。**現在地はここを見れば分かる**状態に保つ。

---

## 1. 方針

- **品質 > 期日。** 初期構想の「1 週間程度」は固定納期ではない (Terrain 制作とスマホ検証で改めて判断)
- **スコープは広げない。** 古民家の続きの場所 + 同じ 6 匹 + 既存ふれあい + 首輪・リードの散歩 + 遠景の古民家。ユーザーが追加したおもちゃ・補助UI・集合・ライブの範囲は `game-design.md` §4・7で管理する
- **まず少ない構成で成立を確かめる。** 描画負荷と犬の移動・遊びが試作で成立してから本制作に入る

## 3. 現在地

**現在は「自由な散歩と本制作の首輪・リードを PCVR で確認できたプロトタイプ」 (`f25de23`)。公開品質はまだ未達。** 2026-09-20、周囲追従の試作が「非常に面白い」と評価された後、同日に目的地と通過点による自由な散歩・ボールの広場配置・首輪とリードの本制作を実装し、ユーザーの PCVR で「かなり良かった」「首輪とリードはあれでいいレベル」との報告を受領した。続けて手元メニュー (さんぽ / あそぶ / おもちゃ)・リード拠点・集合・ボール回収を実装し Editor 検査済み (Play 待ち、[記録](../plans/2026-09-20-menu-gather-stations.md))。2026-09-21 にフリスビー (ラブ 1 匹・広場限定・照準モード) を本シーンへ導入し PCVR 1 人で好評 ([記録](../plans/2026-09-20-frisbee-prototype.md))。**2026-09-22 にユーザーが PCVR で手元メニューと空・ナイトモードを確認し、地形は Unity Terrain 採用で確定** (DES-UI-001 / IMP-ENV-002 / DES-ENV-001 / VER-ENV-001 完了)。**2026-09-22 にユーザーが 6 人 PCVR で散歩し、複数人の競合・退出・途中参加は成立** (総合評価。項目別の合否は未記録) して IMP-DOG-002 は完了。Quest 単体・iOS は一度も実機に載せておらず [VER-WLD-001](issues/VER-WLD-001-quest-ios-devices.md) に集約、境界の項目別確認は未了のまま残る。証拠の正本は [自由な散歩の記録](../plans/2026-09-20-free-walk.md) と [制作票](../plans/2026-09-20-leash-asset-production.md)。

#### 以前の整理 (2026-09-20 PCVR具体報告を反映)

その後のユーザー依頼により、首輪・リードのBlender本制作 (IMP-DOG-004) とおもちゃの候補提案を実施。モデル9個と共通材質をUnityへ反映・保存し、Editor検査74+56項目合格。新モデルのPCVR・Quest/iOS確認待ち。[制作票](../plans/2026-09-20-leash-asset-production.md)を参照。モデルのリリース品質を目指し、単体モデルと犬の動作中の適合・ワールド内操作を両方確認する。下表は引き続き機能改善の順序として使う。

ユーザーが最優先としたのはリード操作・犬の動き。具体的には犬が後ろに隠れること、首輪のずれ、ボールの初期落下を改善する。接続/解除・伸びる紐・既存の犬の動作・広場の遊びは好評なので維持する。景観は今くらいの軽い構成でよく、犬との体験を先に磨く。[報告と先行設計案](../plans/2026-09-20-pcvr-feedback.md)。
