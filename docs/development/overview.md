## 1. 方針

- **品質 > 期日。** 2026-09-30ユーザー指定の目標は、開発完了2026-10-03〜04ごろ、公開2026-10-10〜11ごろ（公開を1週間後ろへ変更済み）。今週中に洗う体験の核を組み込み、公開までを実機テスト・Quest単体／スマホ確認・負荷調整・バグ修正のバッファにする。目標日と検証完了は区別し、難点が出た場合は公開範囲と日程を再判断する
- **採用した範囲に集中する。** 古民家の続きの場所 + 同じ6匹 + 既存ふれあい + 首輪・リードの散歩 + 遠景の古民家。ユーザーが追加したおもちゃ・補助UI・集合・ライブ・散歩帰りのお手入れの範囲は `game-design.md` §4・7で管理する
- **まず少ない構成で成立を確かめる。** 描画負荷と犬の移動・遊びが試作で成立してから本制作に入る

### 性能と検証の最新状況

- **Quest 3 の実機確認は開始済み。** 09-30の10〜20 fps報告から地形・描画・Udonを切り分け、[IMP-DOG-034](issues/IMP-DOG-034-dog-udon-tick-thinning.md) で段階的に削減。10-02のC-1＋C-2版では入室直後が約40 fps、6匹リード散歩で20〜30 fpsへ落ちることはほぼ無くなったとのユーザー報告。ただし6匹が同時に川へ入ると20台まで低下。この値は特定の版・条件での報告で、Quest／iOS全体の合格ではない。
- **C-2の採用分は実装済み。** 初期汚れは既定・ビルダー・シーンとも0。汚れの反映20秒、汚れの速さの調整、同じ持ち手の犬同士の押し出し除外、1分平均fpsによるロープ直線化を反映。洗浄・水・途中接続等の対象検証記録は上記Issueにある。汚れの体感やロープ切替の見た目は引き続き確認する。
- **川の計算削減は10-02に実装済み (`c036743`)。** 多角形判定の新旧280,529点の照合で差0、水・泳ぎ・回収の対象ハーネスを通過。削減後のQuest 3での改善量は未確認。
- **[IMP-DOG-036](issues/IMP-DOG-036-leash-decision-thinning.md) は実装中。** 10-02に対象をリードから全状態へ拡張。通常の判断は5フレーム、川では10フレームに1回、位置は毎フレーム進める方針。使っていない機能のUpdate入口も削減対象。全段階の実装・検証が完了したとは扱わない。
- **通常改修で20分の6匹一周を毎回回さない。** `8de1bf1` で歩行の区間指定と、目的を必須にした一周実行を追加。橋の正方向6匹は約48秒、門の逆方向6匹は約62秒で `SEGMENTS_OBSERVED`。対象の初期化・判定は維持し、一周・実通信・実機の合格とは区別する。[実行手順と適用範囲](../testing/kh-frisbee-harness.md#歩行-通常は区間連続一周は目的を指定-2026-10-02)
- **容量は日付と対象版を付けて扱う。** 10-01の洗浄道具取り込み時のAndroid代理バンドルは圧縮50.28 MB／非圧縮129.51 MB（[記録](imports/wash-tools.md)）。09-24の37.91 MBは過去値。代理計測はSDKアップロードサイズや実行時メモリの実測ではなく、現行PC／Android／iOSの最終値は公開前に確認する。
