# IMP-DOG-035 洗い場へ犬を呼ぶ・留める

親は [IMP-DOG-024](IMP-DOG-024-walk-and-wash-experience.md)。設計と担当間の約束は [洗い場へ犬を呼ぶ・高さを調整する](../../plans/2026-10-01-wash-call-and-height.md)。

2026-10-01 ユーザーの決定 (PCVR の確認から): 「犬が洗う場所に来る方法が難しい。犬を選択して呼べるようにして、呼んだら洗い場に犬が来て、そこで立ってくれる。洗い終わるまでちゃんとそこにいてくれる」。

## 範囲

- 洗い場ごとの `KH_WashStationCall` (留まっている犬・呼んだ人・着いたか、を同期)。要求は `[NetworkCallable]` で Owner が裁定
- 犬の側: 洗い場へ向かう (遠ければ近くへ現れてから歩く)、すのこの上に棚と平行に立つ、留まる、解放で普段の行動へ
- 規則 (設計 §3): 1 つの洗い場に 1 匹、他人が連れている犬は呼べない、Fetch / フリスビー / 水の中は終わってから、留まっている間は門を閉じる、解放の条件
- ボードの犬のボタンと「おわり」(ボードそのものは [IMP-ENV-011](IMP-ENV-011-wash-height-adjust.md) と同じビルダー)

やらないこと: 台と自分の高さ (IMP-ENV-011)。犬が自分から寄る (呼ばなくても来る) は対象外。

- [ ] ClientSim: 呼ぶ → 来て立つ → 30 秒留まる、「おわり」で解放して歩き出す、別の犬を呼ぶと交代、Fetch 中の犬は来ない、集合・呼び戻し・ワープで解放、留まっている間は Fetch / フリスビー / 新しいリード接続を断る
- [ ] 洗われていない・留められていない犬は既存の経路のまま (回帰: リード・水遊び・フリスビーの既存の群)
- [ ] Codex の独立レビュー (同期と権限に関わる)

- [ ] 他人が連れている犬を呼べない。呼んだ人以外も解放できる
- [ ] Desktop / スマホでボードを押せる
