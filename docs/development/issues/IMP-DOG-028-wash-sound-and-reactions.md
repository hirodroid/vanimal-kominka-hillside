# IMP-DOG-028 音と反応の仕上げ

親は [IMP-DOG-024](IMP-DOG-024-walk-and-wash-experience.md)。方式は [設計書](../../plans/2026-09-30-dog-wash-design.md) §1-6、§1-8、§8 (音の既定値)、§6。依存は [IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md)。反応のきっかけと頻度は試作値。

## 範囲

やること。

- 音素材の新規制作 (合成、または利用条件を記録できる素材) と制作票への記録。先行作の素材は使わない
- 噴射・接触 (毛 / 泡)・泡立て・ふくの音。接触は当たった位置のループ 2 本で、泡の量に応じて配分する。他人の操作の音は受け取ったストロークの位置で鳴らす
- 個人音量の台帳への登録 (既定は既存の設定へ載せる)
- タオル (ふく)、ブルブル (手続き的な骨の往復と飛沫、撫での骨の制御へ合成)、満足の合図 (`cleanSerial` のエッジで 1 回)
- 小さな反応の頻度制御 (開始を 4 秒あける)、コミカルな反応の種類の追加

やらないこと。最小の飛沫と仮の音、反応 1 種は [IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md)。`cleanSerial` の判定は [IMP-DOG-026](IMP-DOG-026-wash-state-and-sync.md)。BGM・川音の設定そのものの変更 (別実装や自動抑制は前提にしない)。

## 完了条件

AI 側で確かめる。

- [ ] コンパイル完了とエラー 0。音の合計容量 (圧縮後) が 3 MB 以内であることを確認した (設計書 §3)
- [ ] 音素材の出所・作り方・利用条件を制作票へ記録した
- [ ] Editor の Verify で、音源が個人音量の台帳へ登録されていることを確認した
- [ ] ハーネスで、`cleanSerial` が進んだ時に満足の合図が全員に 1 回だけ出て、最初の受信では出ないこと、ブルブルの前後で撫での頭の制御が壊れないことを確認した (可能な範囲)

ユーザーが確かめる (Play / PCVR)。

- [ ] 噴射音と接触音を聞き分けられ、泡に当たる・泡が流れる・毛に水が当たる変化が操作と対応する (親: 音の区別、ASMR)
- [ ] 川音・BGM・隣の洗浄音と重ねても、自分の操作の音と会話を聞き取れる。長い再洗浄でループや反応音の反復が気にならない (親: 音の聞き取り)
- [ ] コミカルな反応が認識でき、楽しめて、洗う対象と音を追えなくならない。すすぎ前に泡を全部落として見せ場を奪わない。同じ反応の連発が気にならない (親: コミカルな反応)
- [ ] 満足の合図で「もう十分きれい」が分かり、続けて洗える (親: 仕上げ)
- [ ] 先行 Animal Wash との比較で、上回った点・残る違和感を記録した (親: ASMR。比較は [VER-DOG-002](VER-DOG-002-wash-experience-and-devices.md) と共通)
