# IMP-ENV-004 川沿いの周回コースを実装する

[DES-ENV-002](DES-ENV-002-longer-course.md)で採用した構成を、既存の道・古民家・犬との遊びを保って実装する。[HTML配置計画](../../plans/des-env-002/index.html) / [制作と実測](../../plans/des-env-002/implementation.md)を参照。犬が主役で景観は背景。景観の美しさより容量・処理負荷を優先し、現在程度の簡素さを許容するというユーザー方針。追加指定「もう少し自然な見た目」に沿い、川幅・左右の岸・浅瀬・石の群れ・木目を代表区間へ反映。軽量化優先は維持。

## 範囲と段階

2026-09-27追加：ユーザー自身がClientSimで一周し「すごくいい感じ」と評価。所要時間の計測値・実機FPSではない。橋のBlender制作、整いすぎた道と青い地面の秋色化、既存板ポリ木の少量活用を依頼された。[改修の制作票](../../plans/des-env-002/autumn-polish.md)。犬の水遊び/浮くボールは[DES-DOG-004](DES-DOG-004-river-play-and-floating-fetch.md)、地図/同行ワープ/プレイヤー合流は[DES-WLD-003](DES-WLD-003-map-and-travel.md)へ記録した。

1. 現行シーンの容量と歩行設定・Editor描画の基準を記録する。
2. 川岸・橋・水面の代表区間を別シーンで作り、材質・通行・容量・描画を確認する。
3. 20分の犬連れ散歩に必要な距離をDES-ENV-002へ戻し、承認済みの周回構成で地形/川/道/遠景を全周へ展開する。旧ルート17点は保持し、北と門側の接続帯を整備する。
4. 複数Terrainと橋面へNavMesh/接地を対応し、周回の経路グラフと目的地を配線する。犬と道具の動作を景観の非表示対象にしない。
5. 見える景観だけを描画する制御、樹木の密度/LOD、遠景、共有材質とテクスチャを調整し、16人・犬6匹と長時間の実機検証へ進める。

座標・距離・区画数・追加容量20MiBは未確定の作業案。BOOTHの可視性アセットは未導入で、利用を前提にしない。犬の水遊びや未選定の新ギミックはこの実装で追加しない。

## 現在の確認範囲

本シーンと既存Terrainのファイルハッシュを保持。`KH_RiverRepresentative.unity`へ180mの川、水面6分割、小橋1基、既存樹木2本を配置。C#と構造検査が通り、橋3列の完成経路25m・足場303点・川床16地点の除外を静的検査済み。その後、KH_RiverLoopCourseへ20枚の地形・小橋2基・約2.41kmの中心線を構築。足場14,499点、旧道/広場534点、外周接合4,608点を検査しエラー0。全周NavMeshも別資産へ生成し、再読込後の562地点・橋6経路・河床117地点の静的検査が通過。続いて旧17点を保った436点の閉路と手元の6目的地を接続し、経路ロジック・保存配列・翻訳のEditor検査が通過。橋12ケースはローカルUdonで全頭の通行を観測。その後、門での復帰逆行を修正し、門の1/3/6匹×正逆6ケースを確認した。修正後に橋と門の18ケースを続けて再確認し、全頭の通過を観測した。全周の実歩行、端末性能、背景の仕上げは未完。詳しい測定条件と留保は制作記録を正本とする。

樹皮の頂点色解釈と接続部の植生4個を修正し、Nav/PVS再生成・95視点比較を確認。6匹の連続一周検査は序盤の不連続移動で停止した。ベンチ座面への接地をNavMeshの回避経路で修正し、6匹の短区間通過を確認。その後、6匹の正方向一周で全436地点近傍と門境界の通過を確認。逆方向・人の歩行・実機は残る。原記録と比較画像は制作記録へ集約。

外周地形を下げて遠景の林を見せ、道間の最近道高度切替による直線的な崖を連続補間へ修正。元tileを保持し、Unityの地面補間で追加道の中心差最大2.34cm・左右1m内差7.52cmを確認。最終保存後の足場・旧道・接合・Nav・ベンチ除外・PVS比較と88視点を再確認した。この地形更新前の犬の全周結果を、更新後の実移動の合格とは読み替えない。

現行地形のrun20260926-205950で、6匹の逆方向一周（全436地点・門境界）を連続確認。run20260926-212223では入口から両側へ約80mの途中接続→周回→短い側で帰還→解除/再接続を1・3・6匹の計6ケースで確認した。逆行・不連続移動・実行時Error0、設定/PlayerData復元と保存scene SHA一致を確認。現行版の正方向一周もrun20260926-214203で6匹全頭436地点・門境界を確認し、逆行/不連続移動/Error0と設定/PlayerData復元・scene SHA一致を確認した。川辺の全地点での接続、実歩行・通信・端末の合格とは分ける。

PC向けSDKローカルビルドも成功（81.23MiB、Error0）。処理前後の158入力と未保存PlayerSettingsを照合し、SDKが変更したコピーシーンは退避元へ復元・再読込した。公開・クライアント起動・モバイルSDK本ビルドの合格ではない。容量・警告・復元の根拠は制作記録へ集約。
