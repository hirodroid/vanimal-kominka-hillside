# IMP-UI-012 洗い場の商品板をゲーム風の単語に、古民家ドッグランの案内板を です/ます に

## 1. 依頼 (2026-10-16、原文)

ユーザー: 「洗うの課金アイテム用のメニューボードをもうちょっと洗練。洗練のせいか、文字だけちょっと整えた『基本に戻す』『購入画面を開く』とか、すごい説明的すぎるので、もうちょっとゲームっぽく、単語でこう分かるような感じにしてもらいたいです。あとはあそこ用の画面、古民家ドックランのポータルの画面の文言がデスマス調でおねがいします。」

続けて: 「バニマルトレーナーの説明のところに入り絵の説明って全然入ってないですよね。」(音声入力。「入り絵」は入江 = A_Cove_to_Unwind と読む。§6)
