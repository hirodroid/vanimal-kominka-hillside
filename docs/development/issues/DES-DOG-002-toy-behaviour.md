# DES-DOG-002 動きの異なるおもちゃを設計する

2026-09-20ユーザー要望。裏山ではおもちゃ遊びを充実させ、外見変更に加えて挙動が異なる種類を用意する。フリスビーは候補で、採用種類・数は未確定。[報告](../../plans/2026-09-20-pcvr-feedback.md)。

同日の追加ラフ案を [IMP-DOG-005 フリスビー飛行と基本ジャンプキャッチの試作](IMP-DOG-005-frisbee-jump-catch.md) として起票。平地・1匹・1種類の前方ジャンプから始め、飛行予測に犬の口を合わせる。フリップやドッグキャッチへの拡張は基本動作の評価後とする。おもちゃ全体の選択・同時数・犬の割当・リードとの競合・公開範囲は引き続き本Issueで扱う。

## 決まったこと (IMP-DOG-005 の試作から、2026-09-21)

- **フリスビーは「おもちゃの一覧に増えた、動きの違う 1 種類」**。ボール系 (まり・たい焼きなど見た目違い) とディスク系 (柄違い) の見た目のバリエーションは、それぞれの種類の中の話として後で足す。
- **犬ごとに 1 枚、色はその犬の識別色**。メニュー「おもちゃ」は 6 犬の行のまま、各行に「ボール」「フリスビー」。まだ無い犬は「まだ」。回収は `KH_ToyRecall` の「犬番号 + 種類」。
- **投げ方は照準モード** (軌道プレビュー + トリガー、強さは右スティック / ホイール)。物理投げは上級候補として `aimLaunch=false` に残す。
- **遊び場は広場** (平地前提の計画器)。持っている間だけ薄い輪、場外は灰色 + × + 一言。斜面・見晴らしへの拡張は別途判断し、1匹でのバリエーション試作の前提にしない。
- **取り合い**: 位置取り (Ready) は他の遊びを奪わない。追走〜持ち帰り中は Fetch・リード・集合・撫でを拒み、受理済みのリード・集合が勝つ。
- 残り: 他 5 匹への展開 (犬ごとの姿勢クリップ制作が必要)、ディスク複数、ダッシュ (並走) とフリップ、Quest/iOS、2 人。記録は [試作記録](../../plans/2026-09-20-frisbee-prototype.md)。

## 採用結果 (IMP-DOG-008、2026-09-22)

- **通常版は「先回り型 + 動きの層」に作り替えた**: 投げた瞬間に取る点を決め、8 m/s で先回り / 追いながら勢いのまま跳ぶ (正面から来る球も)、待つのは高いロブだけ、跳べない低い球は立って取る、旋回は走行 240°/s でその場で向きを変えない。ユーザー評価「かなり良かった」「いい感じ」。
- **6 プリセット全部採用**: 待つ場所 (前 8 m / 横 / 遠く / 隣 = 並走)、ひねり (取り方)、横曲がり (投げ方、右へ約 1.7 m)。「ユーザーが選ぶ項目 / 自動で変わる動作」の切り分けと操作権は [DES-UI-002](DES-UI-002-frisbee-settings.md)。開発用の切替 (ヘッダの「試作」) は当面残す。
- **制限**: 購入犬の胴体追従 Constraint はフリスビーの犬で無効化する (ラブで硬さの指摘なし)。ハーネスは持ち主なし・VR 照準なし・1 人の範囲。複数人 (投げ手 ≠ Owner・途中参加)・Quest/iOS は未検証で、IMP-DOG-005 の項目として継続。
- **試さなかった候補**: フリップ、風、ドッグキャッチ (2 案: 手渡しキャッチ / 犬を受け止める)。必要になったら本 Issue で再検討。
- **6 匹展開**: [IMP-DOG-012](IMP-DOG-012-frisbee-six-dogs.md) (犬種別クリップ・facts、胴体固定、負荷、Catch の分割、犬種別ハーネス)。

## 次の順序 (2026-09-21 追加合意)

1. **通常版の体験の仕上げはひとまずOK**。ユーザーのVR評価を受け、IMP-DOG-005を比較基準にする。項目別・2人などの未確認項目は同Issueに残す。
2. **同じラブ1匹で取り方・飛び方を一通り試す**。[IMP-DOG-008](archive/IMP-DOG-008-frisbee-variations.md) で外から走り込むキャッチを最初に扱い、フリップなどの取り方と飛び方の変化を比較する。候補ごとに採否を決める。
3. **1匹で通常版と採用バリエーションがOKになってから6匹へ展開する**。犬種別の姿勢・口の位置などの調整は、その時点で別Issueにする。公開向けの未検証事項も引き継ぐ。

「外から走ってきてパッと取る」は通常版の必須修正ではなく、IMP-DOG-008の最初の試作目標。見た目の柄違い・複数ディスク・斜面対応は、上記の試作と分けて採否を決める。
