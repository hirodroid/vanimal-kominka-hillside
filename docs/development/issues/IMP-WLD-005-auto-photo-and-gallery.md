# IMP-WLD-005 自動写真とギャラリーを看板・ボード・メニューへ追加する

## 依頼

2026-10-02 ユーザー指定: 古民家ドッグランと同様に自動写真とギャラリーを追加する。ギャラリーは入口の説明と同じような古民家に似合う看板・ボードを用意し、手元メニューにも写真ギャラリー用の場所を1つ作って、そこから見られるようにする。

## 範囲

- 古民家ドッグランの自動写真・ギャラリーの仕組みを確認し、裏山へ導入する。撮影契機、写真の選び方・更新、公開・保存・閲覧の範囲と端末差は調査して引き継ぐ
- ワールド内に写真を見る看板・ボードを置く。[DES-UI-004](DES-UI-004-walk-destinations-and-boards.md) の遊び方・マップの看板と外観・配置を合わせて検討する
- 手元メニューに写真ギャラリー専用の入口と閲覧面を作る。「ギャラリーを見る」操作から写真まで辿れるようにし、入口だけで終わらせない。独立タブか副画面かはレイアウトで決める
- 看板・ボードとメニューで写真の参照先・更新状態を揃え、写真が無い・取得待ち・取得できないときの表示を決める
- 撮影・写真表示に伴う描画負荷、容量・メモリ、Quest / iOS の利用可否を確認する。軽量化完了後の予算を踏まえ、撮影頻度・保持枚数・解像度は実測で決める
