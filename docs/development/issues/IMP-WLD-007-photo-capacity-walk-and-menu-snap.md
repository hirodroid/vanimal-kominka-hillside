# IMP-WLD-007 写真枚数・散歩中の撮影とメニュー内写真の吸着を改善する

## 依頼

2026-10-03 ユーザー: 写真が今の8枚では少ない。古民家ドッグランのときのようにもう少し欲しい。撮影は犬目線と自撮りの感じの2種類を希望し、散歩中の写真も撮りたい。メニューには写真が出るが、吸着シェーダーがないように見えるので対応が難しいか確認したい。

## 作業範囲

- 現状の8枚から保持・閲覧できる写真を増やす。増加後の枚数は未指定。古民家ドッグランの現行仕様と端末負荷を確認して決める。
- 希望する撮影の見せ方は「犬目線」「自撮り風」の2種類。散歩中の犬や一緒に散歩している場面を撮れるようにする。構図・撮影契機・手動/自動の操作は実装着手時に整理する。
- 手元メニュー内の写真について、VRChatカメラを近づけたときの吸着・全画面表示を想定して現状を調査する。これは依頼中の「吸着シェーダー」の解釈であり、現地の写真ボードとの違い、既存シェーダー・UIでの対応可否を確認する。難しい場合は具体的な制約と代案を示す。
- 枚数・撮影機会を増やした際のメモリと撮影時の負荷、PC / Quest / iOS の対応差を確認する。
