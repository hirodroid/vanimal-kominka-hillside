# IMP-ENV-003 スポーン地点の真後ろにポータルが置かれないようにする

[体験会の記録](../../plans/2026-09-26-group-playtest.md) (2026-09-26、15 人) でユーザーが報告: **ポータルがスポーン地点の真後ろにあり、間違って入りそう。** 途中参加者がスポーンして振り返るとポータルに触れる位置だった。

## 現状

- シーンにワールド側のポータル (`VRC_PortalMarker`) は無い。体験会のポータルは参加者が落としたもの (ログに `PortalManager` の生成・破棄が数回ある)
- スポーンは `KH_Entrance` (門の前、47.6 / 1.6 / 40.1、向きは y 回転 -26°)。人はここへ出て門から登り道へ向かう
- シーンに `Portal` という名前の空オブジェクト (Transform だけ、68.3 / -1.6 / 115.1) があるが、地面の下で無関係。残骸なら消してよい

ポータルは落とした人の目の前に出るので、ワールド側で置き場所を直接は決められない。できるのはスポーンの周りの形と誘導。

## やること

1. スポーンの真後ろを人が立ち止まらない形にする (柵・石・植え込みなど、門前の景観に合うもの)。ポータルを置けなくするのではなく、「そこに置こう」と思わない形にする
2. 門の脇にポータルを置きやすい平坦な余白を作る (説明ボードの隣など。[DES-UI-004](DES-UI-004-walk-destinations-and-boards.md) の配置案と合わせる)
3. スポーンの向きを、出てすぐの視界に門と登り道が入る向きにする (現状 -26° で足りているかを Play で見る)
4. 複数人のスポーン (spawnRadius 0.2) で重ならないか、15 人規模の到着で押し出されないかを見る

## 完了条件

- [ ] スポーン周りの配置案をユーザーが確認し、シーンへ反映した (Build で再生成しても残る)
- [ ] 2 人で「A が門の脇にポータルを落とす → B がスポーンして振り返っても触れない」を確認した
- [ ] 不要な `Portal` 空オブジェクトの扱いを決めた (削除または理由を書く)
