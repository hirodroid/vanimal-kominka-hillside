## 保留を解除するとき

1. `git mv` で `issues/` 直下へ戻す
2. frontmatter の `status` を `todo` へ
3. この表から行を削除し、[issue_summary.md](../issue_summary.md) の表の状態欄を直す
4. 検査を 2 本とも通す

## 保留にするとき

**「再検討のトリガー」を必ず書く。**
条件を書かずに保留すると、二度と見返されないまま公開まで行く。
「M4 に着手したとき」「2 人以上で遊ぶようになったとき」のように、
**観測できる出来事**で書く。
