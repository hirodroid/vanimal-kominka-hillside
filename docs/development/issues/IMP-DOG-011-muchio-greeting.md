# IMP-DOG-011 空いている犬が自由行動中にたまにムチォの匂いを嗅ぎに行く

## 目的・対象

「自分が連れてきたペットを、この世界の犬も気にしてくれた」という体験を作る。**空いている犬が、普段の勝手に遊ぶ自由行動の一つとして、たまに近くのムチォの匂いを嗅ぎに行く。** 嗅いだら通常の自由行動へ戻る。独立した挨拶モードや首かしげなどの追加演出は作らない。

2026-09-21ユーザー依頼・同日の範囲修正。**まず古民家の裏山で試作する。** 古民家ドッグランへの展開は本Issueの実装範囲に含めない。実装・実機検証は未着手。

先行調査: [VER-DOG-001](VER-DOG-001-avatar-pet-contact-research.md) / [Prefab調査結果・実機チェックリスト](../../plans/2026-09-21-avatar-pet-contact-research.md)。静的調査の根拠・対象版はそちらを正本とし、本Issueは試作と犬への接続を管理する。

## 現時点の判断

静的な技術調査、公開規約、ユーザーから共有された作者・利用者の反応の範囲では、今回の試作を止める材料は見つかっていない。**実機での成立と、この自動連携に対する作者の公認は未確認。** 作者への確認待ちを試作開始の必須条件にはしない。

## 実装の前提

| 項目 | 方針・確認結果 |
|---|---|
| 来訪者側の準備 | 購入時の既定構成を対象とし、専用Senderの追加やアバター改変を求めない |
| 検知対象 | ムチォの既存Sender、タグ `OnigiriPetKiss` |
| 取得候補 | Contact proxyの位置・回転・所有プレイヤー。所有者は犬のネットワークOwnerと区別する |
| 基準Transform | `<アバター>/<ペット名>/PetWorld/PetMount/PetGroundRoot/PetMotionRoot/KissContacts`。Root未指定のため自身のTransform |
| 静的調査 | 接地補正後のペットに追従する。収納時は親 `PetWorld` ごとOFFになりSenderも消える |
| 精度 | 見た目の小さな上下動は共有しない。メッシュ中心・鼻先への厳密な一致を前提にしない |
| ワールド側 | Receiverと自作Udonで検知し、ワールドの犬だけを動かす。ムチォ向けSenderは追加しない |
| ムチォ側 | 発言・移動・友達登録などの既存動作を変更・誘発する処理を加えない |
| 対象外 | 犬っこギミック。既存Senderは食器表示依存またはLocal Onlyで、無改変の通常時検知には適さない |

Contact proxyの `position` / `rotation` はContactのRoot Transform、`player` はそのContactを所有するプレイヤー。形状オフセットや接触点をペットの座標にしない。[VRChat公式Contacts仕様](https://creators.vrchat.com/common-components/contacts/#udon-access-in-worlds)（2026-09-21確認）。

タグは商品や個体の真正性を保証するIDではない。同じタグを持つ別のSenderも検知し得るため、仕様説明で完全な商品識別とは表現しない。

## 体験と行動の条件

- 既存の自由行動の候補に「近くのムチォの匂いを嗅ぐ」を加える。検知したら必ず向かうのではなく、たまに選ぶ。短く嗅いだら自由行動へ戻り、追い続けない。
- リード未接続で、集合・Fetch・フリスビー・他の遊びなどを実行していない犬を対象とする。既存行動を中断してムチォへ向かわせない。対象となる既存の状態名は実装時に照合する。
- 匂いを嗅ぐ行動よりプレイヤーの操作・既存の遊びを優先する。途中でリード接続や遊びが始まったら、その行動へ譲る。
- 発生頻度、再反応までの待ち時間、接近距離、嗅ぐ時間は既存の自由行動に合わせて調整する。複数の犬が同時に集中して取り囲まない。現時点で数値は未決定。
- 到達できない位置、抱っこ中の高さ、急な移動には無理に接近しない。検知喪失・収納・アバター変更・退出時には嗅ぎに行く行動を打ち切り、古い位置へ向かわない。
- 犬の移動判断は既存の犬Owner側で行い、既存の同期経路を使う。各端末が同じ犬へ競合して移動指示を出さない。ペットの持ち主と犬Ownerが異なる条件で位置差を測る。

## 規約・作者とユーザーの反応

### 公開規約と今回の利用範囲

[ムチォの商品ページ・利用規約](https://booth.pm/ja/items/8657397)を2026-09-21に確認。商品データの再配布やワールドへのアップロードは禁止されている。一方、来訪者の既存Contactを検知してワールドの犬を動かす連携を明示的に禁止する記載は確認できなかった。

ワールドへ実装するのは自作の検知処理と犬の行動のみ。ムチォのモデル・Prefab・Animationなどの商品データは組み込まない。この範囲を商品データの再配布・ワールドへのアップロードとは区別して試作する判断であり、作者の個別承認を得たという意味ではない。

### 共有された反応と確認の限界

ユーザー提供の調査では、作者が「ムチォおさんぽコース」に反応し、紹介動画の曲をワールド作者にも使ってほしいと発信した例がある。[共有された作者投稿](https://x.com/IWANUGA_fl/status/2088641384001753472)。今回のWeb再確認では投稿本文を取得できなかったため、独立に確認済みの事実とはせず共有情報として記録する。

追加のX調査として、改変を喜ぶ発言、おさんぽコースやHubへの訪問・交流の報告も共有された。個別の投稿URLは未受領。関連ワールドや連れて歩く遊びへの好意的な反応は企画の参考になるが、次の点は区別する。

- 共有情報が示すもの: 関連ワールドや改変、訪問・交流が楽しまれている例。
- 未確認: NPCがContactでムチォを検知する同種の実装、公認事例、今回の方式への作者の意思。
- 推論しないこと: 作者の無返信が了承を意味する、今回も必ず歓迎される。

告知では実際の動作を説明し、「公式コラボ」「公認」とは表記しない。将来作者へ紹介・相談する場合は、実装範囲が伝わる短い実機動画を使う。紹介・連絡は本Issue作成では行わない。
