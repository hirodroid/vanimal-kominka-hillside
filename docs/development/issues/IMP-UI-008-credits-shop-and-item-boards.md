# IMP-UI-008 クレジット・紹介・アイテム案内ボードの整備

## 依頼 (2026-10-14)

古民家ドッグランと揃えたクレジット・ショップ紹介・グループポスターを用意する。古民家ドッグランの「犬たちのお気に入り」の隣に置いてある各アイテムの説明とメニューを開くボードも、裏山版にして現地へ配置する。

## 作業範囲

### メニュー内のクレジット

- 現在メニューにあるクレジットを、古民家ドッグランと同じ構成・見せ方に揃える。
- ユーザー指定「フォントは不要」を反映し、フォントのクレジット掲載を外す。表示に使うフォント資産の削除を指すものではない。
- 古民家ドッグランの現行表示を確認し、裏山に載せる内容を整理する。
- [IMP-UI-001](IMP-UI-001-menu-table-driven-and-settings.md) の 2026-10-03 記録では Noto Serif JP / OFL 表示を含む 5 行だった。今回の依頼は、その表示内容の追加変更として扱う。

### torinosukeShop の紹介とバニマルのグループポスター

- torinosukeShop の紹介を、**古民家の壁面の、ポータルが出るほうと反対側**へ設置する。
- バニマルのグループポスターは、**古民家ドッグランと同じもの**を導入する。
- グループポスターは **torinosukeShop の紹介と並べて**置く。
- 参照元の素材・表記・リンクや操作の有無を確認し、裏山側へ必要なものを移植する。

### 裏山版のアイテム案内とメニューを開くボード

- 参照元は、古民家ドッグランの **「犬たちのお気に入り」の隣にある、各アイテムの説明とメニューを開くボード**。
- 参照元の説明と操作を確認し、裏山のアイテム・機能・メニューに合う内容へ作り替える。
- ボードから裏山のメニューを開けるようにする。対象のアイテムと開くメニューの対応は、参照元と現行の裏山メニューを確認して整理する。
- **配置候補は地図の隣、道の反対側。** ユーザーの「かなぁ」という提案であり、位置は未確定。読みやすさ・操作のしやすさ・通行への影響を見て、良さそうな場所を提案・調整する。
