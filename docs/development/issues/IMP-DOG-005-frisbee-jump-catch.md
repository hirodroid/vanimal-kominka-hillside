# IMP-DOG-005 フリスビー飛行と基本ジャンプキャッチを試作する

2026-09-20 ユーザー提示のラフ案をIssue化。関連する全体設計は [DES-DOG-002](DES-DOG-002-toy-behaviour.md)。本Issueは試作の作業票であり、公開仕様や調整値の確定・実装済みを意味しない。

## 目的と初版の範囲

**平らな場所で、素直に投げたディスクを、犬が自然にジャンプして取る。** まず1匹・1種類の前方ジャンプで「パクッと取って、トンッと着地する」気持ちよさを確かめる。特に犬の姿勢を重視する。

設計の核は、**ディスクが少し先に来る場所と時刻を予測し、そこにキャッチ姿勢の犬の口を合わせること**。犬の中心をディスクに合わせる設計にしない。

- 平地での投球・追走・踏み切り・頂点付近でのキャッチ・着地・持ち帰りを対象とする。
- 取れない投球の中止・地上回収・場外からの復帰を含む。
- フリップ、ドッグキャッチ、風、複雑な横曲がり、跳ね返り後の空中キャッチ、斜面でのジャンプは初版の対象外。
- 試作の1匹は既存6匹から選ぶ。全犬種への展開は基本動作の評価後に判断する。

## 飛行と予測

- プレイヤーの投げる方向・強さを反映し、前へ滑空しながらゆっくり落ちる、予測しやすい軌道から始める。
- 極端な投球速度には上限を設ける。速度・落下・滑空感の数値は試作で調整する。
- **実際の飛行と、犬が使う未来位置の予測は同じ計算を使う。** 同じ初期状態・経過時間に対する飛行位置と予測位置の一致を確認する。
- 物理の忠実さより、まず飛行と犬の組み合わせで遊んで気持ちよいことを評価する。

## 犬の動作と判断

| 段階 | 動作・判断 |
|------|-----------|
| 投球を確認 | ディスクの今後の軌道を予測する |
| キャッチ地点を探す | 到着が間に合い、口が届く高さで、進路・着地点が空いている未来の位置と時刻を選ぶ |
| 追いかける | 選んだ地点へ走り、走行中は予測を更新する |
| 踏み切る | キャッチ位置・時刻と着地点を決め、ジャンプを開始する |
| 空中キャッチ | 口とディスクの縁が許容範囲内に近づいたら、くわえる |
| 着地・帰還 | 着地で少し沈み込み、走りへつなげて持ち帰る |

踏み切ったあとは大きく進路を変えない。空中で追尾し続けて飛行して見える動作を避ける。くわえる瞬間だけ小さなずれを吸収して口元へ固定し、大きく離れていれば失敗とする。許容距離・補正量は未確定とし、遠くから吸い込まれる見た目にならない範囲を実測して決める。

## 犬の姿勢を4段階で作る

ユーザー案の重点を、次の4段階のポーズ案として整理する。模式図そのものは未作成。制作時に側面から口・胴体・脚の関係を確認できるポーズ図または短いプレビューを用意する。

| 段階 | 姿勢のラフ案 | 確認する見え方 |
|------|--------------|----------------|
| 1. 踏み切り前のため | 脚を曲げて重心を下げ、前進から跳躍へつなぐ | 脚で地面を押して跳ぶ準備が見える |
| 2. 踏み切り・上昇 | 脚を伸ばして離地し、前進に合わせて胴体を傾ける | 急に浮き上がらず、ためから力がつながる |
| 3. 頂点付近のキャッチ | 空中の脚を整え、首・口をディスクの縁に合わせて開閉する | 口が届く瞬間と「パクッと取る」が読める |
| 4. 着地・走りへの復帰 | 接地で脚を曲げて少し沈み込み、姿勢を戻して走る | 重さと衝撃の吸収が見え、持ち帰りへ自然につながる |

特に **ため → 口が届く瞬間 → 着地の沈み込み** のつながりを評価する。足の接地順や胴体の傾きなどの詳細は、選んだ犬のリグ・既存クリップを確認して詰める。

## アニメーションと移動制御の分担

- アニメーションは脚の曲げ伸ばし、胴体の傾き、首・口の動きを担う。
- 移動制御は踏み切り位置、キャッチ位置・時刻、着地点を担う。
- クリップ内の本体移動やルートモーションを使う場合は、移動制御との二重移動を防ぐ。
- 投球全体を固定のTimelineにすることは前提にしない。ジャンプの姿勢を作り、実行時に開始タイミングと移動距離を合わせる。
- 「踏み切りから口を開いて取るまで」の時間と、その姿勢での口の位置を基準に、予測キャッチ時刻からジャンプ開始を逆算する。

参考（ユーザー提示）: [Unity 2022.3 Root Motion](https://docs.unity3d.com/2022.3/Documentation/Manual/RootMotion.html)。数学の補助は位置・速度・方向を表すベクトルと、ジャンプ軌道を扱う二次関数を中心にする。

## 取れない投球・中断時の動作

| 状況 | 初版の対応案 |
|------|--------------|
| 低く、ジャンプ不要で口が届く | 通常キャッチ |
| 空中では間に合わないが、落下地点へ行ける | 落ちてから拾う |
| 高すぎる・遠すぎる・障害物の向こう | 空中キャッチを狙わない。地上回収できるかは別途判断する |
| 途中で壁に当たる・人がつかむ | 追跡を中止し、跳んでいたら着地を優先する。壁への衝突後は空中キャッチを再開しない |
| ジャンプ後に口が届かない | 無理に吸着させず、着地してから回収可否を判断する |
| 場外に出る | 深追いせず、ディスクを戻せる手段を用意する |

## 試作の順序

1. **同じ投球を繰り返す**: 平地・1匹・固定の投球条件で、予測と飛行の一致、4段階の姿勢、口の位置、着地を調整する。
2. **方向・距離・高さを変える**: プレイヤー操作で投げ、成功範囲と通常キャッチ・地上回収・中止の分岐を確認する。壁への衝突、人による取得、場外も確認する。
3. **複数人で見え方を確認する**: 投げる人と観察者で、飛行・踏み切り・キャッチ成否・くわえた状態・着地が矛盾しないか確認する。所有権や途中参加の扱いも検証項目に含める。

AIはコンパイルと構造・設定を確認し、PlayとVRChat実機での気持ちよさ・同期の評価はユーザーへ引き継ぐ。条件と結果を記録し、未実施の検証を完了扱いにしない。

## 実装着手時に詰めること

- 試作対象の犬・平地・既存Fetchとの接続点、使用可能なリグとクリップ。
- 投球速度上限、滑空・落下の調整値、走行速度とジャンプの到達範囲、予測更新間隔。
- 口の基準点とディスクの縁の判定、キャッチ許容距離、小さな位置補正の上限。
- 犬とディスクの所有権、キャッチ成否の裁定、所有者退出・途中参加時の復帰。
- リード中・呼び出し・ほかのおもちゃとの優先順位、リセット方法。全体の契約はDES-DOG-002と整合させる。
- Quest単体・iOSへの展開条件と負荷確認。1匹の試作合格と全機種・6匹の公開品質を分ける。
