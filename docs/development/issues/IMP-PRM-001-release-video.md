## 決めたこと (委任範囲内。ユーザーが覆せる)

| 軸 | 決定 | 理由 |
|---|---|---|
| 形 | 横 1920×1080 / 60 fps / **60.0 秒**、統合 -20 LUFS、20 MB 以下の投稿用も出す | 予告 3 本と同じ型。手本 (36 秒) より長いのは 3 つの遊びを入れるため。曲を縮めるには新しい BGM の作業が要る (依頼なしでは作らない) |
| 曲 | **「いっしょに、裏山さんぽ」002** | 裏山の主題歌 (4 作品中 3 作品で使用)。小節の時間割が既にある |
| コピー | **「公開しました！」(着地) → 「さんぽして、」→「遊んで、」→「洗って、」→「さっぱり。」→ 題字** | 手本の「コピー → 場面」の形をポスト文面の語で。大きさは「文字ドーン」(予告の slam 文字の大きさ) |
| **「汚れて」は動画に入れない** | ポストの文面には残す | 素材に汚れた犬が写っていない (洗えますティザーの企画で「汚れが落ちる・泥んこ」を言わないと決めた根拠と同じ)。映像で確認できない文言は入れない |
| 締め | 「古民家の裏山 / VRChat ワールド ｜ **公開中！** / 出演：そら・うにぃ」 | 手本の「公開中！」とポストの「公開しました」に合わせる。日付は入れない (公開後も使える) |
| Quest・スマホ | 動画に入れない | ポスト本文が持つ。手本にも無い |
| 古民家ドッグランへの誘導 | 動画に入れない | ポストの最後の 1 行が持つ。裏山の素材だけで作る |
