# IMP-WLD-008 犬との自動動画撮影カメラ

## 依頼と目的

2026-10-03 ユーザー提供「犬との自動動画撮影カメラ 仕様案」を起票。

散歩中などにVRChat標準カメラを操作し続けなくても、犬とユーザーの様子を撮影できる「専属カメラマン」のような体験を作る。犬の近くからユーザーを撮る、犬とユーザーを同時に映す、散歩に自動追従する、手ブレの少ない映像にすることを目的とする。

本Issueは仕様案と実装・検証の課題を記録する。以下の構成・性能値・録画経路は、実装や実機での成立を確認済みという意味ではない。

## 構成

既存の犬目線カメラ・自動撮影・写真吸着の仕組みを流用候補とする。

`追従用Camera → リアルタイム更新するRenderTexture → 撮影用モニター → VRChat標準カメラへ吸着表示 → Stream Camera等の出力・録画環境で録画`

- ワールド側の独自Cameraの位置・向きをUdonで制御する。VRChat標準カメラ自体をUdonで移動させる構成にはしない。
- 「吸着」は既存の写真表示の仕組みを指す。モニターのTransformを物理的にカメラへ追従させる必要があるか、シェーダー上の全画面表示だけで成立するかは既存実装を確認する。
- ワールド側が提供する範囲は追従映像と表示・操作。動画ファイルの記録開始・停止・保存はVRChat側の出力機能と録画環境で行う想定。端末別に、実際に使える録画手段・必要な操作を確認して案内する。

## ユーザー操作

1. 手首メニューなどの「撮影カメラ」を選ぶ。
2. ユーザー付近に撮影用モニターが現れ、追従映像を表示する。
3. VRChat標準カメラをモニターへ近づける。
4. 既存の吸着機能で、カメラの撮影画面いっぱいに映像を表示する。
5. 利用する録画環境で録画を開始する。

終了はモニターの「×」。閉じると追従Cameraと映像更新も停止する。既存の犬目線カメラに近いUI・操作感とする。モニターは仕様案では「閉じるまで出した場所に存在する」。固定配置の意図は確認中で、散歩中に標準カメラと離れても表示が継続するかを検証する。

## MVP

最初のモードは第一候補の **並走カメラ1種類**。犬の横または斜め前を滑らかに移動し、犬とユーザーを一緒に映す。

- メニューから撮影カメラ・モニターを出す
- モニターへリアルタイム映像を表示する
- VRChat標準カメラへの吸着表示を使う
- 犬へ追従し、ユーザーの頭部または胸付近を見る
- 滑らかな位置・向きの更新とRoll固定で揺れを抑える
- ×でモニターを閉じ、追従Camera・映像更新を止める
- 機能全体をローカル処理とする

複数犬を同時に収める制御や、他の撮影モードはMVPの完了条件に含めない。対象端末・対象犬の選び方は下記の確認事項。

## Cameraの追従と安定化

ユーザー案の基本式は `TargetPosition = DogRoot + CameraOffset`、向きは `LookAt(Target)`。犬またはユーザーを基準に位置と注視点を計算する。

- 犬のHeadボーンへ直接固定せず、Rootなどを基準にする。
- Position Smooth / Rotation Smoothを用い、歩行・走行・アニメーションの上下動を抑える。
- Rollを固定し、ユーザーの頭部または胸付近を注視する。
- 距離に応じてCamera Offsetを調整する。
- 「犬そのものの視点」より「犬のそばを飛んでいるカメラマン」を目指す。

実装時にはオフセットの座標系と進行方向の取り方、曲がり角・停止・急な向き変更・ワープ時の追従、対象犬が遠ざかった/無効になった場合の扱いを決める。Root追従とユーザーLookAtだけで犬とユーザーの両方が画面内に収まるとは仮定せず、構図を確認する。壁・地形へのめり込みや遮蔽、犬の体内が映る場合も確認し、必要な最小限の対処を決める。

## ローカル処理・負荷

- Camera、RenderTexture、モニター、追従処理、モード選択はユーザーごとに独立し、同期しない。
- 通常時・終了時は `Camera.enabled = false`。撮影中のみ有効にし、必要な頻度で描画する。
- 利用者だけが追加レンダリング負荷を負う設計とする。使わない人の端末でCameraが動かないことを確認する。共通アセットの読み込み等も含む総負荷ゼロを保証する表現にはしない。
- FPS・RenderTexture解像度は既存犬目線カメラの設定を基準に検討し、端末別に実測する。
- ユーザー提示の目安は **PC 30fps前後 / Mobile・Quest 8〜15fps程度**。確定値・最低保証ではなく、対応端末と品質を決めるための候補値として扱う。
- ×で閉じた後は追従計算・RT更新も停止し、繰り返し出し入れしてもCamera・RT・モニターが増殖しないようにする。

## 音声

音声はVRChat標準カメラの出力・録画ソフト側で取得する想定。独自Cameraの位置から聞こえる音をワールド側で再現する必要は基本的にない。

ユーザー本人が聞いているワールド音・犬の音・環境音・Voiceが、利用する録画構成でどう記録されるかを実機で確認する。映像が出ることを音声収録の成立と同一視しない。

## 後続モード・将来拡張

MVPが動いてから、共通のCamera・RT・モニター・吸着処理を使って追加する。

| モード | 構図・用途 |
|---|---|
| 犬目線 | 犬の低い位置からユーザーを見て、一緒に歩く雰囲気を撮る |
| 後方追従 | 犬とユーザーの後ろから散歩風景・景色を含める |
| 前方撮影 | 前方から後ろを向き、こちらへ歩いてくる犬とユーザーを撮る |

将来候補: 距離・高さ・左右・FOVの変更、犬だけの撮影、ユーザー＋犬の自動フレーミング、複数犬対応、定点カメラ、自動カメラ切り替え。位置・注視点・オフセットの計算を共通化しつつ、追加機能固有の設計・検証は別途行う。
