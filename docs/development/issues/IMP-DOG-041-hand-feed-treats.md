# IMP-DOG-041 手に持ったおやつを犬へ直接あげる

## 要望と決定

2026-10-07 ユーザー要望: 「おやつってそんな落とさないよね。手であげるよね」「手に持ってるやつを食べるようにしちゃいたい」。続けて、実行前に Issue を立てて記録を残すよう指定。実装ファイルの変更前に本票を作成した。

従来の「手に出す → 見せる → 手放して地面で食べる」を、**手に持って犬の口元へ差し出せば、そのまま食べる**操作へ変更する。既存の自動吸着と掴み直しの両方を対象にする。高い位置・遠い位置にある餌は食べず、犬の口が届くところへ差し出す。落とした餌の既存の食べ方も残す。

## 範囲と成立条件

- 犬の呼び寄せ・自分の接続犬の優先・他人の接続犬の除外は [IMP-DOG-006](IMP-DOG-006-leashed-treat-approach.md) を継承する。
- 既存の口アンカーと餌の位置で届いたかを判定する。水平距離だけで高い餌を食べない。手振れは地面の静止判定と分ける。
- 出した直後の手への吸着は `VRC_Pickup.IsHeld` と別物。Owner だけにある吸着フラグを遠隔の犬の判断に直接使わず、手持ち状態を全員で判別できるようにする。
- 食べ始めは既存の Box の Owner が決定し、枠と世代を照合する。手からの受け取り・表示・食べ演出・回収をこの決定に合わせる。在庫は既存の「出す」時の1回だけ減らし、食べた時に再消費しない。
- 6 犬種の口元への差し出し、リード有無、左右の手、地面へ落とす、しまう、連続使用を対象にする。食後のお礼・リード中の待機を維持する。
- 既報の「地面に落としても来ない」は症状の再現条件が未確定。直線移動で障害物・川に止まり担当犬を保持する経路、未接続犬の受付と割当の条件差は今回の調査で見つかった別の論点。手渡し追加で解消したとは扱わない。

### 実装

- Slot の Owner が吸着・Pickup をまとめた `handOffered` を同期する。`_CommitOut` の世代と同時に初期状態を配り、解除/掴み直しと周期的な実体照合で更新する。
- Box の Owner が口アンカーから **3D 0.22 m以内**で手渡しの食べ始めを決定する (暫定の操作許容距離。実機で確認)。地面用の静止判定は手渡しには適用しない。手渡しの種別・受取位置は食べ始めと同じ Box の同期で配る。
- Controller は同じ枠/世代の受け取りを見てメッシュ・Collider・Pickup を無効にし、Owner が Drop・吸着解除・kinematic 化する。食べ時間終了から回収までの間も非表示を保ち、同じ人/同じ品を続けて出した別世代では表示を戻す。
- 犬は口の水平オフセットに合わせて餌へ近づく。壁・川・リード範囲の制限は維持する。手渡し後は立ったまま固定した受取点へ注視し尻尾で反応する。**専用の咀嚼クリップは追加していない**。食後 FX も受取点を使う。
- 既に引き受けた手持ち餌に限り、口元へ来た手で撫で判定が発生しても割当を維持する。別の撫でられている犬を新しく呼び出す条件は変えない。
