# IMP-DOG-030 洗浄の 6 匹への展開

親は [IMP-DOG-024](IMP-DOG-024-walk-and-wash-experience.md) (実装順 3「6 匹と散歩への接続」)。方式は [設計書](../../plans/2026-09-30-dog-wash-design.md) §1-1、§3、§4、§6。依存は [IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md) の評価 (成立を確かめてから着手)。

## 範囲

やること。

- 6 犬種 (柴・サモエド・ダックスフンド・Corgi・Lab ほか、既存の 6 匹) の位置マップの焼き込みと部位 Collider の配置。骨の名前は共通だが、2 段構成の犬 (Corgi / Lab / Shiba) はメッシュ側の骨を追う
- 体格差の調整 (小型犬の足・大型犬の背中に届く位置、部位の範囲、ブラシの大きさ)
- 毛色差の調整 (白・黒・茶で汚れ・泡が見え、顔・表情・毛の特徴を隠しすぎない。顔の泡と押し出しの上限)
- 動く部位 (足・尻尾) の追従の確認
- 犬ごとの RenderTexture・殻・`KH_DogWash` の配置。同時に洗われる犬 3 匹までを目標とした負荷の確認 (設計書 §3)

やらないこと。方式の変更 (賭けが外れた場合は [DES-DOG-006](DES-DOG-006-wash-method.md) へ戻す)。行動の切替は [IMP-DOG-027](IMP-DOG-027-wash-behavior-switching.md)。複数地点の配置は [IMP-ENV-008](IMP-ENV-008-wash-stations-along-course.md)。端末別の実測は [VER-DOG-002](VER-DOG-002-wash-experience-and-devices.md)。

## 記録

2026-09-30: 起票。実装は未着手。

2026-09-30: 実装。ビルダーの `Targets` を 6 匹にし、犬ごとの表 (高さ、汚れの高さの境目 = 柴の値を高さの比で伸縮、殻の押し出し `_BaseOffset` (長毛 0.008 / 短毛 0.004〜0.005)、泡の厚み `_FoamThickness` (柴 0.05 を高さの比で: ダックス 0.029、ポメ 0.022、コーギー 0.032、ラブ 0.059、サモエド 0.057)、毛の明るさ `_FurBrightness` (サモエド・ポメ 1.0、ラブ 0.7、他 0.5)) を Wash/11 が書き、Wash/12 が照合する。31 骨のポメは表に無い骨 (Bone.022/.023) を飛ばす。PhysBone の登録は犬ごとに自動。Wash/11 3738 項目 PASS (変換の往復、Collider の表面と毛の表面の差の中央値 ≤ 0.07 m を含む)。試し描きは `Wash/18` で犬を選ぶ。Edit モードの撮影: サモエド (白) は泡が青灰色の膜に見えたため、シェーダーに `_FurBrightness` を足して白い毛では谷を暗く頂上を明るくし、灰色の塊 + 白い粒として読める状態に (灰色がやや強め、PCVR で調整候補)。ダックスは尻尾の泡が太く見えたため厚みを比例させた。ClientSim (run 20260930-113707 全体 53 ケース、115102 群 6/6): W-dogs-wired / W-dogs-others / W-dogs-foam PASS。同期の量の見積もり: 1 匹約 470 B、洗っている犬 1.33 Hz で約 0.63 KB/s、3 匹洗いながら 3 匹散歩で約 4〜5 KB/s (実測は未)。**試作の初期の汚れ 0.6 が 6 匹全部に入り、最初から 6 匹の殻が有効 (描画負荷)。公開前に 0 へ。** Play・実機は未確認。

2026-09-30 (Codex レビュー後): 白い毛の対比の変更 (`_FurBrightness`) が茶色の毛の見え方を変えないよう、粒の間の減光と谷の色を fb に連動させ、`_FoamShadow` の既定値を旧に戻した。Verify の表面の差の検査はシーンの実際の CapsuleCollider を測るように変更。Wash/11 3888 項目 PASS、群 100e 6/6 (run 20260930-115923)。
