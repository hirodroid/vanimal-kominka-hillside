# IMP-DOG-033 場所を決めて呼ぶを手の傾きに追従させる

斜面でも、自分が抱っこしている感じに犬を置きたい (2026-09-30 ユーザー要望)。今は古民家も裏山も向きは水平の yaw だけ。先に [IMP-DOG-032](IMP-DOG-032-call-placement-free-height.md) で古民家どおりに戻し、この件は後で行う。

## 範囲 (案)

- VR: マーカーの回転を手に追従させる (yaw に加えて傾き)。板の ◀▶ は yaw の微調整として残すか決める
- 同期: `KD_SleepSlot` の `spotYaw` に傾きを足すか、回転をまるごと同期する
- 犬: 寝床に収まるとき、指定した回転で据わる。呼び終わったら接地と同時に水平へ戻す
- Desktop / Touch: 手が無いので、真下の地面の傾きに自動で合わせる案がある
- 犬が水平でない間、撫でる・あご乗せ・お手の位置計算や、寝ている間の他の処理が傾きを前提にしていないか確かめる
