# BUG-DOG-002 リードの持ち手が左右どちらの手でも左向きに付く

2026-09-20 ユーザーの PCVR 報告: 首輪・リードの本制作版は「あれでいいレベル」だが、持ち手が右手でも左手でも左向きに付いて見える。最後の微調整として扱う。

現行は `KH_LeashCollar.UpdateModeledGeometry` が持ち手を手の追跡回転そのままに置く。右手用・左手用で持ち手モデルの向き (または鏡像) を分けるか、手ごとに回転オフセットを持たせる。

## 完了条件

- [ ] 右手・左手それぞれで持ち手が握った手の向きに沿う (PCVR で確認)
- [ ] 片手 3 匹のときも持ち手は手ごとに 1 個のまま
- [ ] Desktop/Touch の見た目を悪化させない
