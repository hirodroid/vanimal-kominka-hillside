# IMP-DOG-045 — リードを持つと犬が台へ寄ってくる

2026-10-10 ユーザー採用・実装依頼。実装、シーン配線、Editor検証、独立レビュー済み。Play・VRChat実機は未確認。

## 採用仕様

- 入口・見晴らし・広場の3か所。台から水平5m以内で誰かが未接続のリード先端を持つと、台から水平25m以内の空いている犬が寄る。25mは入口洗い場の呼び寄せと同じ距離感。
- 人について移動せず、台の犬側約1.7〜2mに分散して待つ。犬ごとに0.25〜1秒の反応差を付け、着いたら保持者を見る。待機位置は犬ごとの固定スロット。
- 複数人・複数の先端は台ごとにOR。誰か1人が持ち続けていれば継続。最後の保持者が放す・5mを離れると5秒の余韻後に自由行動へ戻る。接続した犬は既存の散歩へ移る。
- 散歩・洗浄・撫で・おやつ・Fetch・フリスビー・集合参加・呼び寄せ・ライブ・水遊び・水飲みを優先する。集合に参加していない犬は対象にできる。
- 初回案内の完了や有効設定とは無関係な常設の反応。専有・集合予約を立てないので、近づいた犬へそのままリードを接続できる。

## 実装

- `KH_LeashClip.cs` が取った台を記録。`KH_LeashManager.Invitation.cs` がローカル保持を集計し、既存ManagerのOwnerへ報告する。発信者はCallingPlayerで確認し、Ownerでも台との距離を確認する。
- 同期するのは台ごとの期限・視線相手・犬の割当・開始時刻。Managerや犬の所有権を保持者へ移さない。移動は既存の犬Ownerだけが行う。
- 保持報告は1秒間隔、消失判定は3秒。通常解除は5秒。報告消失時はTTL 3秒＋余韻5秒の設計値で失効し、0.5秒maintenanceや通信の検出遅延が加わる。Owner交代では3秒再構築し、引き継いだ情報だけで期限を延長し続けない。
- `KD_DogWanderController.HillsideInvitation.cs` と既存の本体・Performance・Tickへの小さな差込で行動を選ぶ。既存の完全NavMesh経路を利用し、経路失敗時に直進やワープをしない。
- `KH_LeashInvitationEditor.cs` が18点を事前計画してから配線。待機点はNavMesh上、洗い場の進入禁止半径＋0.3m外、互いに0.72m以上離す。新規UdonBehaviour・入力Collider・表示物は追加しない。

## 実機確認（未実施）

| 場面 | 期待する結果 |
|---|---|
| 各台で先端を持つ | 近くの空き犬が少しずつ寄り、台の犬側で重ならず待つ |
| 首輪へ接続する | 接続操作を邪魔せず、その犬だけ通常の散歩へ移る |
| 2人で同じ台の先端を持ち、片方が放す／退出する | 残った保持者の誘いが続く |
| 両手で持ち、片方だけ放す | もう片方の保持で続く |
| 全員が放す／台から離れる | 約5秒後に自由行動へ戻る。再取得すれば継続する |
| 他の遊び・撫で・水飲み中 | 進行中の関わりを中断しない。遠方の集合の非参加犬は寄れる |
| Ownerが退出・途中参加 | 誘いを再構築でき、保持者がいなくなった誘いが残り続けない |
| 斜面・障害物・別の台 | 歩ける経路で寄り、壁抜け・ワープ・台間の往復をしない |
