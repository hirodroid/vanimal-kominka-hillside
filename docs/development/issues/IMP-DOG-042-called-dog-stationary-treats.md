# IMP-DOG-042 — 呼んだ犬に、その場に留まったままおやつをあげる

2026-10-08 ユーザー依頼。今回はIssueと資料の更新のみ。Unityへ接続せず、コード・翻訳データ・シーンは変更していない。実装・動作確認は未実施。

## 要望

呼んだ犬が動かないことは維持し、呼んだ本人がおやつをあげられるようにする。おやつへ歩かせたり、呼ぶを解除したりすることを給餌の前提にしない。

[IMP-DOG-016](IMP-DOG-016-call-pose-port-and-slope.md)には、呼ぶ／ポーズの移植と寝ている犬をおやつ候補から除外する旧契約がある。今回の要望は呼ばれて待機する犬への給餌を追加するもの。睡眠と待機を同一の拒否条件で扱わないよう設計を整理する。

[IMP-DOG-041](IMP-DOG-041-hand-feed-treats.md)は手持ちおやつを口元で受け取る機能で、現在review。その実装・確認記録を本票の「呼ぶ中もその場で食べる」の完了証拠に流用しない。リード中の呼び寄せ（IMP-DOG-006）とも分ける。

## 要件

- 呼ばれて到着し待機中の犬へ、呼んだ本人が口元におやつを差し出せる。給餌のために指定位置から歩かない。
- 選んだポーズと呼ぶ状態を維持する。食べる返事に必要な一時的な動作とポーズ復帰の方法は設計時に詰め、勝手に自由行動へ移らない。
- 離れたおやつや他人のおやつで連れ出されない。呼び出し途中・実際の睡眠・撫で手が別人の場合の受付範囲は未決として別に整理する。本人の給餌対応は採用要望。
- 手渡し・回収・在庫の消費回数と他犬への割当が競合しない。既存のリード／洗浄などの利用条件を無条件に解除しない。

## 完了条件

- [ ] 呼ぶ→到着→本人が差し出す→その場で食べる→同じ待機・ポーズへ戻る、が採用ポーズごとに成立する。
- [ ] 遠い餌を追わず、他人の餌で占有・場所を奪われない。複数人・複数犬で確認する。
- [ ] 給餌中の解除・ポーズ変更・退室・Owner交代でも二重消費・餌の復活・犬の状態残留がない。
- [ ] 通常の手渡し／地面食べ／リード中の挙動への影響を確認し、実機未確認を分けて記録する。
