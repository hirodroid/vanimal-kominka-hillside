# IMP-DOG-029 汚れの発生と清潔の余韻

親は [IMP-DOG-024](IMP-DOG-024-walk-and-wash-experience.md)。方式は [設計書](../../plans/2026-09-30-dog-wash-design.md) §1-9、§8 (川の既定値)、§6。依存は [IMP-DOG-026](IMP-DOG-026-wash-state-and-sync.md)。数値は試作値で、代表の試作 ([IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md)) では設定した初期値を使う。

## 範囲

やること。

- Owner がセルの汚れを増やす。部位ごとの係数表 (足 4 本 → 腹 → 胴の順に汚れやすい)
- きっかけ: リード接続中と Fetch / フリスビー中の移動距離、土・泥の採用地点での滞在、川に入った時の足の汚れの少しの減少と濡れ
- 川だけでは清潔にしない (未決定事項の既定値。ユーザーが違う指定をすれば変える)
- 猶予: 洗い終えてから 120 秒、門の外の待機範囲にいる間は汚れない
- 汚れの模様 (ノイズ) を掛けて増やす表現。泥の場所の指定は環境側の設定として持つ

やらないこと。セルの正本・清潔の判定は [IMP-DOG-026](IMP-DOG-026-wash-state-and-sync.md)。洗う操作は [IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md)。泥の場所の配置は [IMP-ENV-008](IMP-ENV-008-wash-stations-along-course.md) と道中の採用地点の決定。汚れの永続保存・ワールド間の持ち越し。洗浄スコア。

## 完了条件

AI 側で確かめる。

- [ ] コンパイル完了とエラー 0
- [ ] ClientSim ハーネスで、リード接続中の移動距離・土や泥の範囲・川に応じて汚れのセルが増減し、係数表の順 (足 → 腹 → 胴) になっていることを確認した
- [ ] ハーネスで、洗い終えてから猶予の間と門の外の待機範囲では汚れが増えないこと、猶予が過ぎると増えることを確認した (親: 洗い場から数歩で汚れ直さない)
- [ ] ハーネスで、川に入っても清潔にならない (既定値どおり) ことを確認した
- [ ] 汚れの発生の増分が Owner だけで行われ、同期の頻度が 1〜2 Hz に収まっていることを確認した

ユーザーが確かめる (Play / PCVR)。

- [ ] 散歩や土・泥遊びで汚れた犬が、洗った後に普通に過ごす間は清潔な余韻を保つ。次の散歩や土・泥遊びで汚れる (親: 汚れる理由と余韻)
- [ ] 汚れを罰や義務に感じない。洗わなくても散歩・遊びを続けられる
- [ ] 300 m で足が半分などの試作値の体感を評価し、調整値を記録した

## 記録

2026-09-30: 起票。実装は未着手。

2026-09-30: 実装。Owner だけがセルの汚れを増やし (2 秒に 1 回、変化があった時だけ)、部位ごとの平均の変化を NetStroke (道具 3 = 汚れ) で全員へ送って部位マスクで足す (Restore の塗り直しは洗った帯を消すので採らない)。きっかけ: リード・Fetch・フリスビー中の移動距離 (300 m で足 0.5)、泥の地点 (半径 2.5 m の Transform を 2 か所: 奥広場の縁、水遊びの入口の岸。10 秒で足 0.5・胴 0.2)、川 (30 秒で足 −0.3、下限 0.15。濡れが付く)。猶予: 清潔から 120 秒 (`cleanMs` を同期し、Owner が替わっても続く)、洗い場から 6 m 以内。川で減った後は洗うストロークが入るまで清潔の合図を出さない。ビルダー `Wash/20` / `21` (28 項目 PASS)。調整値はすべて public。**試作の初期の汚れ `initialDirt` (0.6) は本番で 0 にする** (Wash/11 の値)。ハーネス W-dirt-zone / walk / grace / station / river を追加 (結果は次の記録)。

2026-09-30 (Codex レビュー後): 汚れのイベントに犬ごとの通し番号 `dirtSeq` を付けてセルと同期し、Restore の後はセルに無いものだけを描き直す (二重加算・消失の防止)。新しい Owner はセルに無い記録を積算し直す (旧 Owner のイベントは交代から 5 秒受け付ける)。川の抑制 `riverBlocksEdge` を同期。洗い始め・清潔・猶予中・洗い場の近くでは貯めた汚れを捨てる。犬ごとに足す時刻を 0.3 秒ずらし、汚れの描画は 1 匹 1 フレーム 2 回まで。ハーネス W-dirt-restore / W-dirt-boundary を追加。

2026-09-30 (ClientSim、run 20260930-051545、Course/100 46 ケース): 44 PASS / 2 SKIP (2 人が要る W-leash-other / W-react-remote)。W-dirt-zone (10 秒で足 0.51・胴 0.20、外では増えない) / walk (リードで 30 m 歩いて足 0.52。係数は 1/10 に短縮) / grace (清潔の後は増えず、猶予が過ぎると増える) / station (洗い場の近くでは増えない) / river (足 0.4 → 0.15 で止まり、濡れる) / restore (Restore で二重にも消えもしない) / boundary (洗い始めで貯めた分を捨てる) PASS。疑似の入力で、実通信・Play は未確認。

2026-09-30 ユーザーの PCVR 確認: 「汚れ方はもう少しゆっくりでもいい。洗ったのに散歩ですぐ汚れる。どれくらいがいいかは難しい」。統括の目安 (1 周 2.4 km を 25〜30 分で歩く前提): 散歩で足が半分汚れる距離 300 → **900 m** (約 10 分)、泥の地点で足が半分 10 → **25 秒**、清潔の後の猶予 120 → **300 秒**。値は public で、Play の感触で調整する。

2026-09-30: 汚れの調整値の表 `DirtTuning` (KH_DogWashSetupEditor.Dog.cs) を Wash/11 が書き、Verify がシーンの値と照合する。散歩 900 m / 泥 25 秒 / 猶予 300 秒で組み立て直し (753 項目 PASS)。ハーネス 47 ケース 45 PASS / 2 SKIP (run 20260930-100251)。Play での感触は未確認。
