# IMP-UI-007 洗い場の追加フォントを共通フォントとVRChatフォールバックへ置き換える

2026-10-13 ユーザー依頼。フォント追加を原則避け、VRChatのフォールバックを基本とする。独自書体が不可欠な限定用途だけ必要文字をStatic化する。[共有規約](../../../../../vrc-world-agent/claude-skills/vrc-world-ui/SKILL.md)を正本とする。

## 対象と方針

- 10-08の洗い場プレミアム対応で追加した `CareFont` / `CareLatin` と `NotoSerifCJKjp-Regular.otf`、それらの生成・使用箇所を対象にする。洗い場の13言語の文言と操作を維持し、既存 `KD_NotoSerif SDF` を利用、未収録字はVRChatクライアントのフォールバックへ委ねる。専用フォントを再生成しない。
- `kh-fonts 21.59 MB` は元フォントも明示的に含む分類別バンドルの値で、実シーンから減る容量の保証ではない。[容量記録](../../plans/2026-09-24-build-size-audit.md)を参照。元ファイルサイズ、分類別容量、シーン全体の圧縮容量を分ける。
- 既存の共通フォントや表示名フォント全体の刷新、毛色テクスチャの削減は今回の範囲外。新しいフォントの購入・ダウンロードはしない。

## 完了条件

- [x] 洗い場の専用フォント/マテリアル参照を既存共通フォントへ移行し、旧フォントの欠落参照を残さない
- [x] 作成処理を再実行しても専用フォントが復活せず、共通フォントの字形を勝手に増やさない
- [x] 元OTFと不要専用アセットを参照ゼロ確認後に除去し、保存後の依存とコンパイルを検査
- [x] 画像制作の経路とフォント検査を整合させ、Editor欠字とクライアントの表示を区別
- [x] 同条件の容量比較を記録し、分類別容量を実ダウンロードの削減量と混同しない
- [ ] PC/Quest等の対象端末で、洗い場の13言語・5タブ・状態文言の字形と枠内収まりをユーザー確認

## 作業記録

開始時点: CareFontは既にStatic、実行時元フォント参照はnull。Editor用参照がCJK OTFを指しており、分類別計測の5ファイルに元OTF/TTFが含まれている。専用フォントの追加自体を撤回し、既存共通フォントへ寄せる。Editorで全文字が焼かれていることを新しい合格条件にはしない。

2026-10-13 実施:

- `WashPremium/43 - Apply Shared Font` で4洗い場・76ラベルの主フォントと共有マテリアルを置換。自動保存・字形追加はしない。対象シーンを明示保存し、別の `51 - Verify Font Policy` で文言・非表示ラベル・副メッシュ・保存済み依存・旧GUID残存を確認。再適用は `changed=0`。
- CareFont / CareLatin / 元CJK OTFと対応metaを削除。削除前後の保存シーンで旧3GUIDゼロ、削除後のAssets内のunity/asset/mat/prefabでもゼロ。共通フォント、13言語words.json、既存商品PNG25枚の計27ファイルのSHA-256は前後一致。
- 41の商品画像作成では共通フォントを拡張しない。例外用途は**Editorで文字をPNGへ焼く撮影のみ**。既存NotoSerifJP-Regular.ttfから実キャプション96文字だけの非永続Static（1024² / 48pt）を作り、全字とsource nullを確認してから撮影し、finallyでfont/material/atlasを破棄する。配布用アセットを作成しない。生成前に不足があれば既存PNGを保持して停止する。
- `52 - Preview Listing Font` で全キャプション96文字収録、Static・source null・非永続を確認。Tempへの代表1枚を目視し、実行後の一時資産残存なし、シーンdirtyなし。既存商品画像は再生成していない。下線用字形の警告は撮影に下線を使わないため表示へ影響せず、予備文字を追加していない。
- C#コンパイルはエラー0。ランタイム/Udonコード変更なし、Playや実機確認は未実施。独立担当Codexの読取レビューを実施し、削除後の壊れたGUIDを直接検出する検査と旧コメントを修正。写真撮影専用の一時Staticの用途分離・例外時破棄に必須指摘なし。
- シーン差分は76ラベルのfont/materialだけをコミット対象にする。既存他セッション差分と、保存時に再計算された `m_IndirectSpecularColor` は含めない。

### 容量比較（今回の同条件測定）

Unity 2022.3.22f1、Android/ASTC、保存済み本番シーンを既存Build Size/2で圧縮/非圧縮バンドル化。今回Import設定のApplyはせず同じ設定を使用。各回で旧出力を消す既存手順、更新時刻と新規出力を確認し、変更後は両バンドルのCRC取得も成功。

| 対象 | 修正前 | 修正後 | 減少 |
|---|---:|---:|---:|
| 圧縮 | 78,070,794 B（74.45 MiB） | 77,610,126 B（74.01 MiB） | 460,668 B（約0.44 MiB） |
| 非圧縮 | 227,675,008 B（217.13 MiB） | 223,151,488 B（212.81 MiB） | 4,523,520 B（約4.31 MiB） |

過去の71.26 MBはImport設定Apply後の別測定なので今回の比較元にしない。`kh-fonts 21.59 MB` は元フォントも明示的に束ねた分類別の値であり、元OTF削除による実シーンの削減量ではなかった。分類別バンドルの再測定はしていない。SDKアップロード容量・端末メモリ・fpsの測定ではない。

代理計測の内部ログには `Build Finished, Result: Failure` も出ている。既存測定関数は新規バンドルを出力し、上記はそのファイルサイズとCRCの確認結果だが、内部結果表示の理由は未切り分け。SDKの正式ビルド成功とは扱わず、実機確認用ビルド時に確認する。
