# IMP-DOG-037 洗い場で呼べる犬の表示と距離・エリア制限

## 依頼

2026-10-02 ユーザー指定: 洗い場のボードで、呼べる犬と呼べない犬を分かりやすくする。誰かと遊んでいるなら「遊んでいるので呼べません」、遠ければ「遠すぎます」のように理由を知らせる。

また、川そばの洗い場から古民家側にいる犬まで呼べるのは避けたい。その洗い場の周辺エリアにいる犬だけを呼べるようにする。具体的な距離は未指定。

## 範囲

- 犬ごとのボタン・行で「呼べる」「呼べない」と理由が分かる表示にする。色だけに頼らず短い文や記号を併用する。押せない状態でも理由を読めるようにする
- 理由の候補は「他の人と遊んでいます」「他の人と散歩中です」「遠すぎます」等。既存の行動・利用権の判定に対応させ、同時に複数の理由があるときの優先順も決める
- 呼び出し範囲は洗い場と犬の位置を基準にする。最大距離、エリア判定、またはその組み合わせを比較し、主洗い場・川辺・広場・裏山それぞれで自然な範囲を決める
- 範囲外の犬は要求自体を受け付けない。既存の「遠い犬を近くへ移してから歩かせる」動きで距離制限をすり抜けないようにする
- 表示後に犬が移動したり遊び始めたりした場合も、要求を受理する側で最新の状態を再確認し、拒否された理由を操作した人へ返す
- 犬の移動・行動終了に追従して表示を更新する。追加の毎フレーム全頭走査を前提にせず、既存の更新周期と軽量化方針に合わせる

## 既存の呼び出しとの関係

基本の呼ぶ・留める・解放する機能は [IMP-DOG-035](IMP-DOG-035-wash-call-dog-to-station.md)、設計は [洗い場の呼び出しと高さ](../../plans/2026-10-01-wash-call-and-height.md)。本 Issue は追加の可否表示と受理範囲を担当する。

2026-10-01 に決定済みの「水遊び中の犬も呼べる」は維持する。**近くで自由に水遊びしている犬**は岸へ上がって来られるようにし、他人との遊びや Fetch / フリスビー中の犬とは区別する。範囲内で受理した後の到着補助・上陸待ちの扱いは、距離制限と矛盾しないよう設計時に整理する。

## 完了条件

- [ ] 犬ごとに呼べるかと呼べない理由が、ボードを見て分かる
- [ ] 近くの空いている犬は呼べ、遠い犬には「遠すぎます」等が表示され、犬は移動しない
- [ ] 川そばから古民家側の犬を呼ぶ例を含め、4か所の洗い場で範囲内・境界・範囲外を確認する
- [ ] 他人と遊んでいる/散歩中の犬に割り込まず、理由を表示する。近くの自由な水遊び中の犬は呼べる
- [ ] 表示後の状態変化・2人の競合でも、表示と受理側の規則が一致する
- [ ] PCVR / Desktop / Touch で理由を読め、距離・判定・表示の決定を設計書へ反映する
