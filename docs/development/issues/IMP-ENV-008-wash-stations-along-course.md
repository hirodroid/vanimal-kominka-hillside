# IMP-ENV-008 複数ポイントへの洗い場の展開

親は [IMP-DOG-024](IMP-DOG-024-walk-and-wash-experience.md) (実装順 4「複数ポイントへ展開」)。設計書 [§6](../../plans/2026-09-30-dog-wash-design.md) の分割表と、親 Issue の「洗い場と散歩の導線」の表が根拠。設計書は複数地点の方式を新たに定めていないので、共通処理を配置するだけを前提にする。依存は [IMP-ENV-007](IMP-ENV-007-main-wash-station.md)。

## 範囲

やること。

- 川辺・広場・裏山の要所のうち、採用する地点の数と位置の決定 (導線・負荷・制作量を見る)。各地点の利用する理由、岸の安全、既存の入水・泳ぎ・回収との切替、おもちゃの回収範囲との干渉、他の洗い場との間隔、傾斜・犬種別の届きやすさ
- 主洗い場と同じ洗浄処理・道具・ビルダーの型で配置する。水の出方や小物の差は設定・配置で表す。洗浄ロジックや犬を地点ごとに複製しない
- 道具の戻し先と、地点を跨いだ時の道具・汚れの扱い
- ビルダーを `Tools/KominkaHillside/Course/NN` に Build と Verify の組で足し、[production.md](../../plans/des-env-002/production.md) へ登録する

やらないこと。洗浄の処理の変更 ([IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md)〜[IMP-DOG-030](IMP-DOG-030-wash-six-dogs.md))。門の外の主洗い場 (IMP-ENV-007)。古民家の建物・室内・別ワールドへの持ち越し。端末別の実測 ([VER-DOG-002](VER-DOG-002-wash-experience-and-devices.md))。

## 完了条件

AI 側で確かめる。

- [ ] コンパイル完了とエラー 0。Course の Verify が通り、Build の再実行で配置が増えない
- [ ] 採用した地点の数・座標・採用理由 (採らなかった候補の理由を含む) を記録し、production.md の表へ登録した
- [ ] 全地点が同じ洗浄コンポーネントと道具のプレハブ相当を参照し、犬・洗浄ロジックの複製が無いことを Verify で確認した (親: 別系統に複製していない)
- [ ] ClientSim ハーネスで、別地点へ移った犬のセル・道具の状態が保たれることを確認した (可能な範囲)
- [ ] 既存の入水・泳ぎ・回収・周回のハーネスが退行していない

ユーザーが確かめる (Play / PCVR)。

- [ ] 入口前と採用した道中の地点で、同じ操作が成立する (親: 複数地点)
- [ ] 各地点で開始と道具の戻し先が初見で分かる。散歩の流れを止めず、洗うか通り過ぎるかを選べる
- [ ] 地点を移っても、汚れと道具の扱いが自然に保たれる
