# IMP-DOG-039 シャンプーのボトル + 手で洗う

## 依頼

2026-10-03 ユーザー: 「あれ？洗うの？手で洗うモードにしたんだけど、あれは？」。検討は [DES-DOG-007](DES-DOG-007-hand-washing-and-shampoo.md) (10-02、推奨案: ボトル + 手を主役、スポンジも残す)。同 Issue の「決定: 2026-10-03」で採用。親は [IMP-DOG-024](IMP-DOG-024-walk-and-wash-experience.md)。

## 作るもの (DES-DOG-007 の推奨案)

1. **ボトル**: 各洗い場の棚に 1 本。持って口を犬へ向け Use を押すと、当たった所に見える泡がすぐ付く
2. **手洗い**: 洗い場の犬の、泡が見える部分を空いた手 (道具を持っていない手) でこすると泡が増えて広がる。片手で成立、両手も可。泡が無い所を触るのは今までどおり撫でる (勝手に泡を出さない)。すすいだ所は触るだけでは泡が戻らない
3. **すすぎ・タオル**: 現行のまま
4. **スポンジ**: 残す (Desktop / スマホの第一段階の経路でもある)
5. **図解**: 洗い場の操作ボードの上か隣に、読む専用の 3 コマ「① 泡をつける → ② 手でわしゃわしゃ → ③ シャワーで流す」。ビルダーの生成対象にする (再生成で消えない)

## 設計で決めること (DES-DOG-007「ソースから分かった実装上の制約」)

- 素手の位置の取り方 (既存の撫でと同じ手の位置) と部位 Collider への当て方、処理を洗い場の近くの犬だけに絞る方法
- 接触の履歴を左右の手・道具ごとに分ける (離れた手の間に泡の線が引かれない、片手を離してももう片手が切れない)
- 他人から届くストロークの検査 (今は「道具を保持している」こと)。素手の経路の開始条件・距離・送信量・状態の検証。既存の保持検査を単純に外さない
- 撫で反応・首輪の操作との区別
- 同期変数・送信量を増やすかどうか、途中参加と Owner 交代
