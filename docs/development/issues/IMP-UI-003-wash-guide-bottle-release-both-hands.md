# IMP-UI-003 洗い場の説明でボトルを離して両手で洗う流れを伝える

## 依頼

2026-10-03 ユーザー: 洗い場の説明の雰囲気はとてもよい。ただし、泡をつける場所は背中限定ではなく犬のどこでもよく、ボトルを離して両手で洗う。足りなくなったらまたボトルで泡を足すことまで分かるようにしたい。

## 案内する流れ

1. **犬に泡をつける** — 背中だけに限定せず、洗いたい場所につける。
2. **ボトルを離す** — 泡をつけたら両手を空けることを独立した手順で見せる。
3. **両手でわしゃわしゃ洗う** — ボトルを持ち続けて片手だけで洗う印象をなくす。
4. **泡が足りなければ、ボトルで足してまた洗う** — 追加して繰り返せることを短い説明と写真で示す。

## 作業範囲と関連

- 洗い場の上にある説明を更新する。現状の好評な雰囲気を活かし、本文・見出し・図の食い違いをなくす。
- 実際のワールドでボトル・犬・両手の操作を撮影し、手順が見て分かる説明にする。写真の制作・案内全体の配置は [IMP-UI-002](IMP-UI-002-guide-board-capture-instructions.md) と合わせる。
- 手洗いの実装は [IMP-DOG-039](IMP-DOG-039-hand-wash-with-shampoo-bottle.md)。本件は案内の改善であり、片手でも洗える機能を削るものではない。案内と実挙動に差があれば実装側へ記録する。
- VRの両手操作と Desktop / Touch の既存操作を混同させず、すすぎ・タオルへの案内ともつなげる。対応する多言語文言も同じ意味に揃える。
