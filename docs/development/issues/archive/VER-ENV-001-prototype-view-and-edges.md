# VER-ENV-001 試作: 眺め・移動・端の見え方・実機負荷を確認する

企画原本 §9 の着手依頼。簡単な地形・軽量化した古民家の外観 (仮)・犬を置いた試作で、次の 3 点を優先して確かめる。

1. 山から古民家が見える
2. 犬と無理なく遊べる
3. 小さな空間でも散歩した感じがする

`core-concept.md` §3 の代表シーン検証も兼ねる (仮決め → 本制作基準への更新はこの結果で判断)。

## 作るもの (最小)

|---|---|
