# IMP-DOG-036 リードの犬の判断を間引く (足は毎フレーム)

親: [IMP-DOG-034](IMP-DOG-034-dog-udon-tick-thinning.md) の段階 3 C2-5。**2026-10-01 にユーザーが別 Issue へ切り出し、別で対応すると決定。** 034 の他の項目 (汚れの反映 20 秒・初期汚れ 0・同じ持ち手の犬は押し出さない・リードの直線化) とは独立に進める。

## 決定 (2026-10-01 ユーザー)

- 「毎フレームはコストが高すぎる。**fps が低いときに限らず、5 フレームに 1 回ぐらいで全然よい**」
- 足の動きは毎フレームのまま (犬がカクつかないこと)

## 背景

Quest 3 (段階 3 C-1 の前): 待機 35 fps、6 匹をリードで歩くと 20 fps、犬の Udon 全停止で 60〜70 fps。リードの犬は `TickBusy()` が `_wasLeashed` で true を返すので、段階 1 の間引き (待機中だけ) の対象外で、毎フレーム全部の判断を回している。再棚卸し ([walk.md §4](../../_sessions/udon-audit-2026-10-01b/walk.md)、git 管理外) の概算では、歩く犬 1 匹あたり判断側が約 510 extern、足だけなら約 70。C-1 の後は判断側が約 230〜300 に減っているので、効果の見積もりは実装前に数え直す。

## 設計

**周期**: 判断は **5 フレームに 1 回** (犬ごとに `dogIndex` で位相をずらし、6 匹が同じフレームに集まらない)。fps が低いときに反応が遅くなりすぎないよう、**間隔が 0.2 秒を超えない**上限を付ける (20 fps なら 4 フレーム)。fps 連動の条件は付けない (常時)。

**分け方**

| 毎フレーム (足、Owner) | 5 フレームに 1 回 (判断) |
|---|---|
| `LeashGo` の角の前進、`StepToward` (旋回・加減速・前進・`SnapToGround`)、`Coast`、`FaceTowards*`、`ApplyMoveAnim` | リード・飼い主・手の位置、`TrackHolderSpeed`、行き先・到着、`SampleHolder` |
| `AnimatorYielded` の確認 (Fetch / ディスクが根元を取ったら書くのをやめる) | 返る・待つ・休む・誘う・寄り道・立ち寄り・先導の**モード選択と目標・速さ** |
| 視線・尻尾の再提示 (下の握手) | `LeashPose` (伏せ・座る・嗅ぐ・見つめる)、洗い場・洗浄・水・移動切符の監視、経路の引き直し (NavMesh) と壁の確認 |

足のためにキャッシュするもの (Owner ローカル、同期しない): 足のモード (進む / 惰性 / 惰性 + 向く)、目標・速さ・止まる距離、経路の角、向く先と旋回の速さ、視線の対象と尻尾の強さ。段階 3 C-1 の「立ち止まりの高速経路」(`LeashStandFrame`、判断 5 Hz) が同じ形を止まっている犬に対して既に持っているので、歩行にも広げる形で統合する。

**壊れやすい所 (握手) と扱い**

| 握手 | 単純に間引くと | 扱い |
|---|---|---|
| `_SetGaze` / `_SetUrge` / 顔 (そのフレームだけ有効。`KD_DogPetController`) | 頭と尻尾が 1 フレームおきに戻って明滅 | 足のフレームからキャッシュした対象で毎フレーム再提示する (C-1 の高速経路と同じ)。または撫で側に有効期間 (`_SetGazeFor(…, frames)`) を足す |
| `_washLastFrame` (洗浄の入場・満足の打ち切り) | 洗われているリード犬で毎 tick が「新しい入場」になる | **洗われている・洗い場に留められている間は間引かない** (毎フレーム) |
| `_waterSeenFrame`、`_waterFetchFrame` ほか水の握手 | 水遊びが「割り込まれた」と判断される | 水の状態・拒否 (`_waterLeashVeto`)・泳ぎの高さが残っている間は間引かない。RC-14 (水の中で初めて見たリードは受けない) はリード接続フレームで即時判断 |
| `Dt()` (飛ばした分を積算する dt) | 足が毎フレーム動かしているのに、判断 tick が積算 dt で動かすと**二重に進む** | 移動系は `MoveDt()` (そのフレームの `Time.deltaTime`)、判断の積分 (飼い主の速さ、姿勢の時計) は積算 dt |
| `TrackHolderSpeed` の「1 m 以上はテレポート扱い」 | 判断の間隔が伸びると、走る飼い主を誤ってテレポートと見なす | 距離ではなく速さ (10 m/s 超) で判定 |
| Fetch / ディスクへの引き渡し、解除、移動切符、ワープ | 足が古い目標へ 1〜4 フレーム歩き続ける | 足の先頭で `AnimatorYielded()` を毎フレーム確認。解除・切符・ワープで足のモードを 0 に |
| 非 Owner | 位置は VRCObjectSync で来るので足は不要 | 非 Owner は tick 全体を同じ周期に落とす (視線の再提示だけ毎フレーム) |

**見え方 (最悪)**: 飼い主が止まる・曲がる・歩き出すへの犬の反応が最大 5 フレーム (72 fps で 0.07 秒、30 fps で 0.17 秒、上限 0.2 秒) 遅れる。先行の行き過ぎは歩きで最大約 0.2 m。リードの紐は首輪が毎フレーム実距離で描くので破綻しない。嗅ぐ・座る・見つめるの出入りが同じだけ遅れる (ヒステリシスがあるので明滅しない)。
