# IMP-DOG-007 リードを引っ張られたら振動する (Haptics)

## 要望

2026-09-20 ユーザー要望: 「リードを引っ張られたら振動してほしい。Haptics」。

犬にリードを引っ張られた感覚を、リードをつないでいる側の手のコントローラー振動で伝える。今回は要望の登録であり、判定方法・振動の強さや長さ・端末別対応は実装時に具体化する。

## 想定する体験

- 犬が先へ行こうとしてリードを引っ張ると、そのリードを持つ側の手に振動が伝わる。
- リードが緩んでいるときや、接続を解除した後は振動しない。
- 左右の手と接続犬に対応し、他の人のリード操作では自分の手が振動しない。

## 実装前に決めること

- 「引っ張られた」の判定: 手と犬の距離・リードの張り・犬の移動状態など、既存の散歩挙動から何を使うか。単なる追従遅延や瞬間移動との区別。
- 振動の強さ・長さ・間隔と、引っ張り続けた場合の扱い。片手最大3匹・合計6匹で過剰な振動にならないまとめ方。
- 振動の有効・無効や強度調整の必要性、PCVR・Quest単体などでの対応と実機確認。振動を使えない端末でも散歩が成立すること。

既存仕様ではリードの絡まり・引っ張り合いを物理シミュレーションしない。Haptics の判定・演出はこの前提で検討する。接続成功時の通知振動とは別の要望として扱う。

## 完了条件

- [ ] 引っ張りの判定・振動パターン・対象端末を決め、仕様の正本へ反映した
- [ ] リードを引っ張られた際、接続している本人の対応する側の手に振動が出る
- [ ] 緩み・解除時に振動が止まり、他人の接続犬や瞬間移動で意図しない振動が出ない
- [ ] 左右それぞれ・片手複数匹・両手合計6匹で、振動の対応と重複時の挙動を確認した
- [ ] 対応端末のユーザー実機確認結果を記録し、振動を使えない端末でも散歩に支障がないことを確認した
