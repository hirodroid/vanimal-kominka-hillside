# IMP-DOG-007 リードを引っ張られたら振動する (Haptics)

## 要望

2026-09-20 ユーザー要望: 「リードを引っ張られたら振動してほしい。Haptics」。

犬にリードを引っ張られた感覚を、リードをつないでいる側の手のコントローラー振動で伝える。今回は要望の登録であり、判定方法・振動の強さや長さ・端末別対応は実装時に具体化する。

## 想定する体験

- 犬が先へ行こうとしてリードを引っ張ると、そのリードを持つ側の手に振動が伝わる。
- リードが緩んでいるときや、接続を解除した後は振動しない。
- 左右の手と接続犬に対応し、他の人のリード操作では自分の手が振動しない。

## 実装前に決めること (2026-09-22 決定・実装)

- **「引っ張られた」の判定 = 伸び比率と、止まっている時の引き。** 紐の張力は存在しないので、手と首輪の**水平**距離 ÷ リード長 (`ratio`) と、その距離が伸びる速さ (`away` m/s) で測る。高低差を無視するのは、斜面の下にいる犬を「引っ張り」と誤認しないため。
  - **伸び (stretch)**: `ratio >= 1.0` かつ `away > 0` — 張ったまま、まだ伸びている。強さは `ratio` 1.0 → 1.25 で 0.3 → 1.0 に上がる (1.25 は犬自身が戻り始める比率)。短いパルスを 0.12 s 間隔。
  - **止まっている時の引き (still-pull)**: 自分の移動が 0.4 m/s 未満 (EMA τ 0.3 s) で `ratio >= 0.85`・`away >= 0.3` — 立ち止まっているのに犬が離れていく。強さ 1.0、0.15 s を 0.5 s 間隔で「グイッ」。同じ手では tug がパルスに優先する。
  - **区別する物**: 追従遅延 (伸びていない = `away <= 0` は鳴らない)、瞬間移動 (1 フレーム 1 m 超の移動は速度・距離履歴ごと破棄)、接続直後 (前フレームの距離が無い 1 フレームは鳴らさない)、他人の接続犬 (`_IsMine` のみ)。
- **まとめ方 = 手ごとに最大。** 毎フレーム、その手につながれた犬のうち最も強いモード・最大の強さを 1 つ選び、手ごとに 1 回だけ振動させる。片手 3 匹でも振動の回数は 1 匹のときと同じで、強さだけが上がる。振動を鳴らす場所はこの 1 スクリプトだけ (Verify で担保)。
- **端末 = VR の手だけ。** `IsUserInVR()` のときだけ動く。Desktop/Touch の手は実体のない身体基準の位置なので判定に使わない (振動先も無い)。Quest 単体・iOS の実機確認は [VER-WLD-001](VER-WLD-001-quest-ios-devices.md) に集約する。有効・無効は `hapticsOn` (Inspector) で、後日メニューの設定項目にできる。強度調整の要否は PCVR の評価後に判断する。

既存仕様ではリードの絡まり・引っ張り合いを物理シミュレーションしない。Haptics の判定・演出はこの前提で検討する。接続成功時の通知振動とは別の要望として扱う。

## 実装 (2026-09-22、Editor 検査済み・Play 未)

- `Assets/KominkaHillside/Scripts/KH_LeashHaptics.cs` (新規。`BehaviourSyncMode.None`、ローカル専用、同期変数も犬も触らない)。マネージャと同じ `KH_Leashes` の下に 1 個だけ置き、Build が配線と調整値を書く。
- 調整値 (すべて public、Build が上書き): `pullRatio 1.0` / `pullFullRatio 1.25` / `stillSpeed 0.4` / `stillPullRatio 0.85` / `awaySpeed 0.3` / `pulseInterval 0.12` / `pulseDuration 0.08` / `tugInterval 0.5` / `tugDuration 0.15` / `minAmplitude 0.3` / `frequency 0.5` / `teleportJump 1.0`。
- 記録用に、鳴らした瞬間のログを手ごとに 1 秒 1 行まで出す (`logPulls`): `[KH_LeashHaptics] hand=L dog=2 ratio=1.12 away=0.8 holder=0.2 mode=tug amp=1.00`。
- Walking Verify 197 項目 失敗 0 (13 項目追加)。コンパイルエラー 0、コンソール Error 0。

## Play チェックリスト (ユーザー担当・PCVR)

準備: PCVR で入り、リードを 1 匹つなぐ。Console を `[KH_LeashHaptics]` で絞ると `ratio` / `away` / `holder` が読める。すべて試作値なので「合格/不合格」より**どう感じたか**を残す。

- [ ] 犬が先へ行って紐が張ったとき、持っている側の手が**グイグイ**来る (強さが張りに応じて上がる)
- [ ] 自分が立ち止まっているのに犬が離れていくとき、**グイッ**と来る (パルスとは違う手ごたえに感じるか)
- [ ] 紐が緩む・犬が待つ・追いついたら止まる (歩いているだけで鳴り続けない)
- [ ] 解除した後、他人がつないでいる犬、他人が引っ張っているときに鳴らない
- [ ] 片手 3 匹 (+ 両手 6 匹) でうるさくない・強すぎない。左右が正しい手に来る
- [ ] リスポーン・拠点への瞬間移動で鳴らない

| 症状 | 見るところ |
|---|---|
| 何も鳴らない | VR で入っているか / `hapticsOn` / ログが 1 行も出ないなら判定前 (接続 `_IsMine`・首輪の参照) |
| 鳴りっぱなし・うるさい | ログの `ratio` (1.0 前後で張り付いていないか)、`away` (伸びていないのに鳴るなら `awaySpeed`)、`pulseInterval` を上げる |
| 弱い・気づかない | `minAmplitude` / `frequency`、`pullFullRatio` を下げる |
| 歩いているだけで「グイッ」が出る | ログの `holder` (自分の速さ)。0.4 を超えないなら `stillSpeed` を下げる |
| 瞬間移動で鳴る | ログの `away` が極端に大きい → `teleportJump` を下げる |
