## 確認の進め方

1. 確認方法は Issue 本文の「完了条件」に書かれているものを使う
   (ここで新しく考え直さない。考え直したくなったら完了条件の方が誤っている)
2. **OK なら `archive/` へ、NG なら `issues/` 直下へ戻す**
   (移動手順は [issue_summary.md](../issue_summary.md) の末尾)
3. NG だった場合、**何がズレたかを Issue へ追記してから**戻す
   — 期待値が誤っていたのか、実装が誤っていたのかを区別して残す

**AI の確認はコンパイルエラー 0 件 + シーン構築の確認まで。**
Play と実機での体感はユーザーが行う。ここに置く Issue は、
その引き継ぎ待ちであることが多い。
