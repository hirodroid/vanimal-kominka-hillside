# DES-WLD-003 地図・地点ワープ・プレイヤーへの合流

2026-09-27ユーザー要望。コース拡張に伴い、地図とポイント間のワープ、フレンド/プレイヤーの近くへ合流する機能が欲しい。リードでつないだ犬も一緒に移動する。景観制作とは別Issueとして残す。

## 設計する内容

- 地図：既存の登り道・奥広場・橋2か所・川岸・入口、現在地と方向。Desktop/VR/Touchで読める大きさと操作。
- 地点ワープ：入口/既存広場/奥広場/川辺などの安全な足場。水面/橋/斜面/他人と重ならない着地点。
- 合流：在室プレイヤーをどう選ぶか、相手の受入れ/拒否、退出/移動中/水中の扱い。フレンド判定APIが利用できると仮定しない。相手を強制移動する機能ではない。
- 同行：両手のリード最大6匹を対象に、接続・左右・Owner・目的地を維持する。通常の追従がプレイヤーのTeleportだけで必ず成立するとは扱わない。犬/紐の伸び・旧地点への引戻し・非Ownerの要求を調べる。
- 誤操作対策、短時間の連打、到着後の向き、散歩を続ける場合と入口へ戻る場合の扱い。

## 受け入れ条件

- [ ] 地図と地点/プレイヤー選択の画面・操作仕様を決める。
- [ ] 1/3/6匹、片手/両手、他人の犬を動かさない条件を定義する。
- [ ] 同期・退出・途中参加・Owner交代で二重移動/置き去りがない検証手順を持つ。
- [ ] VR酔い、Touch操作、到着位置と安全な失敗時動作を確認する。
