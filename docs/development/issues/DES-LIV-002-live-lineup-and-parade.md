# DES-LIV-002 裏山で作るパーティクルライブの演目と犬のパレードを企画する

2026-09-23 ユーザー依頼: 「パーティクルライブを何を作るか」を独立した Issue にする。候補はハロウィン、Candy Step、ライブパック。裏山の散歩道を犬たちがパレードする専用ライブを 1 本作りたい。

購入者の利用・再生権限・開催と終了の設計は既存の [DES-LIV-001](DES-LIV-001-hillside-live.md) が担当し、本 Issue は演目の中身と制作範囲を扱う。今回は企画案の記録で、演目制作や公開範囲の確定は行わない。

## 初期案

| 枠 | 今回の案 | 具体化すること |
|---|---|---|
| ハロウィン | 裏山専用の演目を作る | テーマ、曲、演出、衣装、舞台となる場所 |
| Candy Step | 裏山専用の演目を作る | テーマ、曲、演出、衣装、舞台となる場所 |
| ライブパック | 古民家側の既存 3 本を基本とし、裏山側の専用 1 本を追加する案 | 既存 3 本の特定、移植時の配置・演出調整、追加演目とパックの関係 |
| 犬のパレード | 裏山の散歩道を犬たちがパレードする専用ライブを 1 本作りたい | どの枠に含めるか、ルート、観覧場所、演目の構成 |

**本数と枠の対応は要確認**: ハロウィン／Candy Step は「各 1 本」と仮整理する。ライブパックへの追加 1 本とパレードが同じ演目か、別枠かは未確定。パレードを機械的に足して専用ライブの合計本数を固定しない。発話中の場所名は正式名を特定できないため、ここでは「裏山の散歩道」と記録し、広場との関係・具体的な区間は企画時に確認する。

## 犬のパレードで検討すること

- 古民家と同じ 6 匹を前提に、出発・道中・到着／フィナーレの流れ、隊列や犬らしい動き、パーティクルと音楽の組み合わせを考える。
- 散歩道のどの区間を使い、広場をどう使うかを決める。観客が定位置から見るか、一緒に歩くか、見失わず楽しめる場所と進行速度を検討する。
- リード散歩・Fetch・集合中の犬をどう扱うか、参加可能な犬が少ない場合、終了・中断後にどう戻すかを DES-LIV-001 へ渡す。利用中の犬を無条件で参加させる前提にはしない。
- 音の届く範囲と通常時の BGM／環境音との切替は [DES-WLD-002](DES-WLD-002-sound.md)、目的地・ボードとの配置調整は [DES-UI-004](DES-UI-004-walk-destinations-and-boards.md) と揃える。

## 完了条件

- [ ] ハロウィン・Candy Step・ライブパックの演目候補と本数、既存演目の利用範囲が整理されている
- [ ] パレードをどの枠へ含めるか、追加演目との重複を解消している
- [ ] 各専用演目の狙い・曲／演出の方向・場所と観覧方法がユーザーと合意できている
- [ ] パレードのルート案・構成・犬の参加条件を整理し、開催／同期／復帰の検討を DES-LIV-001 と接続している
- [ ] 初期公開する演目と制作順を決め、採用内容を仕様へ反映し、制作 Issue へ分けている

購入済みの人が裏山でも利用できる既存要件は DES-LIV-001 に残す。本 Issue の演目案だけで、新規販売・商品変更・再購入の要否を決めない。
