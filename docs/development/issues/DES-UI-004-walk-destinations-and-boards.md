# DES-UI-004 散歩の目的地・配置と案内／説明ボードを本制作へ向けて整理する

2026-09-23 ユーザー依頼: 散歩の目的地にある仮ボードをちゃんとしたものにしたい。目的地の場所・位置、ボードの配置、説明用ボードも含めてどうするかを別 Issue で検討する。今回は課題の記録で、配置・文言・形状の確定や制作は行わない。

## 現状と引き継ぎ

- [IMP-DOG-003](IMP-DOG-003-walking-polish.md) で入口・見晴らし・広場に仮看板 `KH_WalkSign` を設置した。`PLAZA >` / `GATE <` で目的地を指示できるが、`GATE <` が分かりにくいとの PCVR フィードバックがある。[実装記録](../../plans/2026-09-20-free-walk.md)。
- 手元メニューの目的地選択は [DES-UI-001](DES-UI-001-menu-and-leash-assist.md) で実装・確認済み。仮看板は 2026-09-26 に全撤去した (下の決定)。
- 仮看板の本制作と分かりやすさの検討を本 Issue に分離する。犬の散歩挙動は IMP-DOG-003、道・休憩場所の景観調整は [IMP-ENV-001](IMP-ENV-001-hillside-polish.md) が担当する。

## 検討すること

1. 目的地としてどの場所を使うか、呼び名・到着位置・立ち止まる場所を整理する。現行の広場／散歩入口を出発点に、追加や変更の必要性を検討する。
2. 目的地を示す案内板と、散歩の始め方・リード・手元メニュー等を伝える説明ボードの役割を分ける。必要な内容・枚数・設置場所を決める。
3. 仮看板の操作を残すか、手元メニューに集約して案内板にするかを決める。表示名・矢印・進行方向を現地とメニューで揃える。
4. 各ボードの位置・向き・高さ・大きさと見た目を検討する。犬や人の通行、リード取り出し口、眺めを妨げず、入口や目的地で必要な説明を見つけられる配置にする。
5. 昼／ナイトモード、立位／座位、PCVR／Desktop／Touch での読みやすさ・操作の届き方を確認する手順を用意する。

## 完了条件

- [ ] 目的地の場所・呼び名・到着位置と、案内板／説明ボードの配置案が決まっている
- [ ] 仮看板ごとの置換・撤去・操作の扱いと、説明する内容が決まっている
- [ ] 現地の配置案と表示案をユーザーが確認し、本制作の範囲を合意している
- [ ] 決定した内容を [game-design](../../game-design.md)・[world-ui-spec](../../world-ui-spec.md) の該当箇所へ反映し、制作・確認作業へ引き継いでいる

決定: 2026-09-26 (ユーザー指示) 仮看板 `KH_WalkSign` 3基 (入口・見晴らし・広場) は全撤去。行き先は手元メニューで選ぶので現地の操作は置かない。同時に広場の中心のリード拠点も撤去し、見晴らしの拠点が広場を兼ねる ([game-design §4](../../game-design.md#集合と拠点のリード))。案内板・説明ボードを置くかは引き続き本 Issue で検討する。

散歩道を使うライブの配置と干渉しないよう、[DES-LIV-002](DES-LIV-002-live-lineup-and-parade.md) のパレード案とも調整する。新しい目的地の追加、全看板の撤去、具体的なデザインは起票時点で確定しない。
