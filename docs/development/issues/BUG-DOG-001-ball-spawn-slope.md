# BUG-DOG-001 ボールの初期位置を上の広場へ移す

2026-09-20 PCVRユーザー報告: 門前の坂にあるボールが開始時から全て転がり落ちる。ボールは上の広場へ置く方針。[報告](../../plans/2026-09-20-pcvr-feedback.md)。旧Builderは初回に犬の近くへ配置していた。

初期配置だけでなく、戻し先・復帰処理・Builder再実行も確認する。広場内の平らな場所で、放置しても散らばらない配置を選ぶ。購入アセット原本は変更しない。

## 対応 (2026-09-20)

- `KH_DogWalkingEditor.BallHome(i)` を設計値とし、Build のたびに 6 個を広場の平坦部 (中心 75.5,130.5、y=19.07、3×2 間隔 0.9 m) へ書く。`VRCObjectSync` の Respawn 先はシーン開始位置なので戻し先も同じ。支えは置かない (平坦部は 19.00 で水平)。
- Verify に「広場の平坦部にある・地面 19.00±0.02・NavMesh 上」を追加し 98/98 合格。[記録](../../plans/2026-09-20-free-walk.md)。
- ボールを集めるリセット操作は古民家のメニュー側にあり未移植 (DES-UI-001 で扱う)。
