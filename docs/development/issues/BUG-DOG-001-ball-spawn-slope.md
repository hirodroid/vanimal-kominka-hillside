# BUG-DOG-001 ボールの初期位置を上の広場へ移す

2026-09-20 PCVRユーザー報告: 門前の坂にあるボールが開始時から全て転がり落ちる。ボールは上の広場へ置く方針。[報告](../../plans/2026-09-20-pcvr-feedback.md)。現Builderは初回に犬の近くへ配置する。

初期配置だけでなく、ボールの戻し先・復帰処理・Builder再実行も確認する。広場内の平らな場所で、放置しても散らばらない配置を選ぶ。購入アセット原本は変更しない。

## 完了条件

- [ ] 6個の初期位置・戻し先が上の広場にあり、コード設定と保存済みシーンが一致
- [ ] 開始直後・放置・リセットで坂へ勝手に落ちないことをユーザーPlayで確認
- [ ] 投げる・取る・持ち帰る遊びが広場で成立し、配置用の支えが邪魔をしない
