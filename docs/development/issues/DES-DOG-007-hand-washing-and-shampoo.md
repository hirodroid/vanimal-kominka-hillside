# DES-DOG-007 シャンプーをつけて手で洗う体験を検討する

## 依頼と位置づけ

2026-10-02 ユーザー指定: 洗い方は「ちょっと検討が必要」。提供された調査メモと体験案をもとに、現行のスポンジ中心から **シャンプーをつけ、自分の手で犬をわしゃわしゃ洗う体験** を主役にするか検討する。**手洗いの採用・スポンジの撤去はまだ決定していない。**

目的は、古民家で覚えた「撫でる」の延長として、自分の手で犬を世話する感覚とASMR的な気持ちよさを高めること。現実の手順をそのまま必須工程にするのではなく、ワールドでの洗いやすさと犬とのふれあいとして比較する。

## 提供された体験案

- 主案: ボトルを持つ → 犬にシャンプーをつける → 空いた手または両手でわしゃわしゃする → 触れた場所から泡が増える → シャワーで流す
- 一周の例: シャワー → シャンプーボトル → 手洗い → シャワー → タオル。現行の自由な手順・水から始める・途中で泡を足す方針との整合を検討する
- スポンジを残す案: 泡を作る、泡をたっぷり犬に乗せる補助道具にする。既存の仕組みを再利用できるか調べる
- ラバーミット/ラバーブラシは追加候補。今回の手洗いを成立させる必須の道具にはせず、必要性を比較する

## 検討すること

1. シャンプーをつける操作と、手でこすって泡を増やす操作の関係。つける量・範囲・持続時間と、きれいな犬へ繰り返し泡をつける扱い
2. 手の接触・移動から泡立てを判定する方式。普通の撫でと手洗いの区別、頭・関節・動く足や尻尾でも自然に洗えるか
3. 片手・両手・座位のVR操作と、Desktop / Touch の代替操作。ボトルを持ったまま片手で洗えるか、手が使いにくい人の道具の選択肢
4. スポンジ中心・手洗い中心・併用の比較。ボトルや手の準備が増えることで、触れ合いの楽しさより操作の手間が増えないか
5. 既存の撫で反応、首輪操作、洗い場の保持、2人同時の泡立てとすすぎ、同期・描画負荷との整合
6. 少数の代表場面での試作と評価。片手/両手の泡立ち、自分の手で世話している感覚、すすぎへの切替、端末別の扱いやすさを比較する
