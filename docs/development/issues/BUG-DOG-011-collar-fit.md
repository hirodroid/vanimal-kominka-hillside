# BUG-DOG-011 散歩用首輪が首に対して上が浮き下が埋まって見える (6 犬種)

## ユーザー報告

2026-10-10:「首輪の位置がずれている。埋まっている部分と浮いて見える部分がある」。

## 修正前の状態 (2026-10-10 の調査)

対象は散歩用首輪 `KH_Collar_<Corgi|Pome|Lab|Dachs|Shiba|Samoyed>` (Blender 製の帯 `Band` + 金具 `ClipAnchor`。首骨 `Bone.003` 直下)。一時 Editor スクリプト `KH_CollarSurveyTempEditor` でプレビュー用の犬の複製を作り、静止 (rest)・歩き (aruku)・座り (Sit)・伏せ (huse) の 4 姿勢をクリップからサンプルして計 102 枚を撮影し、帯の各頂点から体 (`karada`) の最近傍頂点までの符号付き距離を測った (負 = 埋まり、正 = 浮き)。**Editor のアニメーションサンプルで、Play / VR / 実機の結果ではない。** 本物の犬・シーンは変更していない (一時スクリプトは削除済み、写しは `tools/KH_CollarSurveyTempEditor.cs.txt`)。

- 閾値は埋まり < −4mm、浮き > +12mm (目安)。毛はシェーダーで基準面の外へ押し出して描くので、小さい正の値は毛の中に沈んでいる状態。浮きの % は毛の中の頂点も数える (短毛の Lab でも 66%) ので、見た目の浮きの量は扇形の平均で読む。最近傍「頂点」までの距離なので、体の頂点が粗い所では大きめに出る。
- 「計測上の位置」は撮影スクリプトの `InverseLerpPoint` が測った首骨→頭骨の比で、Fit の設定値ではない。Fit は全犬種 `Lerp(Bone.003, Bone.004, 0.45)` で、犬別の補正は Lab (前 40mm・下 8mm) と Shiba (下 20mm) だけ。
- 首輪の localScale (Corgi 0.763、Shiba 0.619 など) は `1 / neck.lossyScale` で首骨の拡大を打ち消す値。ワールドでの倍率は 6 犬種とも 1.0 で、帯の大きさは `scripts/art/leash-assets.cjs` の `radii` で決まる。
- Lab の localEuler (271.27, 180, 180) は (268.73, 0, 0) と同じ回転で、他犬種と同系統 (向きは反転していない)。
- 上側の浮きは 4 姿勢ともほぼ同じ。下側は伏せ・座りで動く (Corgi 伏せ −4.9、Lab 伏せ +35.4、Lab 座り −12.3、Samoyed 座り −42.3)。全数値は `tools/metrics.json` と `tools/report.txt`。

### 原因

1. **輪の中心を首骨の軸に置いている (主因と推定)。** `KH_LeashProductionEditor.Fit` は `Lerp(Bone.003, Bone.004, 0.45)` に置き、向きは `LookRotation(head − neck, dog.up)`。上下の差からの推定では、輪の中心が首の断面中心より 3〜6cm 上にある (Corgi 48 / Pome 39 / Dachs 32 / Shiba 57 / Samoyed 31mm)。首骨が首の背中寄りを通っているためと推定 (リグは未確認)。**Lab を除く 5 犬種**で、上が 3〜4cm 浮き、下が 2.4〜8cm 皮膚の内側に入る。Lab は Fit で前・下へ補正してあり、静止で上 +15.8 / 下 +0.9mm と例外。
2. **帯の大きさが体格に合っていない。** 帯の楕円半径は `scripts/art/leash-assets.cjs` の `radii` (犬種別の固定値) で決まり、Shiba は rx 0.09 / ry 0.08 で小型の Pome と同じ。Shiba は下側が最も深く沈む (−81.7mm)。
3. **毛の厚みを見ていない。** Samoyed / Pome は帯の下側が毛の中に沈み、毛が帯を突き抜ける。Samoyed の毛材質だけ `_FurTouchStrength` = 0 (他は 1.0) なのも一因の候補 (要確認。この値が何を参照するかは未確認)。
4. **正面からは帯が頭に隠れ、金具だけが見える。** 金具は帯の上端に接している (`RingY` − ry = 6 犬種とも 0.025)。帯全体が高く後ろにあるためで、原因 1 の結果。あご下からも帯がほぼ見えず、「首輪をしている」ことが正面から伝わらない。
5. **Dachs は euler X 278.6 で帯の面が他より約 7° 起きていて**、耳の直後に輪が掛かっているだけに見える。背中側の上からは帯が首より左右にはみ出して見え、下側は胸毛に消える。

## 対応方針 (修正前に立てた提案、優先順)

- A. 輪の中心と大きさを首の断面から決める (Fit の改修)。帯の面に入る `karada` 頂点から断面の中心と楕円半径を求め、中心を骨ではなく断面中心に、帯の楕円半径を断面半径 + 犬種ごとの毛の余白に合わせる (`KH_DogWashSetupEditor` の犬種別 coat 表が流用候補)。Lab で前・下へ補正した結果が良いことが、この方向の裏付け。
- B. 帯の面を少し前下がりにする (断面の主軸、または骨方向を 10〜20° 前傾)。Dachs の起き過ぎを解消する。
- C. 毛の厚い犬 (Samoyed / Pome / Dachs) は帯が毛を押さえる見た目にする (内側に毛の余白、派生材質で `_FurTouchStrength` を 1.0 にして試す (要確認)、帯を広げる、のいずれか)。購入アセットの元材質は触らない。
- D. (A の後に確かめる項目) 金具の高さ `RingY`。A を当てた後に正面を撮り直し、まだ金具だけが目立つ場合に限って調整する。
- E. 帯の下端が胸の前に出る高さを目標にする (Lab-rest-front が見た目の手本)。
- F. 数値目標は完了条件のとおり。見た目の手本は Lab だが、数値条件は Lab にも課す。

注意:

- 首輪の Transform は Setup (`Walking/8 Refit Collars` → `KH_LeashProductionEditor.Fit`) が上書きする。**手で動かさず、Fit のデータ (犬種補正・`RingY`) と帯の半径を直し、Refit で再現できる形にする。**
- 首輪の `SphereCollider (Trigger) + Interact` (接続解除) は、位置を下げると首・頭の当たり判定に Interact の光線が先に当たる問題 (`KH_DogWashSetupEditor` のコメント) を再確認する。
- 首元の飾り (バンダナ・蝶ネクタイ・首飾り等。KD_Acc_*) との干渉を、飾りを同時に表示して確認する (今回の撮影は飾りを非表示)。干渉表は [IMP-DOG-015](IMP-DOG-015-accessories-and-petfx-port.md) の案 C。
- 輪の位置や金具を動かすとリードの接続点 (`ClipAnchor` = `KH_LeashCollar.anchor`) が変わるので、縄の始点・`_RopeSolveNow` の見た目・リード台の掛け外しを合わせて確認する。
- 撮影ツールは一時スクリプトを `KH_LeashPoseStudyEditor` に多視点として統合する案がある。

## 対応 (2026-10-10)

### 改修内容

`KH_LeashProductionEditor.Fit` (`Walking/8 Refit Collars` が呼ぶ) を、首骨の軸ではなく **`karada` スキンの首断面**から輪の中心・向き・楕円半径を決める方式に改修した (対応方針 A・B)。

- 首骨→頭骨の 0.45 の点で、帯の面を首軸に直交する面から世界の鉛直面へ `TiltBlend` の割合だけ寄せる。その面の ±20mm のスライスに入り、帯半径の 2.4 倍以内にある `karada` 頂点から断面の中心と半幅を求め、輪の中心を断面中心へ移す。
- 帯の楕円は「断面の半幅 + `FurMargin`」に合わせ、X (左右) と Y (上下) を別々に拡大する (帯の幅 Z は 1 のまま)。倍率は 0.75〜`MaxScaleByBreed`。
- 断面の頂点が 20 未満なら旧配置 (骨の軸 + 旧 Lab / Shiba の手補正、倍率 1) へフォールバックし、`Debug.LogWarning` を出す。旧 Fit の Lab / Shiba の手補正は通常の配置から削除し、フォールバックにだけ残した。
- 首輪の Interact 用 `SphereCollider` は首輪と一緒に拡大されるので、半径を倍率で割ってワールド半径 .10 を維持する。フォールバックの警告と合わせて独立レビューの指摘を反映した。
- 純関数 `Solve` と、シーンを変えないドライラン用メニュー `Walking/Production 8b Collar Fit Report` を追加した。

### ユーザー決定 (案 1「実物どおり」)

R4 (帯を 6 犬種とも見せる置き方) をユーザーが VR で確認した:「首輪は全部見えるようになったが、サモエド・ポメは毛の外側に大きな輪が浮いていて明らかにおかしい。実物のふわふわ犬は首輪が毛に埋もれて見えないはず」。統括が選択肢を示し、ユーザーが案 1 を選んだ。

- Pome・Samoyed は帯を毛の中 (皮膚の内側) に埋めて見せず、金具とリードで首輪の存在を見せる (「リードで見せていく」)。
- 短毛・中毛の 4 犬種 (Corgi・Lab・Dachs・Shiba) は断面基準の配置を維持し、Corgi・Shiba は毛の余白を減らして毛に半分沈める。

決定: 2026-10-10

### 埋もれ犬種の置き方 (`BuriedInFur` = Pome・Samoyed)

- 帯の倍率は左右・上下で同じ k = clamp(min(1, (断面の半幅 hx − `SideInset`) / rx), 0.75, 1)。一様なので金具が歪まない。`FurMargin` と `MaxScaleByBreed` はこの 2 犬種の配置には使わない。
- 帯の上端を皮膚の上面から `SinkDepth` 下に、横は皮膚の `SideInset` 内側に置き、帯全体を不透明な体の中に隠す。毛はアルファで抜いた層を重ねて描くので、皮膚の外にある物は層の隙間から透けて見える。皮膚の上面や毛の中に置くだけでは「毛が帯を突き抜ける」見え方が残った (R5・R6)。
- 金具 (`ClipAnchor` の D リング。`KH_LeashCollar.anchor` = リードの接続点) は `RingY + RingLift` に置き、毛の上に出す。首輪を外す Interact の `SphereCollider` の中心も金具の位置に合わせる。

### ラウンド

- R1 (傾き .5、一様スケール上限 1.4): 縦長になり帯が太る。
- R2 (傾き .3、XY 別スケール、探索半径 1.8→2.4 倍で Shiba の胸側を拾う、Pome 余白 .004・上限 1.2): Pome が毛に沈んで見えなくなる。
- R3 (Pome 余白 .010・上限 1.3・傾き .15): Pome の上側で毛が突き抜ける。
- R4 (Pome 余白 .014・上限 1.35): いったん採用。ユーザーの VR 確認で Pome・Samoyed の「毛の外に浮いた大きな輪」を指摘され、案 1 に決定。
- R5 (埋もれ犬種の帯の上端を皮膚の上面に。余白 0、倍率 1): 側面で帯が毛の層と混ざり、毛が突き抜けて見える。
- R6 (帯を 1cm 沈める): まだ透ける (毛はアルファ抜きの層なので、皮膚の外にある物は隙間から見える)。
- R7 (帯を皮膚の内側 = 不透明な体の中に入れ、金具を持ち上げる): ほぼ隠れるが、帯の端が覗く。
- R8 / R9 (沈め幅と内側寄せを増やし、金具の持ち上げを増やす。上の最終値): 帯は完全に隠れ、金具だけが毛の上に出る (Pome ははっきり、Samoyed は毛が厚く金具がぎりぎり)。採用。

## 完了条件

- 6 犬種 × 4 姿勢 (静止・歩き・座り・伏せ) で、top 平均 ≤ 毛の厚み相当、bottom 平均 ≥ −5mm、埋まり頂点 (< −4mm) ≤ 5%。**Lab にも課す** (修正前の Lab は top +15.8、埋まり 16%、座りの bottom −12.3 で 3 条件とも満たさない)。
  - 注記 (2026-10-10、案 1): この 3 条件 (埋まり ≤ 5% を含む) は短毛・中毛の 4 犬種 (Corgi・Lab・Dachs・Shiba) に当てる。埋もれ犬種 (Pome・Samoyed) は帯を体の中に隠すので数値条件を当てず、帯が見えないこと・金具が毛の上に出ることを条件にする。
- top の目安と犬種の分け方 (`KH_DogWashSetupEditor` の犬種別 coat 表から):
  - 短毛 +10mm 程度: Lab・Dachs ("short smooth coat")。ただし Dachs は材質の毛の押し出し (`_FurVector.w × _FurVectorScale` = 0.025×1.3) が Lab (0.01×2.5) より大きく、同表のコメントも撮影で浮き・沈みを見るとしている。
  - 長毛 +25mm 程度: Pome・Samoyed ("long fluffy coat" / "long white double coat")。
  - 中毛: Shiba・Corgi ("medium double coat")。目安の値はまだ無い。短毛と長毛のどちらを当てるかは修正後の撮影で決める (要判断。材質の押し出しは Shiba 0.01×1.0、Corgi 0.02×1.0)。
- 毛が帯を突き抜けない。正面・あご下の視点で帯が見え、金具だけが見える状態にならない (短毛・中毛の 4 犬種。埋もれ犬種は帯が見えず金具だけが毛の上に出るのが正しい状態)。

- 首元の飾りを同時に付けた状態、リード接続・解除 (Interact) が修正前と同じく成立する。
- ユーザーが VR で確認する: 歩き・座り・伏せ・リード接続中・撫で中。埋もれ犬種は金具が毛の上に出ていること・リードが毛の中から出る見え方も見る。
