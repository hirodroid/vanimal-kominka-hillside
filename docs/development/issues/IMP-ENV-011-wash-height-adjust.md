# IMP-ENV-011 洗い場の高さの調整 (台と自分の床)

親は [IMP-DOG-024](IMP-DOG-024-walk-and-wash-experience.md)。設計と担当間の約束は [洗い場へ犬を呼ぶ・高さを調整する](../../plans/2026-10-01-wash-call-and-height.md)。主洗い場と道中の洗い場は [IMP-ENV-007](IMP-ENV-007-main-wash-station.md) / [IMP-ENV-008](IMP-ENV-008-wash-stations-along-course.md)。

2026-10-01 ユーザーの決定 (PCVR の確認から): 「犬を洗うには上下の移動が要る。PCVR は OVR で位置を調整できるが、それ以外は難しい。台の高さを調整できるようにする。自分用の見えない床のコライダーを作って、その高さも調整できるようにする。高さの調整で自分は浮くこともできる (犬を上から洗える)。背が高い人は犬を上に上げる」。

## 範囲

- ボード: 各洗い場の棚に World Space の Canvas (犬 6 匹のボタン、おわり、台 ▲▼、自分 ▲▼、いまの状態)
- 台の昇降: すのこ (と Collider) を 0〜0.9 m、0.1 m 刻みで上下。洗い場ごとに同期。留まっている犬のルートも一緒に上がる
- 自分の床: 見えない床 (自分だけに効く Collider) を 0〜1.2 m、0.1 m 刻みで上下。同期しない。8 m 離れたら 0 へ
- Verify と ClientSim のケース

やらないこと: 犬を呼ぶ・留める処理そのもの (IMP-DOG-035)。小物の見た目の作り込み (IMP-ENV-007 の後段)。

- [ ] ClientSim: 台を上げると留まっている犬のルートの高さが同じだけ上がる、犬がいない時は 0 へ戻る、自分の床が上がってプレイヤーが乗れる、離れると 0 へ戻る
- [ ] 洗い場の既存の検査 (道具・リセット・手動配置との距離) が通ったまま

- [ ] 自分の床の上げ下げで酔わない・落ちない。他の人の見え方が不自然でない
- [ ] ボードの文字と押しやすさ
