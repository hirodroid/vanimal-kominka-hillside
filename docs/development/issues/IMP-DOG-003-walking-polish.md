# IMP-DOG-003 接続と散歩の手触りを磨く

2026-09-20のPCVR体験が好評だった試作を基準に、体験を磨く。既知の不具合が報告されたという意味ではなく、[開発全体像](../overview.md) §3の改善提案。基本実装と機能検証は [IMP-DOG-002](IMP-DOG-002-leash-walking.md)、具体値・採否は [DES-DOG-001](DES-DOG-001-leash-walking.md) が受け持つ。

## 進め方

2026-09-20、ユーザーが改善の最優先として「リード操作・犬の動き」を選択。次の実装はこのIssueから進める。具体的な不満や症状はまだ受領していないため、まず比較して改善対象を絞る。

1. 入口から坂を往復し、接続・停止・方向転換・解除・再接続を1匹、3匹、6匹で比較。気になる場面を記録してから距離・速度・判定を変える。
2. 首輪の輪、持つ先端、左右の選択を見つけやすくする。成功・上限・他人の犬・Fetch中の違いを短い表示や反応で伝える案を検討する。音・振動の採用は未確定。
3. 首輪と接続輪の犬種ごとの適合、動作中の貫通、リードの伸び・たるみ、ラックの置き方を調整する。
4. VRの体験を軸に、Desktop・Touchでも接続位置へ先端を運べる操作を確かめる。新しい操作で既存の撫で・ボールを邪魔しない。

## 完了条件

- [ ] 気になる場面と調整前後の条件・結果を保存した
- [ ] 1匹・3匹・6匹、停止・方向転換・斜面・再接続で改善を確認した
- [ ] 初見の利用者が接続と解除を理解できることを確認した
- [ ] 犬種別の首輪適合とPCVR / Desktop / Touchの結果を記録した
- [ ] 採用値をgame-design、生成側、保存済みシーンへ整合させた

同期の不具合はIMP-DOG-002へ、性能の測定はVER-ENV-001へ記録。おしゃれの種類・保存・解放はDES-DOG-001で別途範囲を決め、ここで無断に増やさない。
