# IMP-DOG-003 目的地を持つ自由な散歩とリードの手触りを作る

2026-09-20のPCVR試作を基準に体験を磨く。追加相談で、主眼を「前方へ配置する追従」から「犬自身が目的地へ行きたがり、自由に過ごす散歩」へ具体化した。仕様の正本は [game-design §4「目的地を持つ自由な散歩」](../../game-design.md)、経緯は [PCVRフィードバック](../../plans/2026-09-20-pcvr-feedback.md)。基本実装と機能検証は [IMP-DOG-002](IMP-DOG-002-leash-walking.md)、未決定の契約は [DES-DOG-001](DES-DOG-001-leash-walking.md)、目的地メニューは [DES-UI-001](DES-UI-001-menu-and-leash-assist.md) と連携する。2026-09-20 に手順 1〜2 (通過点・目的地・自発的な散歩・待機・誘い・寄り道・道外) と目的地の看板を実装し Editor 検査済み。Play は未確認。[実装記録と Play チェックリスト](../../plans/2026-09-20-free-walk.md)。

## 今回の合意

2026-09-23: 仮看板の本制作・目的地の場所と配置・説明ボードの検討は [DES-UI-004](DES-UI-004-walk-destinations-and-boards.md) に分離した。以下に残る看板の記述は試作とフィードバックの履歴で、今後の看板の検討先は DES-UI-004 とする。

- 自分の接続犬へメニューで広場/古民家側の散歩入口を指定し、犬ごとに目的地を持つ。他人の犬や未接続犬へ波及させない。
- 目的地と通過点 (ウェイポイント)・接続関係を用意する。任意の開始位置から、近くて到達可能かつ目的地へつながる点へ入り、以後は区間を覚えてたどる。共通区間を再利用し、将来の草むら等への拡張に備える。
- 自発的な先行・寄り道・待機・止まっている人への誘い・犬同士の遊びを作る。人が引かないと歩かない状態を改善し、全犬を常時視界内に固定しない。
- 首/手の回転で目的地を切り替えない。人の移動方向は補助として緩やかに見る。約1秒の判断周期は試作案であり、歩行や安全対処まで1秒更新に落とす意味ではない。
- 多少の遠回りは許容し、崖への進入・往復ループ・置き去りは防ぐ。道外では人に付き合い、戻れば散歩を再開する。
- 初期目的地・再接続時の扱い・距離・誘いの頻度・じゃれ合いの動作や中断条件は未確定。接続/解除と伸びる紐、既存の撫で・ボール遊びを維持する。

## 進め方

直近のボール配置修正 (BUG-DOG-001) の後、このIssueを進める。DES-DOG-001とDES-UI-001のうち目的地指定に必要な契約を先に決め、メニュー全体の完成を待たずに散歩を試作する。

1. 広場/入口の目的地と通過点を用意する。1匹で往復・途中開始・曲がり角・道外からの復帰を試し、目的地への直進や毎回の最近傍選択で道を飛ばさないか確認する。
2. 自分から歩く、寄り道する、人が来なければ待つ、長く止まった人へ戻って誘う動きを試す。人が反対へ歩けば近くへ戻るが目的地は変えない。到着後は落ち着いて過ごす。
3. 2匹・3匹で短いじゃれ合いから散歩へ戻る動きを追加し、6匹で行動の偏り・集中・連続催促を確認する。最初の試作対象は同じ人の接続犬同士。遊び中の移動・目的地変更・解除への対応は先に契約化する。
4. 自分の接続犬への目的地変更と共有された動きを確認する。2人で異なる行き先、要求中の接続変更、途中参加、接続者/Owner退出をIMP-DOG-002と連携して検証する。
5. 首輪の輪、持つ先端、左右の選択を見つけやすくする。成功・上限・他人の犬・Fetch中の違いを短い表示や反応で伝える案を検討する。接続通知の音・振動の採用は未確定。
6. 首輪と接続輪の犬種ごとの適合、動作中の貫通、リードの伸び・たるみ、ラックの置き方を調整する。
7. VRの体験を軸に、Desktop・Touchでも接続位置へ先端を運べる操作を確かめる。新しい操作で既存の撫で・ボールを邪魔しない。
