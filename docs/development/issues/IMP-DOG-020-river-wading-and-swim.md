# IMP-DOG-020 川の浅瀬遊びと泳ぎ (初期公開範囲)

[DES-DOG-004](DES-DOG-004-river-play-and-floating-fetch.md) の決定 (2026-09-27) を実装する。何をどう作るかの正本は [設計書](../../plans/2026-09-27-river-play-and-floating-fetch.md)。本 Issue はその範囲と順序、完了条件だけを持つ。数値は設計書を見る (ここに重複させない)。

## 範囲

- 設計書 A-2 の初期公開範囲: 前提 + 段階 0 + 段階 1。
  - 水遊び場は 1 か所: 目的地「川辺」脇、東岸の外側の曲がり。
  - リードを外した犬だけ。リード中は入水しない。
- **泳ぐのは小型犬** (ポメラニアン・コーギー・ダックスフンド)。柴犬は試作で決める。**大型犬** (サモエド・ラブラドール) は浅瀬だけ。淵は掘らない。
- **専用の泳ぎクリップは作らない。** ルートを水面基準に浮かせ、既存の歩き / 走りを再生する。
  - 見え方が足りないとユーザーが判断したときだけ、生成でクリップを作る (別途)。
- 跳ねる動きと身震いは、既存クリップと PhysBone の減衰ロールで出せる範囲に限る。
- 含めないもの:
  - 段階 2 (浮くボールを泳いで回収)。DES-DOG-004 の段階 2 として、別 Issue で扱う。
  - ただし前提作業の「川へ落ちたボールを岸へ戻す」は本 Issue に含める。
  - 現地の看板は [DES-UI-004](DES-UI-004-walk-destinations-and-boards.md) の担当。

    - 修正: ボールを Rigidbody の FreezeAll で水面より上に止めて置く。戻ったら 1 回きりで、その後 6 s 帯へ戻らないことも合格条件に加えた。
- ハーネス W5 の疑似入力: 投げはボールを置いてから `_OnBallThrown` を呼ぶ。集合は `KD_GroupActivities` の同期変数へ直接書く (メニューの権限と置き場所の検査は通らない)。

  - Course/73 は BUILT (721 サンプル、橋 z 190 / 490、配線 6 / 6 / 1)。
  - Course/74 は PASS (誤差 y 0.000 / x 0.019 / hw 0.001 m、水面下の NavMesh 点 0)。
  - W5 は W5_PASS (3 ケース、run 20260927-033516)。
- Codex の独立レビュー (2026-09-27) を受けて直した点。レビュー反映後に W5 を再実行する予定:
  - 集合の最後の区間: NavMesh の終点ではなく枠へ直進するので、ここにも帯の判定を掛けた。
  - 加速後の歩幅: 加速前の速さで先読みしていたので、実際の歩幅でもう一度判定するようにした。
  - 岸の点の判定: 斜めに流れる区間でも正しく判定できるよう、帯の外向きの法線で見るようにした。安全な点が無ければ置き場へ移す。
  - 置き場送りの数え方: 拾われたときと Fetch の間は回数を戻す。
  - W5 の合格条件: 戻した先が NavMesh 上であることと、置き場送りでないことを加えた。戻したボールは次にハーネスが置き直すまで監視を続ける。
- 2 回目の W5 (run 20260927-041222) は W5_FAIL だった。岸の点の判定が厳しすぎ、z 140 で候補をすべて落として、1 回目から置き場へ送っていた。
  - 生成式で確かめた値: 岸の斜面 (帯の縁から +2 / +3.5 m) は -0.15〜-0.34 (9〜20°)。斜面の上端より先 (+5 m 以遠) は -0.022〜+0.023 (1.3〜1.7°) で、水面の z 方向の傾きの分だけだった。
  - 修正: 内積 -0.10 以上 (水へ向かう下りが約 5.7° 以下) を受け入れ、内積が最大の点を選ぶ。3 回目の置き場送りはそのまま。ログに `slope=` を出す。
- 3 回目の W5 (run 20260927-042802): ボールの 2 ケースは岸 (x 381.80、slope -0.031) へ戻ったが、集合ケースの間に転がって川へ戻り、late で FAIL になった。
  - 原因: 剛体の球には転がり抵抗が無いため、わずかでも水へ向かう斜面なら止まらない。
  - 修正: 戻した直後に地面に接する高さへ置き、速度を 0 にして `Rigidbody.Sleep()` を呼ぶ。その後 1.25 s は、持たれたり犬がくわえたりしない限り眠らせ直す。
  - 候補点は、同じ距離の z ±3 m も探すようにした。
  - ハーネスは、戻して 2 s 後と終了時の `IsSleeping`、戻した点からのずれを記録する。
