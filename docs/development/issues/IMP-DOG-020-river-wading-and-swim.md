# IMP-DOG-020 川の浅瀬遊びと泳ぎ (初期公開範囲)

[DES-DOG-004](DES-DOG-004-river-play-and-floating-fetch.md) の決定 (2026-09-27) を実装する。何をどう作るかの正本は [設計書](../../plans/2026-09-27-river-play-and-floating-fetch.md)。本 Issue はその範囲と順序、完了条件だけを持つ。数値は設計書を見る (ここに重複させない)。

## 範囲

- 設計書 A-2 の初期公開範囲: 前提 + 段階 0 + 段階 1。
  - 水遊び場は 1 か所: 目的地「川辺」脇、東岸の外側の曲がり。
  - リードを外した犬だけ。リード中は入水しない。
- **泳ぐのは小型犬** (ポメラニアン・コーギー・ダックスフンド)。柴犬は試作で決める。**大型犬** (サモエド・ラブラドール) は浅瀬だけ。淵は掘らない。
- **専用の泳ぎクリップは作らない。** ルートを水面基準に浮かせ、既存の歩き / 走りを再生する。
  - 見え方が足りないとユーザーが判断したときだけ、生成でクリップを作る (別途)。
- 跳ねる動きと身震いは、既存クリップと PhysBone の減衰ロールで出せる範囲に限る。
- 含めないもの:
  - 段階 2 (浮くボールを泳いで回収)。DES-DOG-004 の段階 2 として、別 Issue で扱う。
  - ただし前提作業の「川へ落ちたボールを岸へ戻す」は本 Issue に含める。
  - 現地の看板は [DES-UI-004](DES-UI-004-walk-destinations-and-boards.md) の担当。

## 順序と完了条件 (設計書 D-5)

各段は、コンパイル・Console エラー 0・保存後の Verify が通ってから次へ進む。Unity のメニュー実行・保存は統括の担当。

### 1. 前提作業 (水遊びの採否と独立)

- `KH_RiverData` (生成式を z 1 m 間隔で焼いた配列) を作る。
- 自由行動・Fetch・集合の直線移動が、水遊び場の外で川の帯へ入らないようにする。
- 川へ落ちたボールを岸へ戻す (設計書 C の 1・7・8)。

- [ ] Editor 検査 1 (配列と水面メッシュの照合)、検査 6 (除外の縁の水面下の点の一覧) が通る
- [ ] ClientSim ハーネス W5: 水遊び場の外の川へ投げたボール・対岸の集合で、犬が川の帯へ入らず、ボールが岸へ戻る

### 2. 水遊び場

- `KH_WaterSpot` を置く (領域・入水点・出水点・復帰点・河床格子)。淵は掘らない。
- 「川辺」の通過点から入水点まで、踏み分け道を塗る。
- Nav と遮蔽を必要なら再生成する。

- [ ] Editor 検査 2〜5 が通る (勾配は上限 5 % の境目なので値を記録する)

### 3. 段階 0 (浅瀬を歩く)

- しぶき FX と水音をローカルで出す。
- `waterPose` を同期する。
- 入り方 (解除から 5 s 以内に初回の入水)、中断、復旧 3 段、案内の一言。すべて設計書 B-1・C の規則どおり。

- [ ] ハーネス W0 (デバッグ入口なしで、解除から入水まで ≤ 5 s)
- [ ] ハーネス W4 (水中での接続・集合・呼ぶ・おもちゃの呼び出し・陸への投げ)
- [ ] ハーネス W6 (Owner 交代・復帰点を塞いだときの復旧)

### 4. 段階 1 (浮いて泳ぐ)

- 小型犬は水深で泳ぎへ切り替え、ルートを水面基準にして歩き / 走りを再生する (設計書 B-2)。
- まずポメと柴で試し、係数を決め直す。そのあとコーギー・ダックスへ広げ、柴を泳がせるかを決める。
- 大型犬は `waterPose` 2 (泳ぎ) にならない。

- [ ] ハーネス W1 × 6 犬種 (毎フレーム集計で違反 0、大型犬は泳ぎ 0 回)
- [ ] ハーネス W2 (6 匹同時)
- [ ] ユーザーの PCVR: 泳いでいる感が出るか、口と鼻先の出方、大型犬のチャプチャプ、案内が分かるか。見え方が足りなければ、クリップの生成を別途起票する

### 5. 公開前の検証 (設計書 A-2・D)

- [ ] Codex の独立レビュー (同期・Owner 交代・保存を含む)
- [ ] 2 人の実機: S2 (境目の帯での途中参加を含む)・S3 (Owner 退出)・S5a (水中の犬への同時要求)
- [ ] Quest 単体 / iOS: [VER-WLD-001](VER-WLD-001-quest-ios-devices.md) に「川の水遊び」の行を足して確認する (設計書 D-2)
- [ ] game-design §3 の条件 (16 人・犬 6 匹、集合時と分散時、端末・画質・アバター表示条件の記録) での計測を、[IMP-ENV-004](IMP-ENV-004-river-loop-course.md) の計測と同じ回で行う (設計書 D-4)
- [ ] 容量の増分が予算 +0.5 MiB 以内 (Android / iOS の代理容量で測る)
