# IMP-DOG-020 川の水遊び (浅瀬・泳ぎ・浮くボールの回収、初期公開範囲)

[DES-DOG-004](DES-DOG-004-river-play-and-floating-fetch.md) の決定 (2026-09-27) を実装する。何をどう作るかの正本は [設計書](../../plans/2026-09-27-river-play-and-floating-fetch.md)。本 Issue はその範囲と順序、完了条件だけを持つ。数値は設計書を見る (ここに重複させない)。

## 範囲

- **決定 (2026-09-27、2 回目、ユーザー「初期公開にこれ全て入れる」)**: 初期公開は、本 Issue の段階 1〜7 のすべて。設計書の段階 2 (浮くボールの回収) を含む。
  - 水遊び場は 1 か所: 目的地「川辺」脇、東岸の外側の曲がり。段階 5 で岸に沿って 30〜40 m に広げ、目印を置く。
  - きっかけ: リードの付いていない犬が水遊び場の近くにいれば入る (解除の操作に依らない)。リード中は入水しない。
  - 1 回目の決定の「前提 + 段階 0 + 段階 1。浮くボールの回収は後段」は撤回した (設計書 A-2)。
- **泳ぐのは小型犬** (ポメラニアン・コーギー・ダックスフンド)。柴犬は試作で決める。**大型犬** (サモエド・ラブラドール) は浅瀬だけ。淵は掘らない。
- **専用の泳ぎクリップは作らない。** ルートを水面基準に浮かせ、既存の歩き / 走りを再生する。
  - 見え方が足りないとユーザーが判断したときだけ、生成でクリップを作る (別途)。
- 跳ねる動きと身震いは、既存クリップと PhysBone の減衰ロールで出せる範囲に限る。
- 含めないもの:
  - 現地の看板の本制作は [DES-UI-004](DES-UI-004-walk-destinations-and-boards.md) の担当。仮看板 (「犬の水あそび」) は本 Issue の段階 5 で置く。
