# IMP-UI-002 現地の案内と遊びの看板を実際のキャプチャーで分かりやすくする

## 最新の追加依頼 (2026-10-03)

- **洗浄と散歩は、その設備の場所に説明を置く。** 散歩も洗い場と同じように、散歩を始める設備の上に説明を付ける。具体的な取り付け位置は現地で決める。
- **遊び方の看板は、フリスビーなどの遊びを案内する。** 散歩・洗浄の詳しい手順は現地へ移す。マップや課金案内の扱いは別Issueの範囲を維持する。
- フリスビーの文字中心の説明を、実際のメニューのキャプチャーとワールド内の写真で作り直す。どこの何を操作するかを、矢印・強調枠・部分拡大で示す。
- 案内画像は実際のワールドを撮影して作る。洗浄の「犬に泡をつける → ボトルを離す → 両手で洗う → 足りなければ泡を足す」は [IMP-UI-003](IMP-UI-003-wash-guide-bottle-release-both-hands.md) に分離する。

以下の起票時の「入口へまとめる」前提は、この配置方針に置き換える。

## 依頼と目的

2026-10-02 ユーザー依頼。入口へ仮配置した説明ボードは文字中心で、ぱっと見て操作が分かりにくい。ワールド内に道具やメニューの材料が揃っているので、実際のキャプチャーに「ここだよ」と分かる印を付け、何を持ち、どこへ動かし、どのボタンを押すかを見て理解できる説明にしたい。

看板の外観・配置を扱う [DES-UI-004](DES-UI-004-walk-destinations-and-boards.md) から、説明紙面の仕上げを分離する。既存の [看板設計書](../../plans/2026-10-02-guide-boards.md) を起点にする。

## 作業範囲

- お散歩・フリスビー・洗浄など、既存ボードに載せた案内を棚卸しし、文章の代わりに見せる場面を選ぶ。特にリード接続とメニューの使い方を優先する。
- リードは「持つ道具」「持つ箇所」「先端を近づける犬の首輪」「つながった状態」が分かる連続カットを作る。矢印・番号・強調枠と短い動詞で手順を示す。撮影前に現在の実装と操作を照合する。
- メニューは実際の画面を撮影し、開き方から対象タブ・ボタンまでを示す。必要な部分を拡大して、画面内のどこを押すかを強調する。全画面を小さく貼って読ませる構成にしない。
- VR の手で操作する方法と Desktop / Touch のメニュー操作を混同させず、必要な分だけ区別する。未実装の画面や未確認の入力を実際の操作として描かない。
- 古民家に合う既存看板へ収まる紙面案を作り、キャプチャーを主役、短い説明を補助にする。図の順序・余白・拡大率・強調の方法を揃える。
- 採用した紙面を遊びの看板と散歩・洗浄の各設備上の案内へ反映し、実際に読む距離・昼夜・立位と座位で、対象物と次の操作を識別できるか確認する。画像内の文字と既存の多言語表示の扱いも整理する。
