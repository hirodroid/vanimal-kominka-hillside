# BUG-ENV-002 主洗い場の台が土に埋まっている

## ユーザー報告 (2026-10-13、原文)

「まず古民家の裏山の前の部分で、洗うの時、台が土の中に埋まっちゃってるんで、これを土の上に出るような状態に設定をしておきたいです。できるだけ平面な場所に設置した方がいいのかなって気もするけどね。他の 2 つの場所は多分平面なんで大丈夫だと思うんだけど。」

読み: 「前の部分」= 門の外の主洗い場 ([IMP-ENV-007](IMP-ENV-007-main-wash-station.md))。「他の 2 つ」はユーザーの数え方で、道中の洗い場は 3 か所 (川辺 River・奥広場 Upper・展望 Hillside、[IMP-ENV-008](IMP-ENV-008-wash-stations-along-course.md))。River は傾き 4.1° の地点に置いた記録があるので、ここでは 3 か所とも検査の対象にする (食い違いは解消していない。ユーザーが見たのは 2 か所と読む)。

## いまの状態 (2026-10-13 に読んだ範囲。Unity は触っていない)

- 主洗い場は 2026-10-06 (`b9fd85a`) に (39.60, 1.83, 39.60) へ移した。移す前の候補地の測定は IMP-ENV-007 の記録 (x 40〜44・z 40〜44 の平地)。移した後の地点の Terrain の高さと台の y の関係は記録に無い。**移動が原因かどうかは測って決める** (仮説。断定しない)。
- 台の高さは昇降する ([IMP-ENV-011](IMP-ENV-011-wash-height-adjust.md)、`liftRoot` を 0〜0.9 m)。台の平面は犬別に縮む ([IMP-ENV-013](IMP-ENV-013-wash-platform-size-per-dog.md))。どちらも**基準の高さ (0 段) を動かさない**ので、基準そのものが Terrain より低ければ常に埋まる。
- 洗い場の位置・部品は `Tools/KominkaHillside/Wash/11` のビルダーが書く (棚と洗い場の位置は保つ、[production.md](../../plans/des-env-002/production.md))。**シーンで手で動かすだけでは次の 11 で戻る可能性がある**ので、ビルダー側 (または保たれる値) で直す。
- 移設する場合の制約: IMP-ENV-007 の「集合・リード台・おやつ・店番・周回の起点に重ならない」と、[IMP-DOG-029](IMP-DOG-029-dirt-accumulation.md) の「10-06 の移動で門の外の待機の輪が汚れの地点に掛かる」の注意がそのまま効く。

## 範囲

- 主洗い場の台 (すのこ・Collider) の 4 隅で Terrain との高低差を測り、台の下面が地面より上に出る高さ (または傾きの無い場所) に直す
- 直し方は測定後に決める: (a) 台の基準の高さを上げる、(b) 洗い場ごと近くの平地へ少し動かす、(c) Terrain を局所的にならす。(c) は地形の手動調整 ([IMP-ENV-003](IMP-ENV-003-spawn-and-dropped-portals.md) の対象) と周回のコースを崩さない範囲だけ
- 道中 3 か所 (River / Upper / Hillside) で同じ測定をし、埋まっていれば同じ直し方で合わせる
- Wash/11 → 12 の再実行で直した状態が保たれること

やらないこと: 台の昇降・犬別サイズの仕組みの変更 (IMP-ENV-011 / 013)。洗い場の数・地点の見直し。

## 記録

2026-10-13: 原因と対応 (統括 Fable、実装 Opus)。Wash/24 (新設の計測) で主洗い場の台の 4 隅は地面より −0.083〜−0.212 m (埋没)。原因は根の y の取り方ではなく、2026-10-11 にユーザーが Z ファイト回避で手置きした台の局所 y −0.028 を Wash/12 が「保つ」検査にしていたこと + 足元の地面の高低差 0.21 m (斜面)。対応: 根の y をコードの規則「max(棚の足元の最高地面, すのこ下の最高地面 − 台の局所 y) + 0.01 m」で据える (x / z / yaw は保つ)。Wash/11 の経路と、有料品が入ったシーンでも動く Wash/25 (据え直し、y だけ) の両方に入れ、Wash/12 に「埋まっていない (≥ −0.005)・浮いていない (≤ 0.35)・規則どおり」の検査を足した (IMP-ENV-007 の 10-11 の決定は取り消し)。結果: 主洗い場 根 y 1.829 → 2.052 (+0.222)、台の 4 隅 +0.010 / +0.085 / +0.074 / +0.139 m。River +0.059 (棚側の地面が高い)、Upper / Hillside +0.010。Wash/24 → 25 → 24 (変化 0) → 保存 → Wash/12 VERIFY_OK 5393 → WashPremium/50 (bathMinLifts 1 件更新 → 0) → 44 PASS → 保存。移設候補は閾値 (高低差 0.25) 未満で出ていない。残り: 低い側で棚の脚が最大 0.246 m 浮く (斜面に剛体を乗せる以上どちらかは浮く)。ベイク照明は未確認。ユーザーの Play 待ち。
