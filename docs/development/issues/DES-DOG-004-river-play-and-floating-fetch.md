# DES-DOG-004 川の水遊びと浮くボールの回収

2026-09-27ユーザー要望。川を作ったので、犬が水へ入り、少し浮いてパチャパチャと泳ぐ姿を見たい。ボールが水面に浮き、犬が泳いで取りに行き、くわえて帰る体験が目標。今回の橋・地面の景観修正とは別に設計する。人は現在の小川の通行状態を当面維持する。

## 調べて決めること

- 6犬種の体高差、浅瀬の歩行→浮遊/泳ぎ→岸へ上がる切替、水面高さと波の扱い。水深だけで小型犬が沈まない条件。
- 既存Animator/購入クリップに泳ぎがあるか。無ければ手足の動き、頭・口・ボールが水面から出る専用動作が必要。走りのクリップ流用だけで泳ぎ完成とはしない。
- 現状の河床NavMesh除外を全面解除せず、安全な入出水地点と水中経路を設計。リード中/自由行動/ボール回収を競合させない。
- 浮くボールの位置・流れ・岸への回収、取得権限、犬と口の接続、取り出せない場所の復旧。
- Ownerの判定、途中参加/Owner交代、水面FXと音のローカル表示、モバイルでの負荷。

## 決定 (2026-09-27)

ユーザー回答 (音声の要旨):「水遊びは泳ぐことを求める。小さい犬種は泳ぐ。大きい犬種はチャプチャプ普通に入っていくでいい。クリップは作ってもらっているが、走る・歩くのアニメーションで十分泳いでいる感が出ると思う。どうせ犬かきなので、浮いて、ちょっと歩いている感じで動けば十分雰囲気は出る。あとは推奨で OK」。

1. **初期公開の範囲**: 推奨どおり、前提 + 段階 0 + 段階 1。水遊び場 1 か所、リードを外した犬だけ。段階 2 (浮くボールの回収) は後段で、別 Issue で扱う。
2. **泳ぐ犬種**: 泳ぎは求める。小型犬 (ポメラニアン・コーギー・ダックスフンド) が泳ぐ。柴犬は試作で確かめる。大型犬 (サモエド・ラブラドール) は浅瀬をチャプチャプ歩く。**淵は掘らない** (今の川の深さのまま)。6 犬種とも泳ぐことは求めない。
3. **リード中の入水**: 推奨どおり無し (外して遊ぶ)。
4. **クリップ**: 専用の泳ぎクリップは初期公開では作らない。ルートを水面基準にして浮かせ、既存の歩き / 走りクリップを再生すれば十分、というユーザー判断。
   - 上の「調べて決めること」の「走りのクリップ流用だけで泳ぎ完成とはしない」は、この決定で上書きした。
   - 見え方が足りない場合は、これまでどおり生成で作る (購入・外注は不要)。
   - 18 本のクリップと新しい State (`Wade` / `Swim` / `SwimIdle`) は、後で必要になったら作る。
   - 跳ねる動きと身震いは、既存クリップと PhysBone の減衰ロールで出せる範囲だけ。
5. **水遊び場の場所**: 推奨どおり、目的地「川辺」脇の東岸の曲がり。勾配が上限の境目なので、Play で確かめる。

レビュー済みの契約は変えていない: 復旧 3 段、`waterPose`、水中 Fetch の保持と解放、先読みの切替。
