# DES-DOG-004 川の水遊びと浮くボールの回収

2026-09-27ユーザー要望。川を作ったので、犬が水へ入り、少し浮いてパチャパチャと泳ぐ姿を見たい。ボールが水面に浮き、犬が泳いで取りに行き、くわえて帰る体験が目標。今回の橋・地面の景観修正とは別に設計する。人は現在の小川の通行状態を当面維持する。

## 調べて決めること

- 6犬種の体高差、浅瀬の歩行→浮遊/泳ぎ→岸へ上がる切替、水面高さと波の扱い。水深だけで小型犬が沈まない条件。
- 既存Animator/購入クリップに泳ぎがあるか。無ければ手足の動き、頭・口・ボールが水面から出る専用動作が必要。走りのクリップ流用だけで泳ぎ完成とはしない。
- 現状の河床NavMesh除外を全面解除せず、安全な入出水地点と水中経路を設計。リード中/自由行動/ボール回収を競合させない。
- 浮くボールの位置・流れ・岸への回収、取得権限、犬と口の接続、取り出せない場所の復旧。
- Ownerの判定、途中参加/Owner交代、水面FXと音のローカル表示、モバイルでの負荷。

## 受け入れ条件

- [ ] 浅瀬遊び、泳ぎ、ボール回収の段階と実装範囲を決める。
- [ ] 6犬種の通常歩行・リード・呼戻し・既存回収との切替を設計し、再現手順を持つ。
- [ ] 深さ/橋の下/岸の段差で沈む・浮きすぎる・取り残す条件を洗い出す。
- [ ] 同期・途中参加・Owner交代・Quest/iOSの検証条件と容量予算を決める。
