# IMP-DOG-027 洗われ中の行動の切替

親は [IMP-DOG-024](IMP-DOG-024-walk-and-wash-experience.md)。方式は [設計書](../../plans/2026-09-30-dog-wash-design.md) §1-5、§0-2 (行動の優先)、§6。依存は [IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md)。設計書の行番号は `c1e232b` 時点なので、着手時に現物で確かめ直す。

## 範囲

やること。

- 洗われ中の枝を、近接の `_paused` の更新の後・`ContinueSelectedBehavior()` の前へ入れる。洗われ中は行動の選択を無効にして毎フレーム処理し、終わったら選び直させる
- フラグの寿命の分離 (フレームのフラグは毎フレーム下ろす。`washingUntil` などは消さない)、休憩・おやつの保留の畳み方
- リード接続中の別の停止の判断 (`UpdateHillsideLeash()` の中、`LeashPose()` と非 Owner の姿勢も揃える)
- 水の中では出水・veto を優先し、上陸してから止まる
- 門の扱い: Fetch (`StartFetch`)・フリスビー (`CanPlay`)・新しいリード接続 (`ReqAttach`) は洗われ中を断る。集合・呼び戻し・ワープは洗浄の停止を解く
- 最後のストロークから 3 秒で解ける (拘束しない)。ルートは動かさず、姿勢は既存の調停へ要求として渡す

やらないこと。マスクと描画は [IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md)。セルの正本と同期は [IMP-DOG-026](IMP-DOG-026-wash-state-and-sync.md)。洗い場へ犬を呼ぶ方法は [IMP-ENV-007](IMP-ENV-007-main-wash-station.md)。

## 記録

2026-09-30: 実装。リード接続中の停止は `UpdateHillsideLeash` の引き離された時の追従の後・休憩の前 (条件: 持ち主のストロークが holdSeconds 以内 (`_StrokeAgeOf`)、持ち主が止まっている、リードに余裕。余裕とその幅は Owner だけが見る)。姿勢は `LeashPose` の前に決め、非 Owner も頭が揃う。門: `StartFetch` は false、`CanPlay` は "washing"、`ReqAttach` (新規) は黙って断る。かけっこの勝者の選定と Fetch への遷移にも洗浄の判定 (`Available()` は閉じない)。集合 (参加犬)・呼び戻し・ワープの切符の受理のエッジで `_ReleaseHold()` を 1 回呼ぶ。水の中では止めない。Codex の独立レビュー (高 2・中 1) を反映。ClientSim (run 20260930-025532): W-gate-attach / W-leash / W-gate-fetch / W-gate-frisbee / W-gather / W-release PASS、W-leash-other は SKIP (ClientSim は 1 人)。既存のハーネスの回帰 (同日): 53 周回 観測完了、78 水遊び 14/14、82 ワープ 22/22、**88 川の Fetch 30/31 (W3-Dachs が 2 回連続で FAIL、運搬中の口の余裕が 1 フレーム `carryMouthLow=1`)**。同じ内容の失敗は今回の変更前 (09-28・09-29 の run) にも断続的にあり、洗浄の門はダックス (wash が null) に触れないので論理の退行とは見ていないが、Update に毎フレームの処理 (`WashErrandTick`) を足したことでフレームが伸びた可能性は残る。3 回目の run (20260930-040301) は 31/31 PASS。IMP-DOG-020 の W2 と同じ種類の断続として観察を続ける。**残る穴** (担当の報告): 解除の後に他人がストロークすると保持が戻り、持ち主の解除前のストロークが 3 秒以内ならリードの停止が成立し得る (実害は小さい。PCVR で観察)。
