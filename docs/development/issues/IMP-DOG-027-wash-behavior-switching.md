# IMP-DOG-027 洗われ中の行動の切替

親は [IMP-DOG-024](IMP-DOG-024-walk-and-wash-experience.md)。方式は [設計書](../../plans/2026-09-30-dog-wash-design.md) §1-5、§0-2 (行動の優先)、§6。依存は [IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md)。設計書の行番号は `c1e232b` 時点なので、着手時に現物で確かめ直す。

## 範囲

やること。

- 洗われ中の枝を、近接の `_paused` の更新の後・`ContinueSelectedBehavior()` の前へ入れる。洗われ中は行動の選択を無効にして毎フレーム処理し、終わったら選び直させる
- フラグの寿命の分離 (フレームのフラグは毎フレーム下ろす。`washingUntil` などは消さない)、休憩・おやつの保留の畳み方
- リード接続中の別の停止の判断 (`UpdateHillsideLeash()` の中、`LeashPose()` と非 Owner の姿勢も揃える)
- 水の中では出水・veto を優先し、上陸してから止まる
- 門の扱い: Fetch (`StartFetch`)・フリスビー (`CanPlay`)・新しいリード接続 (`ReqAttach`) は洗われ中を断る。集合・呼び戻し・ワープは洗浄の停止を解く
- 最後のストロークから 3 秒で解ける (拘束しない)。ルートは動かさず、姿勢は既存の調停へ要求として渡す

やらないこと。マスクと描画は [IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md)。セルの正本と同期は [IMP-DOG-026](IMP-DOG-026-wash-state-and-sync.md)。洗い場へ犬を呼ぶ方法は [IMP-ENV-007](IMP-ENV-007-main-wash-station.md)。
