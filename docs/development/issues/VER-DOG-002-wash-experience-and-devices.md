# VER-DOG-002 洗浄の体験の評価と実機

親は [IMP-DOG-024](IMP-DOG-024-walk-and-wash-experience.md)。設計書 [§5・§6・§7](../../plans/2026-09-30-dog-wash-design.md)。**末尾の工程ではなく、各段の到達条件**として、[IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md)〜[IMP-ENV-008](IMP-ENV-008-wash-stations-along-course.md) の各段の後に行う。端末別の記録は [VER-WLD-001](VER-WLD-001-quest-ios-devices.md) へ接続する。

## 範囲

やること。

- 先行 Animal Wash の比較対象の版・体験場面を試作前に選び、同程度の汚れで泡立て→水の接触→すすぎを短く繰り返して比較する。良くなった点・違和感は、命中と変化の対応・所要時間・端末負荷の結果と分けて記録する
- ASMR の評価 (泡のもこもこ、接触と飛沫、帯状のすすぎ、音)。日向・木陰・ナイトモード、手元距離、立位・座位での見え方
- 2 人での洗浄、PCVR・Desktop・Touch の入力、1〜2 分での十分な清潔
- 対象端末 (Quest 単体・iOS) での描画・内容の保持・負荷。賭け 2・3 (設計書 §7) の端末側の結果
- 未使用時・主洗い場への集中・複数地点の分散での、6 匹＋Terrain＋植生の負荷・容量差の実測

やらないこと。実装と調整 (各 IMP Issue)。PC の見た目や Editor の検査をモバイルの合格に読み替えない。疑似入力 (ClientSim) の結果を実通信・PCVR の合格にしない。

AI 側で確かめる。

- [ ] 各段の確認項目を、試作の日ごとの到達 (設計書 §6) に対応づけたチェックリストにまとめ、ユーザーへ渡した (未確認条件を引き継ぎとして明記)
- [ ] 実機・Play の結果を Issue へ記録し、期待値の誤りと実装の誤りを区別して残した
- [ ] ハーネスで確認できた範囲と、実機・PCVR でしか確認できない範囲を分けて記録した

ユーザーが確かめる (Play / PCVR、2 人、実機)。

- [ ] 先行作との比較で、上回った点と残る違和感を記録した。「先行作以上」は、この比較の後にだけ書く (親: ASMR、比較)
- [ ] 泡をもこもこにする過程・接触と跳ね返り・泡と汚れが一緒に流れて毛が現れる過程・対応する音を体験し、洗い続けたくなる (親: ASMR)
- [ ] 2 人で分担して洗え、1 人でも完結できる。犬の Owner でない人の手応えが即時 (親: 2 人協力)
- [ ] PCVR・Desktop・Touch で狙った場所から変化する。座位・片手・ゆっくりした操作の結果を記録した (親: 入力機器)
- [ ] 標準的な汚れで 1 匹を 1〜2 分程度で十分きれいにでき、継続・再洗浄ができる。所要時間を記録した (親: 1〜2 分)
- [ ] Quest 単体・iOS で、マスクへ描き続けられ、内容が保たれる。描けない・消える・負荷が高い場合は設計書 §7 の切り分けで原因を記録した。未検証の端末は対応済みにしていない
- [ ] 端末別の負荷・容量差を、事前に定めた予算と照合した。BGM・川音・2 人の洗浄音を重ねても操作の音と会話が聞き取れる (親: 負荷・音)
- [ ] 基本体験が無料で完結し、スコア・解放・課金を前提にしていない (親: 無料)
