# IMP-DOG-010 散歩の寄り道を分かるようにし、立ち寄り場所と夜の散歩を足す

2026-09-21 の PCVR 所感。散歩の品質をもう一段上げたい。**今の寄り道は「分かりにくすぎる」** ので見せ方を作り直し、さらに犬が決まった場所へ立ち寄る動きと、夜の散歩の違いを加える。自由な散歩の全体は [IMP-DOG-003](IMP-DOG-003-walking-polish.md)、速さの段階は [IMP-DOG-009](IMP-DOG-009-walk-speed-tiers.md)、仕様の正本は [game-design §4](../../game-design.md)。

## 現状

寄り道は実装済みだが、次の理由で気づけない ([HillsideLeash.cs:185-202](../../../Assets/KominkaHillside/Imported/KominkaDogRun/Scripts/KD_DogWanderController.HillsideLeash.cs#L185-L202))。

| 項目 | 今の値 | 分かりにくい理由 |
|---|---|---|
| 起きる条件 | 手から 0.5×リード長以内で歩行中、4 s ごと 25 % | 犬が先行してリードが張り気味だと起きない。人が普通に歩いていると条件をほぼ満たさない |
| 行き先 | 斜め横 1.5〜2.7 m の NavMesh 上の点 | 道幅の中に収まる程度のずれで、進路の揺れと区別がつかない |
| 嗅ぐ | `Coast()` で止まるだけ、1.5〜3 s | **嗅ぐポーズが無い** (Animator に Sniff 系クリップが無く、Idle と同じ立ち姿)。短いので「止まった」以上に見えない |
| 中断 | 紐が 0.9× まで伸びたら即中断 | 人が歩き続けると始まってすぐ終わる |

Animator (`AC_KD_Dog_*`) にある姿勢: Idle (var1〜3) / Walk / Run / Sit / LieDown / Sleep / LookAt / Pet / Pickup / Call 系。地面に鼻を近づける動きは `Pickup` (くわえる) しか無い。

## 目的と範囲

### A. 寄り道のブラッシュアップ

- **見て分かる**: 道端まではっきり外れる (道の縁・木の根元・草の際など、道の中心線から離れた点を選ぶ)、嗅ぐ姿勢を持つ (Pickup の流用で足りるか、Sniff クリップを新規に作るかを試して決める。制作は [vrc-asset-production](../../../.claude/skills/vrc-asset-production/SKILL.md) の手順)、嗅ぐ時間を伸ばして人が気づいて足を止められる長さにする。
- **起きる**: 発生条件をリードのたるみだけに依存させない。先行中でも「次の通過点までの途中で道端へ寄る」形を許し、頻度は「散歩 1 往復で数回は見る」程度を目安に Play で決める。
- **人が付き合える**: 人が近づいて止まれば嗅ぎ続ける (延長)、人が歩き続ければ切り上げて追う。切り上げの見え方が「引きずられた」にならないよう、犬が自分で顔を上げて戻る間を持つ。
- 犬ごとの個性 (寄り道しやすい犬・しない犬) は値の差だけで作り、行動の種類は増やさない。

### B. 立ち寄り場所

- 道沿いに **犬が立ち寄りたがる場所** を数か所置く (候補: 木の根元、水場、石、見晴らし、広場の縁)。場所は通過点と同じく Editor で生成・配置し、後から増やせる形にする。
- 立ち寄ったときの行動は場所ごとに 1 種類 (嗅ぐ / 水を飲む / 座って眺める など)。既存の姿勢 (Sit / LieDown / LookAt / Pickup) で作れる範囲から始め、専用クリップは A の結果を見て決める。
- 人にとっての意味を持たせる: 犬が立ち寄る場所は人も足を止めやすい場所 (休憩場所・見晴らし) と重ねる。場所の制作は [IMP-ENV-001](IMP-ENV-001-hillside-polish.md) と分担し、本 Issue は犬側の行動と配置データを持つ。
- 立ち寄りは目的地を変えない。目的地・通過点・到着の契約 (game-design §4) の中で「寄り道の行き先が固定点になったもの」として扱い、同期変数を増やさない。
- 複数の犬が同じ場所へ同時に集中しない (同じ人の犬は 1 匹ずつ、または場所ごとの定員)。

### C. 夜の散歩

- [IMP-ENV-002](IMP-ENV-002-skybox-and-night-mode.md) のナイトモード ON のときに散歩で何が変わるかを決める。候補: 犬が人の近くに寄る (先行距離を短く)、立ち寄り場所の一部が夜だけ (光る虫・星を見る場所) になる、寄り道の頻度が下がる。
- ナイトモードはローカル切替なので、**犬の行動を夜で変えると人によって見える動きが食い違う**。行動を変えるなら同期される状態 (ライブの夜など) に限るか、見た目だけ (ライトなど) に留めるかを先に判断する。決まるまで C は候補扱いで、A・B を先に進める。

### 範囲外

- 犬同士の遊び (IMP-DOG-003 手順 3)、おやつへの反応 (IMP-DOG-006)、目的地の追加 (草むら等の新目的地は将来拡張)。
- 立ち寄り場所の景観そのもの (木・水場のモデル) は IMP-ENV-001。

## 進め方

1. A を 1 匹で試作する。行き先の選び方・嗅ぐ姿勢 (Pickup 流用) ・時間・人が止まったときの延長を入れ、PCVR で「寄り道していると分かるか」を確認する。
2. 姿勢が Pickup 流用で足りなければ Sniff クリップを作る (制作仕様と権利確認は共通手順)。
3. B の場所を 2〜3 か所置き、場所ごとの行動を既存姿勢で試作する。往復の途中で立ち寄る頻度と、目的地への到着が遅れすぎないバランスを見る。
4. 3 匹・6 匹で、同じ場所への集中と連続発生を確認する。
5. C は IMP-ENV-002 の Play 結果と同期方針を見てから範囲を決める。
6. 採用値を game-design §4 と保存済みシーンへ整合させる。
