## 次に一つずつ決める順番

1. **かざりと初回の支度**: 古民家と同じ品揃え・価格を基準に、初回付与 200/500 ポイントで好きな装いを選べるか比較した (**200pt で決定**)。全品を最初から開放する案は取り下げ済み。干渉調整・CE権利と所持の配線を確認する。
2. **おやつの実装差分**: 種類・基本操作・補充は古民家を継承し、接続犬を1匹ずつ呼ぶ変更をIMP-DOG-006で具体化する。品揃えを再び未決定に戻さない。
3. **呼ぶ・ポーズの実装差分**: 解除後に使う方針を土台に、接続中の除外表示・斜面での配置を具体化する。「接続したまま」の先行案は今回保留。
4. **撫でFX・追加おもちゃ・トレーナーの追加遊び・犬目線**をそれぞれ判断する。
5. **ライブ・設定・商品導線**の公開範囲を既存の担当Issueと揃え、最後にタブ名・並び・階層を決める。機能数とタブ数を同じにする必要はない。

採用した機能ごとに、対象犬 / 自分と他人への影響 / 使用中・所持なし・読込中・失敗 / 終了と復帰 / VR・Desktop・Touch をUI仕様へ落とす。ポイント・所持品の引き継ぎは今回対象外と決定。装着状態等の残る往復の扱いは [DES-WLD-001](DES-WLD-001-round-trip.md) と分担し、所持品の共有を前提にしない。

**距離フェード**

- 効く対象は**犬の毛マテリアル ke_Uzumore.mat (Uzumore シェーダ) の _DistanceFade / _DistanceFadeColor のみ**。MaterialPropertyBlock で上書きし、シェーダ一致を確認してから当てる (`KominkaDogRun: Assets/KominkaDogRun/Scripts/KD_DistanceFadeSettings.cs:240-251`)。
