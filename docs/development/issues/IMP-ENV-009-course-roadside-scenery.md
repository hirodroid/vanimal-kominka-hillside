# IMP-ENV-009 周回コースの道沿いの景観を足す

川沿いの周回コース ([IMP-ENV-004](IMP-ENV-004-river-loop-course.md)) の道沿いに何もなさすぎて、殺風景に感じる (2026-09-30 ユーザー指摘)。特に次の区間。

- 古民家から川まで行く間
- 川からの外周
- 川から奥の広場までの道

「今のままでもいいといえばいい」程度で、重さとの兼ね合いになるので、**優先度は低く、最後に回す** (ユーザー指定)。

## 範囲

やること。

- 上の区間に、木・低木・岩など道沿いの景観を少し置く。散歩している感じを足すのが目的で、密度そのものを目標にしない ([core-concept](../../core-concept.md): 豪華さは草木の密度ではなく眺め・道・犬・つながりで作る)
- 古民家の眺め、道の見通し、犬の見つけやすさ、フリスビー・ボールの遊びを邪魔しない位置に絞る
- 置く前と後で描画・容量を比べ、Quest 単体・iOS で重くならない量に抑える

やらないこと。コースの形・地形の変更 ([IMP-ENV-004](IMP-ENV-004-river-loop-course.md))。見晴らし・休憩場所・端の整理 ([IMP-ENV-001](IMP-ENV-001-hillside-polish.md))。洗い場まわり ([IMP-ENV-008](IMP-ENV-008-wash-stations-along-course.md))。
