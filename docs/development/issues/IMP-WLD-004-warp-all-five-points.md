# IMP-WLD-004 ポイント1〜5すべてにワープできるようにする

## 依頼

2026-10-02 ユーザー指定: 「ワープは1〜5のポイント全部ワープできるようにしたい」。[IMP-WLD-001](IMP-WLD-001-map-warp-and-join.md) の川辺・奥広場の2地点限定から拡張する。

## 範囲

- 現在プレイヤーに表示しているポイント1〜5をすべてワープ先にする
- 地図の目印、地点一覧、選択表示、ワープボタン、到着案内を同じ対象に揃える
- 既存の暗転・接続犬の同行・安全な着地点の検査を各地点にも適用する
- 地図の設計には目印6地点、散歩の行き先番号、地点IDが別々にあるため、実装前に現行表示との対応表を作る。古い設計図の番号や配列添字をそのまま「1〜5」と見なさない。対象外の地点を追加するかは別判断とする

仕様の参照元は [地図と移動の設計](../../plans/2026-09-27-map-and-travel.md)。2地点限定は初期実装の記録として残し、この追加要望と実装後の仕様を区別する。

## 完了条件

- [ ] ポイント1〜5の表示名・地点ID・着地点の対応が明記され、全5地点を選択してワープできる
- [ ] 各着地点で人と接続犬が安全な足場へ移動し、犬が散歩を続けられる
- [ ] 地図・地点一覧・到着案内の表示が一致し、PCVR / Desktop / Touch で選び分けられる
- [ ] 追加地点の保存値と既存ワープ処理を検証し、複数人・途中参加等の既存確認との分担を記録する
- [ ] 設計書と仕様を更新し、未確認端末の条件を [VER-WLD-001](VER-WLD-001-quest-ios-devices.md) へ引き継ぐ
