# IMP-DOG-040 呼び出したおもちゃを手の届く高さに浮かせる

## 依頼

2026-10-04 ユーザー: ボールやフリスビーを呼び出すと、そのまま下 (地面) にあるので拾いにくい。坂だと転がっていく。空中の取りやすいところに出したい。籠を出してその中に入れる? ほかにいい案を検討してほしい。

## 現状

[KH_ToyRecall.cs](../../../Assets/KominkaHillside/Scripts/KH_ToyRecall.cs) の `Place` (590 行〜):

- 頭の向きの水平前方 1.2 m (目の高さ / 1.6 で 0.5〜2 倍) の地点へ下向きのレイを打ち、**地面 + 半径 + 0.05 m** に置く
- ボールは普通の剛体のまま (速度を 0 にするだけ) なので、坂ではそのまま転がる。ディスクは地面に寝る
- 前作 (古民家) は平らな庭だったので、この置き方で困らなかった

## 案の比較

| 案 | 内容 | 評価 |
|---|---|---|
| **A. 手の届く高さに浮かせて待つ (推奨)** | 呼んだ人の胸の前 (VR: 頭から前 0.45 m・下 0.35 m。Desktop・スマホ: 視線の少し下・前 0.8 m。どちらも試作値) に、重力を切って静止させる。取るまで浮いたまま。20 秒 (試作値) 取られなければ、真下の地面へ下ろして眠らせる (転がらない) | かがまなくてよい。坂でも転がらない。モデルの追加なし。同期は今の仕組み (位置と重力の ON/OFF) のまま |

A の出現位置の変種として、**手元メニューの横** (メニューを見ている所に手があるので VR では最短) も試せる。まず頭の基準で作り、Play で遠い・近いを調整する。

## A を実装するときの注意 (コードから分かっていること)

- **浮かせ方は「重力を切る」。kinematic にしない。** 休んでいる犬の Fetch には「kinematic のまま残ったボールを解放する」安全網があり ([KD_DogFetchController.cs](../../../Assets/KominkaHillside/Imported/KominkaDogRun/Scripts/KD_DogFetchController.cs) 872 行付近)、kinematic だとぶつかる。川に浮くボールと同じ手段 (`VRCObjectSync.SetGravity(false)` + 速度 0) を使う
- **川の見回りが重力を戻してしまう。** `CheckRiverBalls` は「水の外で重力が切れている球」を見つけると `StopFloat` で重力を戻す (KH_ToyRecall.cs 421 行)。ディスク側にも同じ処理がある ([KH_Frisbee.cs](../../../Assets/KominkaHillside/Scripts/KH_Frisbee.cs) 688 行付近)。「呼び出しで浮かせている間」はこの処理から外す
- 持てば `OnPickup` が重力を戻す (ボール・ディスクとも既存)。追加の処理は要らない
- 呼んだ人が抜ける・Owner が替わると、新しい Owner の端末は「浮かせ中」を知らない。そのとき川の見回りが重力を戻して落ちる (宙に残り続けない)。この挙動を仕様にする
- 時間切れで地面へ下ろすときは、川岸へ戻すときと同じ `SettleBall` (速度 0 + Sleep) を使う
- 呼べる・呼べないの決まり (持たれている・犬が遊んでいる・水中でくわえている・冷却 2 秒・同じ犬のもう片方をしまう) は変えない
- 浮いている間は投げていないので、犬の Fetch・フリスビーの追走は始まらない (今と同じ)
