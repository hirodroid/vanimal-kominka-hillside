# IMP-DOG-047 洗浄アイテムの採否・改善回答を反映

## 根拠と対応範囲

2026-10-10受領の[回答JSON](../../../artifacts/wash-item-review/2026-10-10/vanimal-wash-review-2026-10-10T07-47-47-617Z.json)がユーザーの回答原本。[DES-DOG-008](DES-DOG-008-wash-paid-tools-and-effects.md)の最新採否（既存9品を残す、8品を外す、プールを追加）を実装へ反映する。

- アヒル・魚・竹の水鉄砲、花シャワー、大きなスポンジ、ブラシ、コロン、小さなアヒルを追加アイテムの選択対象から外す。原本ファイルの削除は目的に含めない。
- **Desktop用の標準スポンジは残す。** 除外対象は追加の大きなスポンジ。
- 選択UI・セット説明・写真・リスティング画像の品数と構成を揃える。未制作のプールは制作・導入前に利用可能と表示しない。
- ドライヤーの風のパーティクルに違和感があるという指摘を受け、風として自然に見える表現へ改善する。回答原文の「風邪」は文脈上「風」と解釈。具体的な粒子形状・色・速度などは未指定。
- タイル台は残しつつ、病院のように見える印象を改善する。具体的な色・材質・形状の変更案はこれから用意する。

販売セットの価格や共有条件を変更する回答はない。セット内容の変更と価格改定を混同しない。

## 分担

- 泡銃の保持方向：[BUG-DOG-010](BUG-DOG-010-wash-tool-grip.md)。
- 泡・水・タオル等の同時利用：[IMP-DOG-046](IMP-DOG-046-wash-tools-by-category.md)。
- プール制作：[IMP-DOG-044](IMP-DOG-044-wash-pool-platform.md)。

## 完了条件

- 採否に従ったアイテムだけを追加品として選べ、表示・説明・写真に除外品や旧品数が残らない。
- Desktop用の標準スポンジと、残す道具の既存機能が維持される。
- ドライヤーの風とタイル台の改善をユーザーが確認できる形で提示し、採用した変更を実装する。
- 選択対象の削減後も、参照・同期・途中参加・リセットが成立することを確認する。見た目と負荷は対象端末で確認し、結果を記録する。

今回は回答の整理と起票まで。Unity・モデル・画像は未変更。
