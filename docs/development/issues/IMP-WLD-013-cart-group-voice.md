# IMP-WLD-013 カートの同じグループ内で音声の距離減衰をほぼなくす

## 背景と決定

2026-10-12 ユーザー決定: 「同じグループだったらもう距離減衰はほぼなしにしちゃって」。今回は Issue 化の依頼であり、実装は未着手。

[自動散歩カート DES-WLD-004](DES-WLD-004-auto-walk-cart.md) は車間 3 m、左右のずれ 0.6 m の千鳥走行。直線では 8 台の先頭と最後尾が約 21 m 離れるため、隊列を保ったままグループ全員と会話できるようにする。

## 実装する振る舞い

- 同じカートグループの参加者同士に、音声の距離減衰をほぼなくす設定を適用する。先頭・中ほど・最後尾で、距離による聞き取りやすさの差をほぼ感じないことを目標とする。
- 対象はカートのグループ所属。別グループ・徒歩の人との間は通常の距離減衰を維持する。ワールド全体への放送にはしない。
- 合流が成立したら参加者同士へ適用する。合流要求中・拒否・取消だけでは適用しない。
- すれ違い待機など、所属を保った一時停止中も適用する。停止・降車・到着・ワープ・リスポーン・退室などで所属を離れたら、離脱者との聞こえ方を通常へ戻す。残った参加者同士は継続する。
- グループのマスター交代・途中参加・再合流・別グループへの移動でも、現在の所属に追従する。空いたグループ枠やプレイヤー ID の再利用で以前の相手への適用を残さない。
- 調整対象はプレイヤーの声。声の方向感はできるだけ保ち、利用者のミュート・個別音量設定を尊重する。BGM・川音・犬の声・アバターの効果音は対象外。

## 実装時に詰めること

- カートの所属状態を正本として、各端末で誰の声へ適用するかを決める。音声専用の別グループ管理は増やさない。
- 既存の音声設定と、その設定を書き換える処理の有無を確認する。離脱時に戻す値と責任を明確にし、他の音声制御を上書きしたままにしない。
- 減衰開始・終了距離などの具体値と更新タイミングは実装時に決める。可聴距離の上限だけを伸ばして、隊列後方の声が小さいままにならないようにする。通常の隊列・カーブ・合流中の位置差を含めて確かめる。
- API の仕様は [VRChat Player Audio](https://creators.vrchat.com/worlds/udon/players/player-audio/) を参照する。「ほぼ減衰なし」はユーザーの採用方針で、設定値や実機の聞こえ方はまだ確定していない。

## 完了条件

- [ ] 同じグループの先頭と最後尾で、通常の声量で相互に会話でき、距離による音量差をほぼ感じない。最大隊列の距離でも確認する。
- [ ] 別グループ・徒歩の人との音量と距離減衰が変わらない。同じインスタンスに複数グループがいても混線しない。
- [ ] 合流成立・取消・拒否、途中参加、マスター交代、一時待機、離脱、再合流、別グループへの移動で適用と解除が正しい。
- [ ] 到着・降車・ワープ・リスポーン・退室・グループ解散後に音声補正が残らない。
- [ ] ミュート・個別音量と声の方向感を実機で確認する。PCVR・Desktop・Quest 単体・Android/iOS の対応結果と未確認条件を分けて記録する。
- [ ] 実装・独立レビューと、複数人の実クライアントでの聴取結果を記録する。設定値の検査だけを聞こえ方の合格にしない。

設計と値は [実装設計 §2026-10-12 グループ内の音声](../../plans/auto-walk-cart/implementation.md#2026-10-12-グループ内の音声-imp-wld-013)。ClientSim では相手の端末の聞こえ方が出ないので、**ここは複数人の実クライアントでしか判定できない**。事前準備: Build & Test をし直した / コンソールにエラー無し / 全員のミュート・個別音量を既定に戻した。

**A (1 人でできる)**
- [ ] A1 乗車・降車・合流の取消でコンソールに例外が無く、`[KH_Cart] voice-*` のログが自分以外の相手にだけ出る (1 人なら 0 件)。

**B (2 人以上。複数人の聴取)**
- [ ] B1 先頭と最後尾: 同じグループで 3 台以上 (できれば 8 台) 並び、直線・カーブ・合流直後に、先頭と最後尾が普段の声量で相互に聞き取れ、近くの人との音量差をほぼ感じない。声の向き (左右) は残っている。
- [ ] B2 別グループ・徒歩: 別グループのカートの人と、カートの横を歩く人の声が、普段どおり距離で小さくなる (隊列の後ろ 30 m で聞こえ過ぎない)。逆向きのすれ違いでも混線しない。
- [ ] B3 離脱後の復元: 停止ボタン・ジャンプ・到着・ワープ・リスポーンで降りた人と、残った人が、降りた直後から普段の距離減衰に戻る (20 m 離れて聞き比べる)。残った人同士は続く。グループが解散した後も残らない。
- [ ] B4 途中参加・再合流・別グループへの移動: 途中参加した人がカートに合流すると掛かり、別グループへ合流し直すと前のグループの人とは普段どおりに戻る。退室した人がいても他の人に影響しない。
- [ ] B5 後方の声がこもる (ローパス) か、ミュート・個別音量が効くか。端末 (PCVR・Desktop・Quest 単体・Android/iOS) ごとに結果と未確認を分けて書く。

| 症状 | 見るところ |
|---|---|
| 何も変わらない | アップロードし直したか → ログ `voice-apply` が出ているか (出ていなければ所属の判定、出ていれば値の不足) |
| 後方が小さい | `voiceNear` が隊列より短い (カーブ・合流の追いつきで 21 m を超える) |
| 後方がこもる | `voiceLowpass` を false にして比べる |
| 降りても大きいまま | ログ `voice-restore` の有無 (無ければ解除の経路、あればアバター変更等で再適用されていないか) |
