# IMP-ENV-007 主洗い場の整備 (門の外)

親は [IMP-DOG-024](IMP-DOG-024-walk-and-wash-experience.md)。方式は [設計書](../../plans/2026-09-30-dog-wash-design.md) §2、§8 (位置の既定値)、§6。依存は [IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md)。位置・置くものは案で、Unity での測定後に確定する。

## 範囲

やること。

- 候補地 (リード台の西側の平地、x 40〜44・z 40〜44 付近) の地形の高さと空きの測定と、位置の確定。スポーンから見え、犬の待機の輪 (z 46〜48)・おやつ・店番・周回の起点に重ならないこと
- 低い洗い台 (すのこ状)、道具の棚 (スポンジ・シャワー・タオルを 2 組)、蛇口とホース、桶
- 道具を置き場へ戻す処理 (既存のボール・ディスクの置き場の作法を調べて合わせる) と、見える戻し先
- 犬を洗い台へ呼ぶ方法の決定 (道具を持って近づくと寄ってくる、が第一案)
- ビルダーを `Tools/KominkaHillside/Course/NN` に Build と Verify の組で足し、[production.md](../../plans/des-env-002/production.md) の表へ登録する

やらないこと。洗浄の処理そのもの ([IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md)・[IMP-DOG-026](IMP-DOG-026-wash-state-and-sync.md))。手動調整済みの配置 ([IMP-ENV-003](IMP-ENV-003-spawn-and-dropped-portals.md) は hold のまま) を動かすこと。古民家の建物への接近・室内導線。川辺・広場・裏山の地点 ([IMP-ENV-008](IMP-ENV-008-wash-stations-along-course.md))。小物の作り込み (試作の後に相談)。
