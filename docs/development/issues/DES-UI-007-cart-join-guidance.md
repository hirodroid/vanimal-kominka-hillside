# DES-UI-007 カートの看板で「合流」を分かりやすく伝える

## ユーザー報告と依頼 (2026-10-14)

フレンド何人かと訪れた際、カートの看板では合流が分かりにくいようで、みんなそれぞれのカートに乗ってしまった。**どうしたら分かりやすくなるか、相談するところから始めたい。**

目指すのは、一緒に散歩したい人が、看板・メニューを見て合流の存在と操作を理解し、同じグループで走れること。各自が自分のカートに乗ること自体は、一人乗りカートの既存仕様に沿っている。今回の課題は「それぞれ乗る」ことと「同じグループで一緒に走る」ことの関係が伝わっていない点として調査する。

実際に押したボタン・表示されていた合流先・各人のグループ状態は未確認。別々のグループで出発したのか、合流先に気づかなかったのかなど、原因はまだ断定しない。

## 相談・検討する内容

- 現在の看板と乗り場メニューを実物で確認し、最初に見える内容、出発と合流の文言・配置・目立ち方、合流先一覧への気づきやすさを整理する。
- 「自分で出発する」と「先に乗った人と一緒に走る」の違い、および合流しても一人ずつ自分のカートに乗ることを、どう伝えるか検討する。
- 最初の一人が出発し、後続がその人のグループへ合流する流れを、短い説明・図・操作の並びで伝える案を比較する。
- 参加したい相手を名前などから識別できるか、合流先がない・受付停止などの場合にも次の行動が分かるかを検討する。
- すでに各自で出発した後でも、一緒に走り直すための現行手順が伝わるか確認する。操作や仕様の変更が必要な場合は、案内だけの変更と分けて相談する。
- 文言の改善、看板の構成変更、メニュー内の出発／合流の見せ方など、複数案と推奨理由を示してユーザーと相談する。具体的な文言・配置・操作方式は、この起票では確定しない。

## 範囲

本 Issue は、分かりにくさの整理と改善案の相談・設計を対象とする。採用案を決めてから実装範囲と確認方法を整理する。一人乗り・グループ合流の仕様変更や自動合流を、起票だけで採用したものとは扱わない。

## 完了条件

- [ ] 現行の看板・乗り場メニューと、出発／合流で迷う箇所を整理している。
- [ ] フレンド同士で一緒に走り始める流れが分かる改善案を比較し、ユーザーと相談している。
- [ ] 合流先の識別、合流できない場合、各自で出発した後の案内の扱いを整理している。
- [ ] 採用案・未決定事項・実装範囲を記録し、関連仕様へ反映している。
- [ ] 実装後に「初めて使う複数人が口頭で操作を教わらず、同じグループに合流できるか」を確認する後続作業を明確にしている。
