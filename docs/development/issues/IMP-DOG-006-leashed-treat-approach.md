# IMP-DOG-006 リード接続中もおやつに反応して寄ってくる

## 要望

2026-09-20 ユーザー要望: 「つないでても、おやつ上げたら寄ってくるとか、したい」。

リードでつないでいる犬とも、散歩の途中におやつで触れ合えるようにする。接続を解除しなくても、おやつに反応して与える人の近くへ寄ってくる体験が中心。今回は要望の記録であり、実装・操作方法・公開範囲は未確定。

## 想定する体験

- 散歩中や立ち止まっているときにおやつをあげようとすると、接続中の犬が気づいて近づく。
- 接続を保ち、リードの行動範囲内で無理なく近づける。
- おやつを食べ終えた、または与えるのをやめた後は、元の目的地を保って散歩へ戻る。

上記の復帰や範囲の扱いは実装時に具体化する案。反応距離・速度・時間はここで固定しない。

## 実装前に決めること

- 反応のきっかけ: おやつを取り出す・手に持って差し出す・使用する、のどの段階で寄ってくるか。
- 反応対象: 1匹を選ぶか、近くの接続犬が反応するか。複数匹へ与える順番と密集の扱い。
- 他の人がつないでいる犬や未接続犬も反応するか。複数人がおやつを差し出した場合の扱い。
- 散歩・寄り道・撫でなどとの優先順位、届かない場所へ差し出された場合、途中で移動・解除した場合の終了と復帰。
- 古民家のおやつ機能から利用する範囲と、裏山メニューへの入口・端末別操作。既存の集合機能とは対象・用途を区別する。

## 完了条件

- [ ] おやつの出し方・反応対象・接近から終了までの流れを決め、仕様の正本へ反映した
- [ ] リードを解除せず、おやつへの反応で犬が近づき、与える操作が成立する
- [ ] おやつの終了・中断後に、接続と元の目的地を保って散歩へ復帰する
- [ ] 1匹・複数匹で、行動範囲・到達不能・密集・途中解除を確認した
- [ ] 複数人の同時利用と途中参加で、確定した反応対象・接続・移動状態が整合する
- [ ] 採用する端末の操作について、ユーザーのPlay・実機確認結果を記録した
