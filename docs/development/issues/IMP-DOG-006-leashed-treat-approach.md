# IMP-DOG-006 リード接続中もおやつに反応して寄ってくる

## 要望

2026-09-20 ユーザー要望: 「つないでても、おやつ上げたら寄ってくるとか、したい」。

リードでつないでいる犬とも、散歩の途中におやつで触れ合えるようにする。接続を解除しなくても、おやつに反応して与える人の近くへ寄ってくる体験が中心。起票時は要望の記録のみ。2026-09-23 に下記の操作方針を了承し、詳細設計・実装・公開範囲の決定はこれから行う。

## 2026-09-23 呼び寄せの用途を具体化

ユーザーの方向性: **おやつで近くの1匹を呼び寄せ、撫でたり首輪を触ってリードを外したりする。次のおやつで次の1匹を呼び、順に外せる。** 3匹などを連れていても全員が一斉に集まる形にはせず、メニューで犬を指定する操作を増やすより、1匹ずつ「おいで」と関わる手間を散歩の体験として残したい。

仕様の正本は [game-design §4「おやつで散歩中の犬を呼び寄せる」](../../game-design.md)。おやつの移植採用は決定済みだが、この接続中の呼び寄せは未実装。

2026-09-23 続くユーザーの「OK」で、**自分の接続犬の最寄り1匹を呼ぶ / 撫でる・首輪を触るため少し待つ / 外したら次の接続犬を呼べる / 外さず終えたら散歩へ戻る / 既存のメニュー解除を残す**という操作方針を了承。距離・秒数・下記の対象保持等の詳細は実装時に詰める。

了承した方針と、実装時に詰める詳細:

- 自分の接続犬がいる間は、その中の反応可能な最寄り1匹を優先する。外した犬が足元に残っても次の接続犬を呼べるようにする。他人の接続犬を横取りしない。
- 接近を始めた1匹は途中で別の犬に選び直さず、食べ終わり・中断・解除まで対象を安定させる。次の呼び寄せで選び直す。
- 到着したら、撫でる・首輪へ触れる時間を確保する。食べ終わった瞬間に歩き出して首輪へ手が届かなくなる挙動を避ける。待つ時間・撫でている間の保持は調整する。
- 解除操作はプレイヤーが首輪を触って行う。おやつで自動解除する機能にはしない。接続を保ったまま呼び寄せを終えた場合だけ散歩へ戻り、途中で外した場合は解除後の通常の自由行動へ戻す。
- 自分の接続犬が0匹のときの未接続犬への反応、反応可能な自分の犬がいない場合、最後の解除直後の再反応、複数のおやつの同時使用は別途詰める。

移植済みソースの読取メモ: `Assets/KominkaHillside/Imported/KominkaDogRun/Scripts/KD_TreatBox.cs` の `EligibleDog` / `Reconcile` / `DistMmOf` に反応可否・割当・おやつからの距離比較がある。これだけで自分の接続犬を優先する契約や、リード散歩中の接近・待機が成立しているとは扱わない。

## 想定する体験

- 散歩中や立ち止まっているときにおやつをあげようとすると、接続中の犬が気づいて近づく。
- 接続を保ち、リードの行動範囲内で無理なく近づける。
- おやつを食べ終えた、または与えるのをやめた後は、接続を保っていれば元の目的地への散歩へ戻る。途中で外した犬は通常の解除後の自由行動へ戻る。

上記の復帰や範囲の扱いは実装時に具体化する案。反応距離・速度・時間はここで固定しない。

## 実装前に決めること

- 反応のきっかけ: おやつを取り出す・手に持って差し出す・使用する、のどの段階で寄ってくるか。
- 反応対象: 自分の接続犬の最寄り1匹を優先する方針は了承済み。距離の基準・同距離の扱い・対象保持を具体化する。全員集合にはしない。
- 他人の接続犬を横取りしない方針を守り、自分の接続犬が0匹のときの未接続犬への反応と、複数人がおやつを差し出した場合の扱いを具体化する。
- 散歩・寄り道・撫でなどとの優先順位、届かない場所へ差し出された場合、途中で移動・解除した場合の終了と復帰。
- 古民家のおやつ機能から利用する範囲と、裏山メニューへの入口・端末別操作。既存の集合機能とは対象・用途を区別する。
