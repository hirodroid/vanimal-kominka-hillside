# DES-DOG-006 お手入れの方式を決める

親は [IMP-DOG-024](IMP-DOG-024-walk-and-wash-experience.md) (実装順 1「参照調査と体験設計」)。設計の本文は [方式の設計書](../../plans/2026-09-30-dog-wash-design.md)。

## 決めること

- 汚れ・泡・濡れをどう見せるか (既存の毛のマテリアルへ差し込むか、上へ重ねるか)
- 道具が当たった位置をどう取り、見た目へどう描くか
- 同じ犬を 2 人で洗う時に、誰が状態を確定し、何を共有するか
- 洗われている犬と、リード・Fetch・フリスビー・集合・呼び戻し・ワープの優先順位
- 子 Issue への分割

## 受け入れ条件

- [x] 設計書に、方式・状態ごとの操作結果・同期・行動の切替・予算・分割が書かれている
- [x] 別ツール (Codex) の相談・レビューの指摘を検証し、採否を設計書へ反映した
- [x] 最初に確かめる賭けと、外れた時の切り替え先が決まっている
- [x] 賭けの結果 (IMP-DOG-025 の試作) を受けて方式を確定した。実機の結果が出るまでは端末の可否を確定にしない (PCVR 1 人は確認済み。Quest 単体・iOS・2 人は未確定のまま VER-DOG-002 へ移した)

## 記録

2026-09-30: 調査 3 本 (先行 Animal Wash の棚卸し、裏山の犬システムの接続点、洗浄表現の技術制約。いずれも読み取りのみ) から設計書の初版を作成。方式は案で、Unity・実機の確認は未実施。

## 2026-10-03 完了の記録

方式 (汚れ・泡・濡れの見た目、マスクのシェーダーパス Brush / Restore / Decay / Runoff、ストロークによる 2 人の同期、洗いと他の行動の切替) は決定し、実装まで進んだ。この Issue の仕事 (方式を決める) は終わりとして閉じる。

- 実装: [IMP-DOG-025](IMP-DOG-025-wash-prototype-one-dog.md) (代表 1 匹の試作)、[IMP-DOG-024](IMP-DOG-024-walk-and-wash-experience.md) (6 匹・4 洗い場)、[IMP-DOG-028](IMP-DOG-028-wash-sound-and-reactions.md) (音・反応)、[IMP-DOG-031](IMP-DOG-031-collar-release-interact-only-own-walk.md) と IMP-DOG-025 のすすぎ改善 (f9ed660)、[IMP-DOG-035](IMP-DOG-035-wash-call-dog-to-station.md) / [IMP-DOG-037](IMP-DOG-037-wash-call-availability-and-range.md) (洗い場へ犬を呼ぶ)。
- ユーザー確認: 2026-09-30 の PCVR 1 人 (`109935b`、設計書 §8) と、2026-10-02 の総合判断「PCVR 1 人 基本全部見たから OK」(洗い心地の項目別の記録はない)。
- 賭け ([設計書 §7](../../plans/2026-09-30-dog-wash-design.md)) の結果:
  - 賭け 1 (UV に有害な重なりが無く位置マップで帯が連続する): 通過。`Wash/1` で 6 匹とも重なり 0 (2026-09-30、IMP-DOG-025)。切り替え先は使っていない。
  - 賭け 2 (殻が毛の上に自然に乗る): PC の Editor・Play で成立 (IMP-DOG-025 の完了条件)。PCVR 1 人の見た目もユーザーが了承。自前の不透明シェーダーへの切り替えは使っていない。
  - 賭け 3 (対象端末でマスクへ描き続けられ、2 人の表示がずれない): PCVR 1 人では描き続けられると判断された。**2 人のずれと Quest 単体・iOS の実機は未確認。** IMP-DOG-025 の「PC での連続描画と 2 人の表示のずれ」は未チェックのまま。これらは方式を変える条件ではなく端末・人数の検証なので、[VER-DOG-002](VER-DOG-002-wash-experience-and-devices.md) と VER-WLD-001 で追う。外れた時の切り替え先 (RenderTexture の形式・描画頻度の間引き・順序と復旧の見直し) は設計書 §7 に残してある。
