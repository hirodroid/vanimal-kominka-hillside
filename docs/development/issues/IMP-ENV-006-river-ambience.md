# IMP-ENV-006 川のせせらぎ音を配置する

2026-09-29 ユーザー依頼。川のせせらぎがまだ入っていないため、ユーザーが制作中の効果音を格納するディレクトリを用意し、完成した音源を川へ設定する。

## 音源の格納先

- **`Assets/KominkaHillside/Audio/Ambience/River/`** — 今回作成。音源は未受領。
- 既存の `Assets/KominkaHillside/Audio/Water/` は犬の水しぶき・水遊び用。川の常時環境音は上記に置く。
- ユーザー制作音源を使う。ファイル名・形式・長さ・ループ点は受領後に確認し、必要なインポート設定を決める。

## 実装すること

- 本番 `Assets/Scenes/VRCDefaultWorldScene.unity` の川沿いにせせらぎ音を配置する。川の形と散歩道からの聞こえ方に合わせて音源位置・数を決める。
- 川へ近づくと自然に聞こえ、離れると減衰するように3D音源の範囲と音量を調整する。複数音源が重なる場所で音量が過大にならないようにする。
- 継ぎ目やクリックが目立たないループ再生にする。会話・犬の音を邪魔しない音量に調整する。
- 既存の設定画面の音量操作への接続先を確認する。ライブ中の音量・停止方針は [DES-WLD-002](DES-WLD-002-sound.md) と整合させる。
- 連続した環境音の再生はローカルを基本候補とし、再生位置の厳密な同期が必要かを実装時に判断する。
- 音源追加による容量・常駐メモリへの影響を確認し、PC／Android／iOS向けのインポート設定を調整する。

## 範囲と関連

- 今回は格納ディレクトリの作成とIssue登録まで。音源の制作はユーザーが進めており、川への配置は音源受領後の作業。
- [DES-WLD-002](DES-WLD-002-sound.md) が扱う音全体の設計のうち、川のせせらぎの導入を本Issueに分ける。BGMや他の環境音は本Issueに含めない。
- シーンの変更は [周回版の運用記録](../../plans/des-env-002/production.md) に従う。
