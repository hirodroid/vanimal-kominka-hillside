# IMP-ENV-005 時間経過のナイトモードとオート／マニュアル切替

2026-09-29 ユーザー依頼。入室後の時間経過で徐々に暗くする。既存のナイトモードのスライダーと描画を活用し、設定画面のナイトモード欄でオート／マニュアルを選べるようにする。

## 要件

- **オート**: インスタンス内で共通の時間経過・暗さをグローバルに同期する。途中参加者も、その時点の共通の暗さに合流する。
- **マニュアル**: 既存スライダーで自分の見え方だけをローカルに調整する。他人の暗さや共通の時間経過を変更しない。
- モードの選択は個人単位。同じインスタンスにオートとマニュアルの人が混在できる。
- マニュアルからオートへ戻ると、現在の共通の時間経過へ復帰する。個人の入室やモード切替で共通の時計をリセットしない。
- 既存の空・乗算オーバーレイによる連続的な暗さ表現を再利用する。

## 実装前に決めること

- 「入ってから」の時間の起点。**最初の参加者の入室を共通の開始時点にする案**を候補とし、各自の入室時刻から別々に進める方式とは区別する。ユーザー指定の起点としてはまだ確定しない。
- 暗くなる所要時間、開始と到達時の暗さ、変化の仕方。夜で止めるか、昼夜を循環させるかも未決定。
- 初回のモード、モードの保存有無、再入室時の扱い。既存の個人の暗さ保存値をどう引き継ぐか。
- オート時のスライダーの表示・操作可否、モード切替時のフェードとマニュアル値の復元。
- 共通時計の管理主体と引継ぎ。管理者の退出・Owner交代・途中参加でも進行が巻き戻らないこと。
- 既存のライブ暗転入力との優先関係。通常のオート／マニュアルとライブ演出が競合しない契約にする。

## 既存実装と範囲

- `Assets/KominkaHillside/Scripts/KH_NightMode.cs` はローカル描画と暗さの PlayerData 保存を持つ。オートの値で個人の保存値を上書きしない設計を検討する。
- 設定面のスライダーは [IMP-UI-001](IMP-UI-001-menu-table-driven-and-settings.md) で実装済み。本Issueはその拡張。
- [初期のナイトモード記録](../../plans/2026-09-21-sky-and-night-mode.md) の OFF/ON・保存なしは初期仕様。現在のスライダー実装と区別する。
- 実装時に [仕様](../../game-design.md) と [UI仕様](../../world-ui-spec.md) の関連箇所を更新し、既存のローカル専用という記述との整合を取る。
- 今回はIssue登録のみ。昼夜に伴う犬の行動変更は含めない。
