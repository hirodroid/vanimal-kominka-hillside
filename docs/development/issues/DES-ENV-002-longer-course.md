# DES-ENV-002 散歩コースの延長 (周回・川) とワールドの広さを決める

[体験会の記録](../../plans/2026-09-26-group-playtest.md) (2026-09-26、15 人) でのユーザーの要望:

- 散歩コースが短い。もっと長くていい。**周回コース**が欲しい。**川**が欲しい
- いまは 2〜3 分で終わるが、**10 倍くらい、20 分くらいかかるコース**があってもいい
- もっと広く。**ワールド自体を少し広くしてもいい**
- ただし**容量と FPS と関連で考える**必要がある。スマホでも快適だったので、それは保ちたい

## いまの前提 (変える場合はここで決める)

- 道は門前〜広場中心 113.9 m、通過点 17 (7 m 間隔) ([game-design §4 道と通過点](../../game-design.md#道と通過点-ウェイポイント))
- 2026-09-19 v4 でユーザー訂正: **円形の周回路は不要**。門から登る道と上部の遊び場 ([core-concept](../../core-concept.md) 記録)。今回の要望はこれを覆すので、決定として書き直す
- [core-concept](../../core-concept.md): 「小さな空間でも散歩した感じがする」が絶対に外せない体験の一つ。**広くすること自体は目的ではなく、散歩した感じを長く保つのが目的**
- [overview §1](../overview.md): スコープは広げない。景観の増量は後回し
- 容量: Android 37.91 MB ([ビルドサイズ実測](../../plans/2026-09-24-build-size-audit.md))。Terrain の拡張はハイトマップ・スプラット・木の配置で増える
- 負荷: Quest 単体・iOS の実機は未測定 ([VER-WLD-001](VER-WLD-001-quest-ios-devices.md))。体験会のスマホは「快適」の所感のみ

## 検討する案

1. **周回**: 広場から別の道で門へ戻る (下り道)。往復と違う景色になり、犬の目的地は「広場」「入口」のままで済む
2. **長い散歩道**: 見晴らしの先に尾根道や谷道を足し、目的地を増やす (game-design §4 は目的地追加に対応できる構成)。20 分は歩く速さ 1.1〜2.4 m/s で 1.3〜2.9 km 相当。現行の 10〜25 倍で、Terrain の面積・木・NavMesh・通過点がそれに応じて増える
3. **川**: 沢を道沿いに置く (見た目 + 音、[DES-WLD-002](DES-WLD-002-sound.md))。水面シェーダはモバイルで軽いものに限る。犬の水遊びは範囲外 (犬の行動を増やさない)
4. **段階**: まず周回 + 短い川で「散歩した感じ」が伸びるかを PCVR で見てから、長いコースを判断する
