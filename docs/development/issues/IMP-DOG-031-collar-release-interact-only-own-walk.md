# IMP-DOG-031 首輪の「外す」は自分が散歩中の犬だけ

リードを外す首輪のインタラクト (`KH_LeashCollar.Interact` → `KH_LeashManager._RequestDetach`) が、散歩していない犬にも常に出ている。付ける操作は持った金具を首輪に触れさせて行うので、首輪のインタラクトが要るのは外す時だけ。常に出ていると、撫でる時などに首輪の判定が手の操作を取ってしまう (2026-09-30 ユーザー指摘)。

## 範囲

やること。

- 首輪のインタラクトは、ローカルのプレイヤーがその犬のリードを持っている時 (`walkers[dogIndex]` が自分) だけ有効にする。それ以外 (散歩していない犬、他の人が散歩中の犬) は `DisableInteractive` で消す
- 接続・解除・持ち主の交代 (Owner 移譲、退室) に追従して切り替える。毎フレーム見るか、`walkers` の同期受信で切り替えるかは実装時に選ぶ

やらないこと。付ける操作 (金具のタッチ) の変更。解除の権限判定 (`ReqDetach` は既に持ち主以外を拒否しているので変えない)。メニューからの解除。

## 完了条件

AI 側で確かめる。

- [ ] コンパイル完了とエラー 0
- [ ] ClientSim ハーネスで、散歩していない犬・自分が散歩中の犬・解除後の犬で、首輪のインタラクトの有効／無効が切り替わることを確認した (他の人が散歩中の犬は 2 人が要るので未確認として残す)

ユーザーが確かめる (Play / PCVR)。

- [ ] 散歩していない犬を撫でる・洗う時に、首輪のインタラクト表示が出ず、手の操作を取られない
- [ ] 自分が散歩中の犬は、今までどおり首輪のインタラクトで外せる
- [ ] 2 人で、他の人が散歩中の犬の首輪にインタラクトが出ない
