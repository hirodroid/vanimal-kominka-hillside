# DES-UI-005 バニマルトレーナー・課金アイテムの説明と購入導線を見直す

## 依頼と目的

2026-10-02 ユーザー依頼: 遊び方ガイドとマップの看板を検討するときに、バニマルトレーナーの説明と課金アイテムの説明も見直す。今回は **課金につなげることを意識して設計する**。

来訪者が特典や商品の魅力を知り、自分が欲しいものを判断して購入し、ワールド内で使い始められる流れを作る。[DES-UI-004](DES-UI-004-walk-destinations-and-boards.md) のお散歩・フリスビー・洗浄のガイドとマップ、古民家に似合う看板のレイアウトと合わせて検討する。

今回は検討課題の登録。具体的なレイアウト・文言・商品構成・価格の決定や実装は後続作業とする。

## 検討すること

1. **対象の棚卸し**: バニマルトレーナーの特典、現在販売・利用できる課金アイテム、今後展開する商品の予定・候補を整理する。裏山で使える内容、古民家との共通利用、未実装・未決定を明記する。
2. **魅力が伝わる説明**: 商品名だけでなく、購入すると犬との遊びがどう広がるかを、具体的な利用場面・見た目・短い説明で示す。トレーナーの集合など、実際の特典を紹介する内容を検討する。
3. **看板とメニューの役割**: 入口の遊び方ガイドと併せた紹介、専用の特典・商品紹介看板、遊びの場面や手元メニューからの案内を比較し、配置・情報量・読む順序を決める。看板の外観と配置は DES-UI-004 と一緒に設計する。
4. **購入までの導線**: 「知る → 欲しいと思う → 詳細・価格・利用条件を確認する → 購入する → 使う」の各段階で、どこを見て何を操作するかを示す。現行の導線で見つけにくい入口や行き止まりを洗い出す。
5. **商品と権利の説明**: 無料の基本体験、滞在ポイントで解放するもの、Credits で購入するものを読み分けられるようにする。**ワールド共通の課金商品はトレーナーだけ** (2026-10-12 ユーザー訂正)。ライブを含む他の商品は古民家で購入済みでも裏山では別途購入する。裏山で購入済みの人には利用方法を案内し、共通商品とワールド別商品の購入先・所有表示を混同させない。
6. **購入につながるかの確認**: 初見の人がトレーナーの価値・欲しい商品の内容・購入場所・購入後の使い方を説明でき、案内から購入入口まで迷わず進めるかを確認する手順を作る。実際の購入状況をどう把握・評価するかも、利用可能な情報を調べたうえで検討する。

## 既存設計との関係

- 現行の特典・価格・無料範囲・共通購入権は [game-design](../../game-design.md) と [world-ui-spec](../../world-ui-spec.md) を基準に棚卸しする。変更案は既存仕様と区別して記録し、採用時に正本へ反映する。
- [DES-UI-003](DES-UI-003-menu-scope-and-polish.md) の「追加の売り場・ギフト・告知帯」は提案・保留。今回の購入導線見直しで必要性を再検討するが、これらの追加自体を決定済みにはしない。
- [IMP-PRG-001](IMP-PRG-001-ledger-shopkeeper-points.md) は台帳・ポイント・購入と権利判定、[IMP-UI-001](IMP-UI-001-menu-table-driven-and-settings.md) は手元メニュー実装を担当。本 Issue は説明・見せ方・購入への流れを決め、必要な改修を引き継ぐ。
- トレーナーの共通購入権は [DES-DOG-001](DES-DOG-001-leash-walking.md)、有料ライブの利用条件・演目は [DES-LIV-001](DES-LIV-001-hillside-live.md) / [DES-LIV-002](DES-LIV-002-live-lineup-and-parade.md) と合わせる。
