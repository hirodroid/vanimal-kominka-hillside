# DES-DOG-008 洗いの追加アイテム (課金) のアイディア

## 依頼

2026-10-05 ユーザー (要旨はユーザーの言葉のまま。音声入力の聞き違いと思われる語は直した):

- 一旦登録しておく。洗いの追加は **全部課金アイテムにする予定**。
- **泡もこもこ銃**: ウォーターガンのような形。今はボトルでシュッシュッとかけているが、洗車のように泡をブワーッと吹き出して、犬を泡まみれのもこもこにできる。
- **水鉄砲**: シュシュッと撃つ。
- **シャワーヘッドの形** をいろいろ変えられる。
- **泡の色**: ピンクなど。
- **泡のパーティクル**: 泡で洗っている時に、ハート・肉球などのパーティクルがブワッと出る。撫でパーティクルと同じような感じ。

土台は [DES-DOG-007 手洗いとシャンプー](DES-DOG-007-hand-washing-and-shampoo.md) / [IMP-DOG-039 ボトルで手洗い](IMP-DOG-039-hand-wash-with-shampoo-bottle.md)、パーティクルの前例は [IMP-DOG-015 撫でパーティクル](IMP-DOG-015-accessories-and-petfx-port.md)、売り方は [DES-UI-005 課金アイテムの購入導線](DES-UI-005-trainer-and-paid-items-purchase-flow.md)。

## AI の追加候補 (2026-10-05)

| 分類 | 案 | 採否 |
|---|---|---|
| 泡で遊ぶ | 泡ヘアスタイル (頭にソフトクリーム・モヒカン・うさ耳の形に泡が盛れる。洗いの写真 [IMP-WLD-011](IMP-WLD-011-wash-photos-kept.md) と相性がよい)、泡が最大までたまると犬が泡に埋もれて顔だけ出る、泡からシャボン玉がふわっと浮かんで割れる | 却下 |
| 泡の見た目 | 色違い (ピンク・水色・虹・季節: 桜 / かぼちゃ / 雪)、泡の形 (ハート形の泡・星形の泡)、キラキラ光る泡 | 採用 |
| すすぎ・仕上げ | ブルブル (犬が体を振る) の水しぶきが虹やキラキラになる、ドライヤーで毛がふわっとボリュームアップ、柄タオル (くるんで拭く時の見た目)、仕上げのコロンで散歩中もしばらくキラキラが残る | 採用 (ドライヤーは特に良いと) |
| 道具 | 水鉄砲の形違い (アヒル・魚・竹の水鉄砲)、ジョウロ、大きなスポンジ・ミトン (肉球柄)、ブラシで仕上げると毛にツヤが出る | 採用 |
| 洗い場 | 檜の桶風呂・露天風呂風の見た目、浮かぶアヒルのおもちゃ、洗い場の見た目の着せ替え (銭湯風・タイル) | 採用 |
| 音 | 泡の音・水の音の種類 (ASMR) | 採用 |

決定: 2026-10-05 ユーザー。「泡で遊ぶ」は却下、それ以外 (泡の見た目・すすぎと仕上げ・道具・洗い場・音) は採用。ユーザーの依頼の 5 案 (泡もこもこ銃・水鉄砲・シャワーヘッド・泡の色・泡のパーティクル) も採用の前提。

決定: 2026-10-05 ユーザー。古民家とは共通にしない。裏山だけで使えるもので、売り方はセット。

## セットの分け方

洗う順 (泡 → 水 → 仕上げ) と場所で分ける 4 セット + 全部入り:

| セット | 中身 |
|---|---|
| 泡 | 泡もこもこ銃、泡の色・形・キラキラ、泡から出るパーティクル (ハート・肉球ほか) |
| 水 | 水鉄砲 (アヒル・魚・竹)、シャワーヘッドの形、ジョウロ、水の音 |
| 仕上げ | ドライヤー、柄タオル、ブルブルの虹しぶき、ブラシのツヤ、コロンのキラキラ |
| 洗い場 | 檜の桶風呂・露天風呂風、浮かぶアヒル、洗い場の見た目の着せ替え、泡の音 |
| 全部入り | 上の 4 つ (単品の合計より安く) |

決定: 2026-10-05 ユーザー「それでいこう」。上の 4 セット + 全部入りを採用。

不採用の別案: テーマで分ける (桜・温泉・夏祭りなど、泡の色・パーティクル・タオル柄・シャワーヘッドを揃える)。洗い方が変わる道具 (泡もこもこ銃・水鉄砲・ドライヤー) をどのテーマに入れるかが決めにくい。

決定: 2026-10-05 ユーザー。価格は各セット 500 Credits、全部入り 1500 (4 つ別々なら 2000)。1 人が買えば、同じインスタンスの全員が選べる (ワールドの基本の方針)。洗い場の見た目もこれに従う。

決定: 2026-10-05 ユーザー。買った人がインスタンスを出ても、今している洗いが終わるまでは使い続けられる。終わった時に買った人が 1 人もいなければ、無料の道具・見た目に戻る。価格は 500 のままで、AI も 500 を推した (全員で使えるので、1 回の購入が場の全員に効く)。

## 決めること

- 「洗いの終わり」を何で判定するか (犬ごとの洗い終わり・洗い場のリセット・すすぎ後のタオル)
- 他の人にも見えるか (泡の色・パーティクル・道具の見た目)。撫でパーティクルは選択だけを他人へ配る方式 (同期変数 0 本)。同じ方式で足りるか
- Quest・iOS の描画負荷 (泡 + パーティクルを 6 匹・複数人で同時に)
- 無料のボトルとの関係 (速く洗える道具にするか、見た目だけ違って洗い時間は同じにするか)
